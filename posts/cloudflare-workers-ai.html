Cloudflare Workers AI: Run AI Models at the Edge — Complete Beginner's Guide

July 11, 2026 11 min read

Cloudflare Workers AI lets you run AI/ML models at the edge — directly within Cloudflare's global network of 300+ data centers. No GPU servers to manage, no API keys to exchange, no cold starts to worry about. This guide walks you through every model type with working code examples.

What is Workers AI?

Workers AI is Cloudflare's serverless inference platform. You write a Cloudflare Worker that calls the AI.run() API, and Cloudflare executes the model at the edge data center closest to your user. The key benefits:

  • Low latency — models run within milliseconds of your users
  • Free tier — 10,000 free requests per day for most models
  • No infrastructure — just write code, deploy with one command
  • Many model types — text generation, image classification, embeddings, speech-to-text, and more

Setup: wrangler CLI

Workers AI requires the wrangler CLI (Cloudflare's build and deployment tool):

# Install wrangler (requires Node.js 18+)
npm install -g wrangler

# Log in to your Cloudflare account
wrangler login

Initialize a new Worker project:

npx create-cloudflare@latest my-ai-worker
cd my-ai-worker

Your First AI Request: Text Generation

Let's start with the most popular use case — generating text with a large language model. Workers AI offers several models including Meta's Llama, Mistral, and others:

// src/index.ts
export default {
  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url);

    if (url.pathname === "/generate") {
      const prompt = url.searchParams.get("prompt") || "Tell me a joke";

      try {
        const result = await AI.run(
          "@hf/nousresearch/hermes-2-pro-mistral-7b",
          {
            prompt: prompt,
            max_tokens: 200,
            temperature: 0.7,
          }
        );

        return Response.json({ result });
      } catch (error) {
        return Response.json({ error: error.message }, { status: 500 });
      }
    }

    return new Response("Try /generate?prompt=Hello", { status: 200 });
  },
};

Add the AI binding to your wrangler.toml:

[ai]
binding = "AI"

Deploy with one command:

wrangler deploy

Now hit your Worker URL with a prompt:

curl "https://my-ai-worker.yourname.workers.dev/generate?prompt=Explain%20recursion%20simply"

  image: [...imageArrayBuffer],

Building a Real AI Search Engine

Let's build something practical — a semantic search endpoint that finds the most relevant documents for a user query using embeddings:

// src/index.ts
interface Env {
  AI: any;
  SEARCH_INDEX: KVNamespace;  // Store embeddings in KV
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);

    // --- Index a document ---
    if (url.pathname === "/index" && request.method === "POST") {
      const { id, text } = await request.json();

      // Generate embedding
      const embeddingResult = await AI.run("@cf/baai/bge-base-en-v1.5", {
        texts: [text],
      });

      const embedding = embeddingResult.embeddings[0];

      // Store in KV: key = doc ID, value = { text, embedding }
      await env.SEARCH_INDEX.put(id, JSON.stringify({ text, embedding }));

      return Response.json({ success: true, id });
    }

    // --- Search for a query ---
    if (url.pathname === "/search" && request.method === "POST") {
      const { query, limit = 3 } = await request.json();

      // Embed the query
      const queryResult = await AI.run("@cf/baai/bge-base-en-v1.5", {
        texts: [query],
      });
      const queryEmbedding = queryResult.embeddings[0];

      // Fetch all indexed documents
      const cursor = await env.SEARCH_INDEX.list();
      const documents = await Promise.all(
        cursor.keys.map(async (key) => {
          const data = JSON.parse(await env.SEARCH_INDEX.get(key.name));
          const similarity = cosineSimilarity(queryEmbedding, data.embedding);
          return { id: key.name, text: data.text, similarity };
        })
      );

      // Sort by similarity, return top N
      const results = documents
        .sort((a, b) => b.similarity - a.similarity)
        .slice(0, limit);

      return Response.json({ results });
    }

    return new Response("Use POST /index to add docs, POST /search to query");
  },
};

// Cosine similarity utility
function cosineSimilarity(a: number[], b: number[]): number {
  const dot = a.reduce((sum, val, i) => sum + val * b[i], 0);
  const magA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0));
  const magB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0));
  return dot / (magA * magB);
}

Configure the KV namespace in wrangler.toml:

[ai]
binding = "AI"

[[kv_namespaces]]
binding = "SEARCH_INDEX"
id = "your-kv-namespace-id"
preview_id = "your-kv-preview-id"

Streaming LLM Responses

For better user experience, stream LLM output token by token instead of waiting for the full response:

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const prompt = new URL(request.url).searchParams.get("prompt") || "Hello";

    const stream = await env.AI.run(
      "@cf/meta/llama-3-8b-instruct",
      {
        prompt: prompt,
        max_tokens: 500,
      },
      { streaming: true }
    );

    return new Response(stream, {
      headers: { "Content-Type": "text/event-stream" },
    });
  },
};

Error Handling and Rate Limits

Production Workers AI code needs robust error handling:

async function safeAIrun(model, input) {
  try {
    return await AI.run(model, input);
  } catch (error) {
    if (error.message?.includes("rate limit")) {
      // Retry after a delay
      await new Promise(r => setTimeout(r, 1000));
      return await AI.run(model, input);
    }
    console.error(`AI Error: ${error.message}`);
    throw error;
  }
}

Cost Estimates

Workers AI pricing varies by model:

  • Free tier — 10,000 requests/day for most models
  • Text generation — charged per token (~$0.0002 per 1K tokens for Llama)
  • Embeddings — charged per input (~$0.10 per million inputs)
  • Image models — charged per image (~$0.01 per 1K images)

The free tier is generous enough for development, testing, and low-traffic production use.

Summary

Cloudflare Workers AI makes AI accessible without infrastructure:

  • Run AI.run(model, input) from any Cloudflare Worker
  • Supports text generation, embeddings, image classification, speech-to-text
  • 10,000 free requests per day — great for side projects
  • Stream responses for real-time chat interfaces
  • Combine with KV/Workers AI for semantic search, chatbots, and content analysis

The best part: you deploy once to Cloudflare's edge, and your AI runs within milliseconds of users in every continent. No GPU cluster to manage, no API key juggling, no scaling headaches.
