JavaScript DOM Manipulation: Build Interactive Web Pages

June 24, 2026 · 11 min read

You've learned HTML for structure and CSS for styling. Your page looks great — but it's static. Nothing responds to clicks, inputs, or user interaction. That's where the DOM (Document Object Model) comes in.

The DOM is a tree-like representation of your HTML page that JavaScript can read and modify. When you click a button, type in a form, or scroll a page, JavaScript uses the DOM to make things happen. It's the bridge between your code and the browser.

In this tutorial, you'll learn how to select elements, change content, handle events, create new elements, and build a fully interactive web page — all with vanilla JavaScript (no frameworks needed).

What Is the DOM?

The browser parses your HTML and builds a tree of objects called the Document Object Model. Every HTML element becomes a node in this tree:

Document (root)
├── <html>
│   ├── <head>
│   │   └── <title>My Page</title>
│   └── <body>
│       ├── <h1>Hello</h1>
│       ├── <div id="app">
│       │   └── <p class="text">Click me</p>
│       └── <button id="btn">Submit</button>

JavaScript accesses this tree through the document object — a global variable available in every web page.

Selecting Elements

Before you can modify an element, you need to select it. JavaScript provides several methods:

// By ID (returns a single element)
const title = document.getElementById('title');

// By class name (returns a collection)
const items = document.getElementsByClassName('item');

// By tag name (returns a collection)
const paragraphs = document.getElementsByTagName('p');

// By CSS selector (returns a single element)
const button = document.querySelector('#app .btn');
const heading = document.querySelector('h1');

// By CSS selector (returns ALL matches as a NodeList)
const cards = document.querySelectorAll('.card');
const links = document.querySelectorAll('nav a');
Recommendation: Use querySelector and querySelectorAll for everything. They accept any CSS selector and are the most flexible and modern approach.

Changing Content and Styles

Once you have a reference to an element, you can change almost anything about it:

const heading = document.querySelector('h1');

// Change text content (safe against XSS)
heading.textContent = 'New Title';

// Change HTML content (⚠️ can execute scripts — use carefully)
heading.innerHTML = '<span style="color:red">New Title</span>';

// Change styles directly
heading.style.color = 'blue';
heading.style.fontSize = '2rem';
heading.style.backgroundColor = '#f0f0f0';

// Better: toggle CSS classes instead
heading.classList.add('highlight');
heading.classList.remove('highlight');
heading.classList.toggle('highlight');
// Check if a class exists
if (heading.classList.contains('highlight')) {
    console.log('Heading is highlighted!');
}

Working with Attributes

const link = document.querySelector('a');

// Get an attribute
link.getAttribute('href');       // "https://example.com"
link.getAttribute('target');     // "_blank"

// Set an attribute
link.setAttribute('href', 'https://new-url.com');
link.setAttribute('data-id', '123');

// Remove an attribute
link.removeAttribute('target');

// Get or set the src of images
const img = document.querySelector('img');
img.src = 'new-image.jpg';
img.alt = 'Updated description';

Event Listeners: Making Pages Interactive

Events are how JavaScript responds to user actions. Use addEventListener to listen for them:

const button = document.querySelector('#click-me');

// Basic click handler
button.addEventListener('click', function() {
    alert('Button was clicked!');
});

// Using arrow functions (modern syntax)
button.addEventListener('click', () => {
    console.log('Clicked!');
});

// Common events:
element.addEventListener('click', handler);     // Mouse click
element.addEventListener('dblclick', handler);  // Double click
element.addEventListener('mouseover', handler); // Mouse enters element
element.addEventListener('mouseout', handler);  // Mouse leaves element
element.addEventListener('mouseenter', handler); // Mouse enters (no bubbling)
element.addEventListener('keydown', handler);    // Key pressed
element.addEventListener('keyup', handler);      // Key released
element.addEventListener('submit', handler);     // Form submitted
element.addEventListener('change', handler);     // Input value changed
element.addEventListener('input', handler);      // Input typing (real-time)

The Event Object

Every event handler receives an event object with useful information:

document.querySelector('#my-form').addEventListener('submit', (event) => {
    // Prevent the form from actually submitting (page reload)
    event.preventDefault();

    // Get the target element
    console.log(event.target);  // The form element

    // For keyboard events:
    // event.key  → the key pressed ("Enter", "a", etc.)
    // event.code → physical key code ("Enter", "KeyA")

    // For mouse events:
    // event.clientX, event.clientY → cursor position
});

// Keyboard example
document.addEventListener('keydown', (event) => {
    if (event.key === 'Escape') {
        console.log('User pressed Escape!');
    }
    if (event.key === 'Enter') {
        console.log('User pressed Enter!');
    }
});

Creating and Removing Elements

You can dynamically build HTML from JavaScript:

// Create a new element
const card = document.createElement('div');
card.className = 'card';
card.id = 'dynamic-card';

// Add content
const title = document.createElement('h3');
title.textContent = 'New Card';
card.appendChild(title);

const desc = document.createElement('p');
desc.textContent = 'This card was created with JavaScript!';
card.appendChild(desc);

// Insert it into the page
const container = document.querySelector('#app');
container.appendChild(card);       // Add as last child
container.insertBefore(card, container.firstChild); // Add as first child

// Remove an element
const oldCard = document.querySelector('#old-card');
oldCard.remove();

// Clear all children of a container
container.innerHTML = '';

Real Project: Interactive Task Manager

Let's build a complete interactive app — a task manager with add, complete, and delete functionality:

<!-- index.html -->
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Task Manager</title>
    <style>
        body { font-family: sans-serif; max-width: 500px; margin: 2rem auto; padding: 0 1rem; }
        input { padding: 0.5rem; width: 70%; border: 1px solid #ccc; border-radius: 4px; }
        button { padding: 0.5rem 1rem; border: none; border-radius: 4px; cursor: pointer; }
        #add-btn { background: #2563eb; color: white; }
        .task { display: flex; align-items: center; gap: 0.5rem; padding: 0.5rem; margin: 0.3rem 0; background: #f8fafc; border-radius: 4px; }
        .task.done { text-decoration: line-through; opacity: 0.6; }
        .delete-btn { background: #ef4444; color: white; margin-left: auto; }
        .count { color: #64748b; font-size: 0.9rem; }
    </style>
</head>
<body>
    <h1>✅ Task Manager</h1>
    <div>
        <input type="text" id="task-input" placeholder="Add a new task...">
        <button id="add-btn">Add</button>
    </div>
    <p class="count">0 tasks</p>
    <div id="task-list"></div>

    <script src="app.js"></script>
</body>
</html>
// app.js
const input = document.querySelector('#task-input');
const addBtn = document.querySelector('#add-btn');
const taskList = document.querySelector('#task-list');
const countDisplay = document.querySelector('.count');

let tasks = [];

// Add a task
function addTask() {
    const text = input.value.trim();
    if (!text) return;

    const task = {
        id: Date.now(),
        text: text,
        done: false
    };

    tasks.push(task);
    input.value = '';
    renderTasks();
}

// Toggle task completion
function toggleTask(id) {
    const task = tasks.find(t => t.id === id);
    if (task) {
        task.done = !task.done;
        renderTasks();
    }
}

// Delete a task
function deleteTask(id) {
    tasks = tasks.filter(t => t.id !== id);
    renderTasks();
}

// Render all tasks to the DOM
function renderTasks() {
    taskList.innerHTML = '';

    tasks.forEach(task => {
        const div = document.createElement('div');
        div.className = `task ${task.done ? 'done' : ''}`;

        const checkbox = document.createElement('input');
        checkbox.type = 'checkbox';
        checkbox.checked = task.done;
        checkbox.addEventListener('change', () => toggleTask(task.id));

        const span = document.createElement('span');
        span.textContent = task.text;
        span.addEventListener('click', () => toggleTask(task.id));

        const delBtn = document.createElement('button');
        delBtn.textContent = '✕';
        delBtn.className = 'delete-btn';
        delBtn.addEventListener('click', () => deleteTask(task.id));

        div.appendChild(checkbox);
        div.appendChild(span);
        div.appendChild(delBtn);
        taskList.appendChild(div);
    });

    countDisplay.textContent = `${tasks.length} task${tasks.length !== 1 ? 's' : ''}`;
}

// Event listeners
addBtn.addEventListener('click', addTask);

input.addEventListener('keydown', (event) => {
    if (event.key === 'Enter') {
        addTask();
    }
});

// Load demo tasks
tasks.push({ id: 1, text: 'Learn JavaScript DOM', done: false });
tasks.push({ id: 2, text: 'Build this task manager', done: true });
renderTasks();

This app demonstrates everything: selecting elements, creating/removing nodes, event listeners, and updating content dynamically. Try opening it in a browser and adding tasks!

DOM Traversal: Navigating the Tree

Once you have a reference to one element, you can navigate to related elements:

const card = document.querySelector('.card');

// Parent
card.parentElement;          // The containing element
card.parentElement.parentElement; // Go up two levels

// Children
card.children;               // All child elements (HTMLCollection)
card.firstElementChild;      // First child element
card.lastElementChild;       // Last child element

// Siblings
card.nextElementSibling;     // Next sibling element
card.previousElementSibling; // Previous sibling element

// Find within an element (scoped query)
const card = document.querySelector('.card');
const btn = card.querySelector('.delete-btn');  // Only inside this card!
Pro tip: Use element.querySelector() to search within a specific container. This avoids accidentally selecting the wrong element when multiple elements share the same class.

Summary

DOM manipulation is how JavaScript brings web pages to life. Here's the essential toolkit:

  • document.querySelector() — Select one element
  • document.querySelectorAll() — Select multiple elements
  • element.textContent — Read/set text (safe)
  • element.innerHTML — Read/set HTML
  • element.classList — Add/remove/toggle CSS classes
  • element.addEventListener() — Respond to user actions
  • document.createElement() — Build elements dynamically
  • element.appendChild() — Insert elements into the page
  • element.remove() — Delete elements from the page

Every interactive website you use — from social media to email to e-commerce — relies on these same DOM operations. Master these fundamentals and you can build anything.
