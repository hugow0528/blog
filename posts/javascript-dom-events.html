JavaScript DOM Manipulation and Events: Build Interactive Web Pages — Complete Beginner's Guide

July 20, 2026 11 min read

The Document Object Model (DOM) is JavaScript's bridge to the HTML page. Through the DOM, JavaScript can read and change any element on the page — text, styles, attributes, structure — and respond to user interactions like clicks, keyboard input, and form submissions. This guide covers everything from selecting elements to building a complete interactive todo app with event delegation.

What Is the DOM?

The DOM is a tree-like representation of your HTML document. Every HTML element becomes a node in this tree, and JavaScript provides methods to navigate, read, and modify these nodes. When you change the DOM, the browser automatically re-renders the page — that's how JavaScript creates dynamic, interactive web experiences.

Selecting Elements

Before you can manipulate an element, you need to find it. Modern JavaScript provides several methods:

// Select by ID (returns a single element)
const heading = document.getElementById("title");

// Select by CSS class (returns a live HTMLCollection)
const items = document.getElementsByClassName("list-item");

// Select by tag name (returns a live HTMLCollection)
const paragraphs = document.getElementsByTagName("p");

// QuerySelector — returns the FIRST matching element
const firstCard = document.querySelector(".card");

// QuerySelectorAll — returns ALL matching elements (static NodeList)
const allCards = document.querySelectorAll(".card");

// Query complex selectors
const activeLinks = document.querySelectorAll("nav a.active");
const nestedSpans = document.querySelectorAll(".parent > .child span.highlight");

querySelector and querySelectorAll are the most versatile — they accept any CSS selector, so you can find elements by class, ID, attribute, pseudo-class, or complex combinations.

Reading and Changing Content

Once you have an element, you can read or modify its content using several properties:

const el = document.querySelector("#message");

// textContent — reads/writes plain text (safe from XSS)
console.log(el.textContent);  // "Hello World"
el.textContent = "Updated text";

// innerHTML — reads/writes HTML (be careful with user input!)
el.innerHTML = "<strong>Bold text</strong>";

// innerText — reads rendered text (respects CSS styling)
console.log(el.innerText);

Use textContent for plain text and innerHTML when you actually need HTML. Never use innerHTML with user-supplied data — it opens your page to cross-site scripting (XSS) attacks. Use textContent or document.createTextNode() instead.

Changing Styles and Classes

Modify an element's appearance through the style property or by toggling CSS classes:

const box = document.querySelector(".box");

// Direct style modification
box.style.backgroundColor = "#3498db";
box.style.padding = "20px";
box.style.borderRadius = "8px";

// Better: toggle CSS classes (keeps logic out of JS)
box.classList.add("highlight");
box.classList.remove("hidden");
box.classList.toggle("active");  // Add if absent, remove if present
box.classList.contains("active"); // true/false

// Read computed styles
const computed = getComputedStyle(box);
console.log(computed.width);   // "300px"
console.log(computed.color);   // "rgb(52, 152, 219)"

The classList API is the preferred approach because it separates styling (CSS) from behavior (JavaScript) and avoids inline style conflicts.

Working with Attributes

Read and set HTML attributes like src, href, alt, and custom data-* attributes:

const img = document.querySelector("img");

// Standard attributes
console.log(img.src);       // Full URL
console.log(img.alt);       // "A beautiful sunset"
img.src = "new-image.jpg";
img.alt = "A sunrise";

// Custom data attributes
const card = document.querySelector("[data-user-id='42']");
console.log(card.dataset.userId);  // "42"
console.log(card.dataset.role);    // "admin"
card.dataset.status = "active";    // Sets data-status="active"

The dataset property converts data-* attributes to camelCase JavaScript properties. data-user-id becomes dataset.userId.

Creating and Removing Elements

Build dynamic content by creating new elements, adding them to the DOM, and removing old ones:

// Create a new element
const li = document.createElement("li");
li.textContent = "New item";
li.classList.add("list-item");
li.setAttribute("data-id", "1");

// Append to parent
const ul = document.querySelector("#my-list");
ul.appendChild(li);         // Add at the end
ul.prepend(li);             // Add at the beginning
ul.insertBefore(li, ul.children[1]); // Insert before a specific child

// Create multiple elements efficiently
const fragment = document.createDocumentFragment();
for (let i = 0; i < 5; i++) {
    const item = document.createElement("li");
    item.textContent = `Item ${i + 1}`;
    fragment.appendChild(item);
}
ul.appendChild(fragment);  // Single DOM insertion for all items

// Remove an element
li.remove();

// Replace one element with another
const newLi = document.createElement("li");
newLi.textContent = "Replaced";
ul.replaceChild(newLi, li);

Use DocumentFragment when adding many elements — it batches the insertions into a single DOM operation, avoiding expensive re-renders.

Event Listeners — Responding to User Actions

Events are how JavaScript responds to user interactions. Attach handlers with addEventListener():

const button = document.querySelector("#submit-btn");

// Click event
button.addEventListener("click", (event) => {
    console.log("Button clicked!");
    console.log(event.target);    // The element clicked
    console.log(event.type);      // "click"
});

// Keyboard event
document.addEventListener("keydown", (event) => {
    console.log(`Key: ${event.key}`);
    console.log(`Code: ${event.code}`);
    if (event.key === "Escape") {
        console.log("User pressed Escape!");
    }
});

// Mouse events
const card = document.querySelector(".card");
card.addEventListener("mouseenter", () => {
    card.classList.add("hovered");
});
card.addEventListener("mouseleave", () => {
    card.classList.remove("hovered");
});

// Form events
const form = document.querySelector("#contact-form");
form.addEventListener("submit", (event) => {
    event.preventDefault();  // Stop page from reloading
    const formData = new FormData(form);
    const data = Object.fromEntries(formData.entries());
    console.log("Form data:", data);
});

Common Events Reference

Here are the events you'll use most often:

// Click: click, dblclick
// Mouse: mouseenter, mouseleave, mousemove, contextmenu (right-click)
// Keyboard: keydown, keyup, keypress
// Form: submit, input, change, focus, blur
// Window: load, scroll, resize, beforeunload
// Touch: touchstart, touchmove, touchend
// DOM: DOMContentLoaded (page fully parsed)

The DOMContentLoaded event fires when the HTML is fully parsed — use it to run scripts that need elements to exist before executing:

document.addEventListener("DOMContentLoaded", () => {
    // Safe to query elements here — the page is ready
    const header = document.querySelector("header");
    header.classList.add("loaded");
});

Event Delegation — One Listener for Many Elements

Instead of adding a listener to every single element, attach one listener to a parent and let events bubble up. This is more efficient and works for dynamically created elements:

// ❌ Bad — adds a listener to every button
document.querySelectorAll(".delete-btn").forEach(btn => {
    btn.addEventListener("click", handleDelete);
});

// ✅ Good — one listener on the parent
document.querySelector("#todo-list").addEventListener("click", (e) => {
    // Find the closest matching element (event delegation)
    const btn = e.target.closest(".delete-btn");
    if (btn) {
        const id = btn.dataset.id;
        btn.closest(".todo-item").remove();
        console.log(`Deleted item ${id}`);
    }
});

Events propagate in three phases: capturing (window → target), target (the element itself), and bubbling (target → window). By default, listeners fire during bubbling. You can opt into capturing by passing true as the third argument.

Building a Complete Todo App

Let's combine everything into a working todo application:

// HTML (simplified)
// <form id="todo-form">
//   <input type="text" id="todo-input" placeholder="Add a todo...">
//   <button type="submit">Add</button>
// </form>
// <ul id="todo-list"></ul>

const form = document.querySelector("#todo-form");
const input = document.querySelector("#todo-input");
const list = document.querySelector("#todo-list");

// Add a todo
form.addEventListener("submit", (e) => {
    e.preventDefault();
    const text = input.value.trim();
    if (!text) return;

    const li = document.createElement("li");
    li.className = "todo-item";
    li.innerHTML = `
        ${text}
        
        
    `;
    list.appendChild(li);
    input.value = "";
    input.focus();
});

// Event delegation for toggle and delete
list.addEventListener("click", (e) => {
    const toggleBtn = e.target.closest(".toggle-btn");
    const deleteBtn = e.target.closest(".delete-btn");

    if (toggleBtn) {
        const item = toggleBtn.closest(".todo-item");
        item.classList.toggle("completed");
    }

    if (deleteBtn) {
        const item = deleteBtn.closest(".todo-item");
        item.remove();
    }
});

Pitfalls and Best Practices

Remove listeners when done: Use removeEventListener() to prevent memory leaks, especially in single-page apps. Never trust innerHTML with user data: Use textContent or document.createElement() instead. Avoid inline handlers: Prefer addEventListener() over onclick="..." in HTML — it keeps JavaScript separate from markup. Batch DOM changes: Use DocumentFragment or disable layout with requestAnimationFrame when modifying many elements. Use closest() for delegation: It reliably finds the intended target element regardless of nesting depth.

Summary

DOM manipulation and event handling are the core skills for building interactive web pages with JavaScript. Select elements with querySelector, modify content with textContent, style with classList, create elements with createElement(), and respond to interactions with addEventListener(). Combine these with event delegation for efficient, maintainable code that scales to any number of elements.
