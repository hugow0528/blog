CSS Subgrid: Perfectly Aligned Nested Layouts — Complete Beginner's Guide

July 15, 2026 10 min read

One of the most frustrating parts of CSS Grid is what happens when you need a nested grid. You create a grid of cards, and each card has its own internal layout — but the card titles don't line up, the buttons sit at different heights, and the spacing feels inconsistent. That's because nested grids create their own independent track system, completely unaware of the parent grid's sizing.

Enter CSS Subgrid — the feature that lets a grid item become a grid itself and inherit its track sizes from the parent. No more wrapper divs, no more guessing at widths. This guide walks you through everything from the basics to real-world card layouts.

What Is CSS Subgrid?

Normally, when you set display: grid on a child element, it creates a brand new grid with its own tracks. Subgrid lets that child grid borrow the track sizes from its parent instead.

Instead of defining grid-template-columns: 1fr 2fr 1fr on a child grid, you simply write grid-template-columns: subgrid. The child inherits the parent's column sizes perfectly.

The Basic Subgrid Pattern

Here's the simplest example — a card layout where every card shares the same column structure:

.card-grid {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
    gap: 1rem;
}

.card {
    display: grid;
    grid-template-columns: subgrid; /* inherits 1fr 2fr 1fr */
    grid-column: 1 / -1;           /* span full width of parent */
}

Each .card creates a nested grid that uses the exact same column sizes as .card-grid. The image column, title column, and button column will align perfectly across all cards — even if some cards have shorter or longer content.

Building a Perfectly Aligned Card Layout

This is where subgrid shines. Consider a card component with an image, title, description, and a button at the bottom. Without subgrid, you'd either accept misaligned buttons or fight with min-height and flex hacks.

The HTML Structure

<div class="card-grid">
    <div class="card">
        <img src="photo1.jpg" alt="Project screenshot" class="card-img">
        <div class="card-body">
            <h3>Short Title</h3>
            <p>A brief description.</p>
        </div>
        <a href="#" class="card-btn">View</a>
    </div>
    <!-- More cards... -->
</div>

The CSS

.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
    gap: 1.5rem;
}

.card {
    display: grid;
    /* Three rows: image, content, button */
    grid-template-rows: auto 1fr auto;
    gap: 0.75rem;
    border: 1px solid var(--border-solid);
    border-radius: 12px;
    padding: 1rem;
    background: var(--bg-surface);
}

.card-img {
    grid-row: 1;
    width: 100%;
    height: 180px;
    object-fit: cover;
    border-radius: 8px;
}

.card-body {
    grid-row: 2;
}

.card-body h3 {
    margin-bottom: 0.5rem;
    font-size: 1.1rem;
}

.card-body p {
    color: var(--text-tertiary);
    font-size: 0.9rem;
    line-height: 1.5;
}

.card-btn {
    grid-row: 3;
    justify-self: start;
    padding: 0.5rem 1.25rem;
    background: var(--brand);
    color: white;
    border-radius: 6px;
    font-size: 0.85rem;
    font-weight: 500;
    transition: background 0.2s;
}

.card-btn:hover {
    background: var(--brand-hover);
}

The grid-template-rows: auto 1fr auto is the key here:

  • Row 1 (auto): The image sizes to its natural height
  • Row 2 (1fr): The body takes all available space — this pushes the button to the bottom
  • Row 3 (auto): The button sizes to its content

Because the 1fr row expands, every button aligns at the same vertical position regardless of how much text is in each card's description.

Column Subgrid for Data Cards

Subgrid works with columns too. Imagine an analytics dashboard where each metric card needs a label, a big number, and a sparkline chart:

.dashboard {
    display: grid;
    grid-template-columns: 2fr 1fr 100px;
    grid-auto-rows: minmax(120px, auto);
    gap: 1rem;
}

.metric {
    display: grid;
    grid-template-columns: subgrid; /* inherits 2fr 1fr 100px */
    grid-column: 1 / -1;
    align-items: center;
    padding: 1rem;
    border: 1px solid var(--border-solid);
    border-radius: 8px;
}

.metric-label {
    grid-column: 1;
    font-size: 0.85rem;
    color: var(--text-tertiary);
    text-transform: uppercase;
    letter-spacing: 0.5px;
}

.metric-value {
    grid-column: 2;
    font-size: 1.8rem;
    font-weight: 600;
    text-align: center;
}

.metric-chart {
    grid-column: 3;
    height: 50px;
    display: flex;
    align-items: flex-end;
    gap: 3px;
}

Every metric card's label, value, and chart are perfectly aligned because they share the parent's 2fr 1fr 100px columns. Without subgrid, you'd need to hardcode pixel widths on every child.

Two-Dimensional Subgrid

You can inherit both rows and columns from the parent:

.parent-grid {
    display: grid;
    grid-template-columns: 200px 1fr 1fr;
    grid-template-rows: auto auto auto;
}

.child {
    display: grid;
    grid-template-columns: subgrid;
    grid-template-rows: subgrid;
    /* Now the child's grid items align on the parent's 3x3 tracks */
}

This is useful for complex layouts like a table of forms where every input, label, and button needs to align both horizontally and vertically across multiple rows.

Example: Aligned Form Table

<div class="form-grid">
    <div class="form-row">
        <label>Name</label>
        <input type="text" placeholder="John Doe">
        <button>Save</button>
    </div>
    <div class="form-row">
        <label>Email</label>
        <input type="email" placeholder="john@example.com">
        <button>Save</button>
    </div>
</div>
.form-grid {
    display: grid;
    grid-template-columns: 120px 1fr auto;
    grid-template-rows: auto auto;
    gap: 0.5rem 1rem;
}

.form-row {
    display: grid;
    grid-template-columns: subgrid;
    grid-template-rows: subgrid;
    grid-column: 1 / -1;
    grid-row: span 1;
    align-items: center;
}

All labels, inputs, and buttons align perfectly because every row inherits the same three-column structure.

Progressive Enhancement Strategy

If you need to support older browsers, use the @supports rule to provide a fallback:

/* Fallback: each card has its own sizing */
.card {
    display: flex;
    flex-direction: column;
    gap: 0.75rem;
}

/* Upgrade: use subgrid when supported */
@supports (grid-template-columns: subgrid) {
    .card {
        display: grid;
        grid-template-columns: subgrid;
        grid-template-rows: subgrid;
    }
}

The fallback uses flexbox — buttons won't be perfectly aligned, but the layout still works. Users with modern browsers get the improved alignment automatically.

Common Subgrid Patterns

1. Nav with Aligned Dropdowns

Navigation menus where dropdown items need to align with menu labels:

.nav-dropdown {
    display: grid;
    grid-template-columns: 120px 1fr;
    grid-template-rows: repeat(4, auto);
}

.dropdown-item {
    display: grid;
    grid-template-columns: subgrid;
    grid-template-rows: subgrid;
}

2. Pricing Table

Pricing cards where feature checkboxes align across plans:

.pricing-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1rem;
}

.pricing-card {
    display: grid;
    grid-template-rows: subgrid;
    grid-template-columns: subgrid;
    /* Features align across all three cards */
}

3. Dashboard Widgets

Widgets with headers, charts, and footers that maintain consistent spacing:

.widget {
    display: grid;
    grid-template-rows: subgrid;
    /* Every widget header is at the same height,
       every widget footer sits at the same position */
}

Common Gotchas

Gotcha 1: Subgrid Only Works on Grid Items

A subgrid must be a direct child of a grid container. You cannot use subgrid on an element that is a grandchild or deeper:

<div class="parent-grid">          /* grid container */
    <div class="child">             /* ✅ grid item — can use subgrid */
        <div class="grandchild">    /* ❌ not a direct grid item */
        </div>
    </div>
</div>

Gotcha 2: You Still Need grid-column or grid-row

When using subgrid, child grid items must be positioned using grid-column or grid-row — they don't automatically flow into tracks:

.child {
    display: grid;
    grid-template-columns: subgrid;
}

/* ✅ Explicit positioning */
.child > .title { grid-column: 1; }
.child > .desc  { grid-column: 2; }

/* ❌ Implicit placement won't work */
/* Items without explicit placement may not position correctly */

Gotcha 3: Gap Inheritance

Subgrid does not inherit the parent's gap. You need to set it explicitly on the subgrid container:

.parent {
    display: grid;
    gap: 1rem; /* This gap does NOT transfer to the subgrid */
}

.child {
    display: grid;
    grid-template-columns: subgrid;
    gap: 0.5rem; /* Set your own gap here */
}

Subgrid vs Alternatives

Approach Aligned Tracks Complexity Recommendation
Subgrid ✅ Perfect Low Best choice for nested alignment
Flexbox ⚠️ With min-height hacks Medium Fallback for older browsers
Flat Grid ✅ Perfect High Only when DOM can be flattened
Fixed Widths ✅ Manual alignment High Avoid — breaks on responsive

Summary

CSS Subgrid solves the most common pain point of nested grid layouts: keeping elements aligned across independent grid containers. By writing grid-template-columns: subgrid or grid-template-rows: subgrid, you create nested grids that share their parent's track sizes.

Key takeaways:

  • Use subgrid when child grids need to align with the parent's tracks
  • Subgrid works on columns, rows, or both simultaneously
  • Child grid items still need explicit grid-column/grid-row placement
  • Gaps are not inherited — set them explicitly on the subgrid
  • Use @supports (grid-template-columns: subgrid) for progressive enhancement
  • Best patterns: card layouts, dashboards, form tables, pricing tables, and nav dropdowns

With full browser support across Chrome, Firefox, Safari, and Edge, there's no reason not to use subgrid today. It makes layouts that were previously tedious or impossible feel natural.
