Python File Operations: Read, Write, and Manage Files

June 21, 2026 · 11 min read

Almost every real Python program needs to work with files — reading configuration, logging output, processing data, or saving results. File operations are one of those fundamental skills that separate "I can print Hello World" from "I can build useful programs." In this guide, we'll cover everything from basic read/write to working with CSV and JSON files.

The Basics: Opening and Reading Files

Python makes it incredibly simple to read a file. The open() function is your starting point:

# Read the entire file as a single string
with open("data.txt", "r") as file:
    content = file.read()
    print(content)

# Read line by line (memory efficient for large files)
with open("data.txt", "r") as file:
    for line in file:
        print(line.strip())  # .strip() removes trailing newlines

# Read all lines into a list
with open("data.txt", "r") as file:
    lines = file.readlines()
    print(f"Total lines: {len(lines)}")
    print(f"First line: {lines[0].strip()}")

Notice the with statement? This is called a context manager. It automatically closes the file when the block finishes — even if an error occurs. This is the recommended way to handle files in Python. Always use with.

Why with Is Better Than Manual Close

# ❌ DON'T DO THIS — easy to forget file.close()
file = open("data.txt", "r")
content = file.read()
print(content)
file.close()

# ✅ DO THIS — automatic cleanup, even on errors
with open("data.txt", "r") as file:
    content = file.read()
    print(content)

If an exception happens between open() and close() in the first example, the file handle stays open forever. With with, Python guarantees cleanup.

Writing to Files

Writing is just as simple. You have two main modes:

# Write mode — creates new file or OVERWRITES existing
with open("output.txt", "w") as file:
    file.write("Hello, World!\n")
    file.write("This is line two.\n")
    file.write("Last line.\n")

# Append mode — adds to existing file without deleting
with open("output.txt", "a") as file:
    file.write("This line was appended.\n")

Warning: Using "w" mode on an existing file will erase everything first. Double-check your filename before writing!

File Modes at a Glance

r   — Read only (default). Error if file doesn't exist.
w   — Write only. Creates new file or overwrites existing.
a   — Append. Creates new file if doesn't exist. Adds to end.
r+  — Read and write. Cursor starts at beginning.
x   — Exclusive create. Error if file already exists.
b   — Binary mode (add to any mode: rb, wb, ab)

Reading and Writing CSV Files

CSV (Comma-Separated Values) is the most common data format. Python's built-in csv module handles all the complexity:

import csv

# Write a CSV file
with open("students.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Name", "Age", "Grade"])  # Header row
    writer.writerow(["Alice", 22, "A"])
    writer.writerow(["Bob", 20, "B+"])
    writer.writerow(["Charlie", 23, "A-"])

# Read the CSV file
with open("students.csv", "r") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
        # Output:
        # ['Name', 'Age', 'Grade']
        # ['Alice', '22', 'A']
        # ['Bob', '20', 'B+']
        # ['Charlie', '23', 'A-']

# Read CSV with column names (DictReader)
with open("students.csv", "r") as file:
    reader = csv.DictReader(file)
    for student in reader:
        print(f"{student['Name']}: {student['Grade']}")
        # Output:
        # Alice: A
        # Bob: B+
        # Charlie: A-

Working with JSON Files

JSON is the standard format for APIs and configuration. Python's json module converts between JSON text and Python dictionaries:

import json

# Write JSON
data = {
    "name": "Hugo's Dev Notes",
    "url": "https://blog.hugow.dev",
    "topics": ["Cloudflare", "Python", "AI Coding"],
    "stats": {
        "posts": 14,
        "visitors": 1250
    }
}

with open("config.json", "w") as file:
    json.dump(data, file, indent=2)

# Read JSON
with open("config.json", "r") as file:
    loaded = json.load(file)
    print(loaded["name"])            # Hugo's Dev Notes
    print(loaded["topics"][0])       # Cloudflare
    print(loaded["stats"]["posts"])  # 14

# Pretty-print JSON
print(json.dumps(loaded, indent=2))

The key functions are:

  • json.dump() — write Python object to file
  • json.load() — read file into Python object
  • json.dumps() — convert to formatted string
  • json.loads() — parse string into Python object

Safe File Handling with Error Checking

Real programs need to handle missing files, permission errors, and corrupted data gracefully:

import json
import os

def read_config(filepath):
    """Read a JSON config file with full error handling"""
    
    # Check if file exists
    if not os.path.exists(filepath):
        print(f"❌ Config file not found: {filepath}")
        return None
    
    try:
        with open(filepath, "r") as file:
            config = json.load(file)
            print(f"✅ Loaded config with {len(config)} keys")
            return config
            
    except json.JSONDecodeError as e:
        print(f"❌ Invalid JSON in {filepath}: {e}")
        return None
    except PermissionError:
        print(f"❌ No permission to read {filepath}")
        return None
    except Exception as e:
        print(f"❌ Unexpected error: {e}")
        return None

# Use it
config = read_config("config.json")
if config:
    print(config.get("name", "Unknown"))

Pathlib: The Modern Way to Handle Paths

Python 3 includes pathlib — an object-oriented approach to file paths that's cleaner than string manipulation:

from pathlib import Path

# Create a Path object
p = Path("my_folder/data.txt")

# Get parts
print(p.name)        # data.txt
print(p.stem)        # data
print(p.suffix)      # .txt
print(p.parent)      # my_folder

# Join paths (no more string concatenation)
new_path = Path("my_folder") / "sub_folder" / "file.txt"
print(new_path)  # my_folder/sub_folder/file.txt

# Check existence
if Path("data.txt").exists():
    print("File exists!")

# List all Python files in a directory
py_files = list(Path(".").glob("*.py"))
for f in py_files:
    print(f.name)

# Read entire file in one line
content = Path("data.txt").read_text()

# Write entire file in one line
Path("output.txt").write_text("Hello!")

# Create directories that don't exist
Path("new_folder/sub_folder").mkdir(parents=True, exist_ok=True)

Real-World Project: A Simple Contact Manager

Let's combine everything into a practical project — a contact book that saves data to JSON:

import json
from pathlib import Path

CONTACTS_FILE = Path("contacts.json")

def load_contacts():
    """Load contacts from file, or return empty list"""
    if CONTACTS_FILE.exists():
        return json.loads(CONTACTS_FILE.read_text())
    return []

def save_contacts(contacts):
    """Save contacts list to file"""
    CONTACTS_FILE.write_text(json.dumps(contacts, indent=2))

def add_contact():
    """Add a new contact"""
    name = input("Name: ").strip()
    email = input("Email: ").strip()
    phone = input("Phone: ").strip()
    
    contacts = load_contacts()
    contacts.append({
        "name": name,
        "email": email,
        "phone": phone
    })
    save_contacts(contacts)
    print(f"✅ Contact '{name}' saved!")

def list_contacts():
    """Display all contacts"""
    contacts = load_contacts()
    if not contacts:
        print("No contacts yet.")
        return
    print(f"\n{'Name':<20} {'Email':<30} {'Phone':<15}")
    print("-" * 65)
    for c in contacts:
        print(f"{c['name']:<20} {c['email']:<30} {c['phone']:<15}")

def search_contacts(query):
    """Search contacts by name"""
    contacts = load_contacts()
    results = [c for c in contacts if query.lower() in c['name'].lower()]
    if results:
        print(f"Found {len(results)} match(es):")
        for r in results:
            print(f"  {r['name']} - {r['email']} - {r['phone']}")
    else:
        print("No matches found.")

# Simple menu
while True:
    print("\n📇 Contact Manager")
    print("1. Add contact")
    print("2. List contacts")
    print("3. Search contacts")
    print("4. Quit")
    choice = input("Choice: ").strip()
    
    if choice == "1":
        add_contact()
    elif choice == "2":
        list_contacts()
    elif choice == "3":
        search_contacts(input("Search: "))
    elif choice == "4":
        print("Goodbye!")
        break
    else:
        print("Invalid choice.")

Best Practices Summary

  1. Always use with — never manage file handles manually
  2. Handle exceptions — files might not exist, be corrupted, or lack permissions
  3. Use pathlib — cleaner than string paths
  4. Specify encoding — use open("file.txt", "r", encoding="utf-8") for text files
  5. Use newline="" with CSV — prevents blank lines on Windows
  6. Prefer JSON for structured data — it maps directly to Python dictionaries
  7. Use json.dump() with indent=2 — human-readable output
Remember: File operations are where programs become useful. A Python script that only works with in-memory data is limited. One that can read configs, process data files, and save results is a real tool.
