Your First Python Script: Complete Beginner Guide

June 17, 2026 · 8 min read

Never written a line of code? No problem. Python is the most beginner-friendly programming language. In 15 minutes, you'll go from zero to running your own program.

Why Python?

  • Reads like English — if x > 5: instead of if(x>5){}
  • Runs everywhere — Windows, Mac, Linux, Raspberry Pi
  • Huge ecosystem — 400,000+ libraries for anything
  • AI/ML language — TensorFlow, PyTorch, OpenAI all use Python

Step 1: Install Python

macOS

brew install python3

Ubuntu / Linux

sudo apt update
sudo apt install python3 python3-pip

Windows

Download from python.org. Check "Add Python to PATH" during install.

Check it works

python3 --version
# Python 3.x.x

Step 2: Write Your First Script

Create a file called hello.py:

print("Hello, world!")

Run it:

python3 hello.py
# Hello, world!

That's it. You just ran a Python program.

Step 3: Variables

Variables store data. No type declarations needed:

name = "Hugo"
age = 28
height = 1.75
is_cool = True

print(f"Hi, I'm {name}, age {age}")

Output: Hi, I'm Hugo, age 28

Step 4: User Input

name = input("What's your name? ")
print(f"Hello, {name}!")

Run it and type your name. Python waits for you to press Enter.

Step 5: Conditions

temperature = float(input("Enter temperature: "))

if temperature > 30:
    print("Hot day! ☀️")
elif temperature > 20:
    print("Nice weather 🌤️")
else:
    print("Cold day 🥶")

Step 6: Loops

For loop — count to 10

for i in range(10):
    print(f"Count: {i}")

While loop — keep asking

password = ""
while password != "secret":
    password = input("Enter password: ")
print("Access granted!")

Step 7: Functions

Functions let you reuse code:

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Hugo"))
print(greet("Hugo", "Morning"))

Output:

Hello, Hugo!
Morning, Hugo!

Your First Real Project

Let's build a weather reminder:

import random

def check_weather():
    temp = random.randint(15, 35)
    rain = random.choice([True, False])
    
    print(f"Today: {temp}°C")
    
    if rain:
        print("🌧️ It's raining — bring an umbrella!")
    elif temp > 30:
        print("☀️ Hot day — stay hydrated!")
    else:
        print("😊 Nice weather!")

check_weather()
