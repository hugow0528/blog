JavaScript ES6+ Modern Features Every Developer Should Know

2026-06-24 9 min read New

JavaScript has evolved dramatically since the ES6 (ECMAScript 2015) release. Modern JavaScript is cleaner, more expressive, and less error-prone than the old way. Whether you're building web apps, Node.js servers, or anything in between, these features will make your code better.

In this tutorial, we'll cover the most important ES6+ features with practical examples you can use right away.

1. let and const: Block-Safe Variables

Before ES6, JavaScript only had var for declaring variables. The problem? var is function-scoped, not block-scoped, which leads to confusing bugs:

// The old way — problematic
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}
// Output: 3, 3, 3 (not 0, 1, 2!)

ES6 introduced let and const, which are block-scoped (limited to the nearest curly braces):

// The modern way — correct
for (let i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}
// Output: 0, 1, 2 ✅

// const for values that shouldn't change
const API_URL = 'https://api.example.com';
const MAX_RETRIES = 3;

// let for values that do change
let counter = 0;
counter++; // works fine
// counter = {}; // ❌ TypeError — can't reassign const, but let works

Rule of thumb: Use const by default. Switch to let only when you need to reassign. Never use var in new code.

2. Template Literals: String Interpolation

Forget string concatenation with +. Template literals use backticks and ${} for clean string building:

// Old way — messy
const name = "Hugo";
const greeting = "Hello, " + name + "! You have " + count + " messages.";

// Modern way — clean
const name = "Hugo";
const count = 5;
const greeting = `Hello, ${name}! You have ${count} messages.`;

// Multi-line strings (newlines preserved!)
const html = `
    <div class="card">
        <h2>${title}</h2>
        <p>${description}</p>
        <button>Click Me</button>
    </div>
`;

// Expressions inside ${} work
const total = `Your total: $${price * quantity}`;
const status = count > 0 ? "available" : "sold out";
const message = `Items ${status} — ${count} in stock.`;

3. Arrow Functions: Concise Function Syntax

Arrow functions provide a shorter syntax and lexically bind this (no more bind() or .that = this hacks):

// Old way
function add(a, b) {
    return a + b;
}

// Arrow function — much shorter
const add = (a, b) => a + b;

// Single parameter — parentheses optional
const double = x => x * 2;

// With a block — use curly braces and return keyword
const greet = (name, time) => {
    const hour = time.getHours();
    const greeting = hour < 12 ? "Good morning" : "Good afternoon";
    return `${greeting}, ${name}!`;
};

// Arrow functions shine in callbacks
const numbers = [1, 2, 3, 4, 5];

// Filter and map in one chain
const result = numbers
    .filter(n => n > 2)       // [3, 4, 5]
    .map(n => n * n)          // [9, 16, 25]
    .reduce((sum, n) => sum + n); // 50

console.log(result); // 50

Warning: Don't use arrow functions as object methods or constructors — they don't have their own this:

// ❌ BAD — 'this' won't reference the object
const user = {
    name: "Hugo",
    greet: () => console.log(`Hi, I'm ${this.name}`)
};
user.greet(); // "Hi, I'm undefined"

// ✅ GOOD — regular method for object methods
const user = {
    name: "Hugo",
    greet() {
        console.log(`Hi, I'm ${this.name}`);
    }
};
user.greet(); // "Hi, I'm Hugo"

4. Destructuring: Extract Values Cleanly

Destructuring lets you unpack values from arrays and objects into variables:

Object Destructuring

// Old way
const user = { name: "Hugo", age: 28, city: "London", role: "developer" };
const userName = user.name;
const userAge = user.age;
const userCity = user.city;

// Modern way — clean one-liner
const { name, age, city } = user;
console.log(name); // "Hugo"
console.log(age);  // 28
console.log(city); // "London"

// Rename variables
const { name: userName, age: userAge } = user;

// Default values for missing properties
const { email = "no-email@example.com" } = user;
console.log(email); // "no-email@example.com" (user has no email)

// Common: extracting from function parameters
function updateUser({ name, age, city = "Unknown" }) {
    console.log(`Updating ${name}, age ${age}, from ${city}`);
}

updateUser({ name: "Hugo", age: 28 });
// "Updating Hugo, age 28, from Unknown"

Array Destructuring

const colors = ["red", "green", "blue"];

// Unpack by position
const [first, second, third] = colors;
console.log(first);  // "red"
console.log(second); // "green"

// Skip values
const [first, , last] = colors;
console.log(last); // "blue" (skipped "green")

// Rest pattern — collect remaining items
const [head, ...tail] = colors;
console.log(head); // "red"
console.log(tail); // ["green", "blue"]

// Swap variables without a temp variable
let a = 1;
let b = 2;
[a, b] = [b, a];
console.log(a, b); // 2, 1

5. Spread and Rest Operators

The spread operator (...) expands arrays and objects:

// Spread arrays
const fruits = ["apple", "banana"];
const vegetables = ["carrot", "broccoli"];

// Combine arrays
const food = [...fruits, ...vegetables];
console.log(food); // ["apple", "banana", "carrot", "broccoli"]

// Add to beginning
const newFood = ["orange", ...fruits, ...vegetables];

// Spread objects
const defaults = { theme: "dark", lang: "en", fontSize: 14 };
const userPrefs = { theme: "light", fontSize: 18 };

// Merge — later values override earlier
const settings = { ...defaults, ...userPrefs };
console.log(settings);
// { theme: "light", lang: "en", fontSize: 18 }

// Rest parameter in functions — collects all remaining args
const sum = (...numbers) => numbers.reduce((a, b) => a + b, 0);
console.log(sum(1, 2, 3, 4, 5)); // 15

// Rest in destructuring
const [first, ...rest] = [1, 2, 3, 4, 5];
console.log(first); // 1
console.log(rest);  // [2, 3, 4, 5]

6. Default Parameters

No more checking for undefined — just set defaults right in the function signature:

// Old way
function createLink(url, text) {
    text = text || "Click here"; // breaks if text is "" or 0
}

// Modern way
function createLink(url, text = "Click here", target = "_blank") {
    return `${text}`;
}

createLink("https://example.com");
// <a href="https://example.com" target="_blank">Click here</a>

createLink("https://example.com", "Visit us", "_self");
// <a href="https://example.com" target="_self">Visit us</a>

7. Modules: Import and Export

ES6 modules let you split code into reusable files:

// ─── mathUtils.js ───
// Named exports
export function add(a, b) { return a + b; }
export function subtract(a, b) { return a - b; }

// Default export (one per file)
export default class Calculator {
    history = [];
    calculate(expr) {
        this.history.push(expr);
        return eval(expr); // simplified — don't eval in production!
    }
}

// ─── main.js ───
// Import named exports (use curly braces)
import { add, subtract } from './mathUtils.js';
console.log(add(5, 3)); // 8

// Import default export (no curly braces)
import Calculator from './mathUtils.js';

// Import everything under an alias
import * as math from './mathUtils.js';
console.log(math.add(10, 20)); // 30

In your HTML, use <script type="module">:

<script type="module" src="main.js"></script>

8. Optional Chaining and Nullish Coalescing

Two operators that prevent runtime errors when dealing with potentially null/undefined values:

// Optional chaining (?.) — stops at null/undefined instead of crashing
const user = {
    name: "Hugo",
    address: {
        city: "London"
    }
};

// Safe access — returns undefined instead of throwing
console.log(user.address?.city); // "London"
console.log(user.phone?.number); // undefined (no crash!)

// Nullish coalescing (??) — default only for null/undefined
const count = null;
const display = count ?? 0;
console.log(display); // 0 (not the empty string, not 0 from falsy)

// Difference from || operator
const emptyString = "";
console.log(emptyString || "default");  // "default" (empty string is falsy)
console.log(emptyString ?? "default");   // "" (empty string is not null/undefined)

9. Practical Example: Building a Mini API Client

Let's combine several features into a practical project:

// apiClient.js — Reusable API client using modern JS
class APIClient {
    #apiKey; // Private field (ES2022)

    constructor(baseUrl, apiKey) {
        this.baseUrl = baseUrl;
        this.#apiKey = apiKey;
        this.timeout = 10000; // 10 seconds
    }

    async fetch(endpoint, options = {}) {
        const url = `${this.baseUrl}${endpoint}`;

        // Spread operator for combining default + custom options
        const config = {
            method: 'GET',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${this.#apiKey}`,
                ...options.headers
            },
            ...options
        };

        try {
            const response = await fetch(url, config);

            // Optional chaining for safe property access
            if (!response?.ok) {
                throw new Error(`HTTP ${response.status}: ${response.statusText}`);
            }

            const data = await response.json();

            // Nullish coalescing for default value
            return {
                success: true,
                data: data ?? null,
                count: data?.length ?? 0
            };
        } catch (error) {
            return {
                success: false,
                error: error?.message ?? 'Unknown error',
                data: null
            };
        }
    }
}

// Usage
const api = new APIClient('https://jsonplaceholder.typicode.com', 'your-key');

async function loadPosts() {
    const result = await api.fetch('/posts');

    if (result.success) {
        // Destructuring + arrow functions + template literals
        const recentPosts = result.data
            .filter(post => post.id <= 3)
            .map(({ id, title, body }) => ({
                id,
                title: title?.slice(0, 50) ?? 'Untitled',
                preview: body?.slice(0, 100) + '...' ?? ''
            }));

        console.table(recentPosts);
    }
}

loadPosts();

Summary

Modern JavaScript (ES6+) makes your code cleaner, safer, and more maintainable. Here's your quick-reference cheat sheet:

  • const/let instead of var
  • Template literals with backticks instead of string concatenation
  • Arrow functions for callbacks and short functions
  • Destructuring to unpack objects and arrays
  • Spread/rest for combining and collecting values
  • Default parameters for clean function signatures
  • Modules for organized, reusable code
  • Optional chaining (?.) for safe property access
  • Nullish coalescing (??) for smart defaults

Start applying these features in your next project. Your future self (and your teammates) will thank you.
