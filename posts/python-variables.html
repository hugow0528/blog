Python Variables & Data Types for Beginners

June 17, 2026 · 7 min read

Every program works with data. Python makes it easy — no type declarations, no complex syntax. Just create and use.

Strings — Text

name = "Hugo"
city = 'Hong Kong'
message = """This is a
multi-line string"""

# Combine strings
full = name + " lives in " + city
print(full)  # Hugo lives in Hong Kong

# Better: f-strings
print(f"{name} lives in {city}")

Numbers — Integers & Floats

age = 28              # integer
height = 1.75          # float
temperature = -5       # negative number
population = 7_400_000 # underscores for readability

# Math
print(age + 1)         # 29
print(height * 100)    # 175.0
print(10 / 3)          # 3.333...
print(10 // 3)         # 3 (integer division)
print(10 % 3)          # 1 (remainder)
print(2 ** 8)          # 256 (power)

Booleans — True/False

is_raining = True
has_umbrella = False

# Comparisons
print(5 > 3)       # True
print(5 == 3)      # False
print("hi" != "bye") # True

Lists — Ordered Collections

# Create a list
fruits = ["apple", "banana", "orange"]

# Access items (0-indexed)
print(fruits[0])   # apple
print(fruits[-1])  # orange (last item)

# Modify
fruits.append("mango")
fruits[1] = "grape"

# Iterate
for fruit in fruits:
    print(fruit)

# List length
print(len(fruits))  # 4

Dictionaries — Key-Value Pairs

# Create a dictionary
person = {
    "name": "Hugo",
    "age": 28,
    "city": "Yuen Long"
}

# Access values
print(person["name"])  # Hugo

# Add/modify
person["job"] = "Developer"
person["age"] = 29

# Iterate
for key, value in person.items():
    print(f"{key}: {value}")

Practical Example: Weather App

# Store weather data
weather = {
    "location": "Yuen Long",
    "temperature": 28,
    "humidity": 75,
    "conditions": "partly cloudy",
    "rain_alert": False
}

# Display info
print(f"📍 {weather['location']}")
print(f"🌡️ {weather['temperature']}°C")
print(f"💧 {weather['humidity']}% humidity")

# Conditional message
if weather['rain_alert']:
    print("🌧️ Rain alert! Bring umbrella.")
elif weather['temperature'] > 30:
    print("☀️ Hot day! Stay hydrated.")
else:
    print("😊 Nice weather!")

Type Conversion

# String to number
age_str = "28"
age_num = int(age_str)
print(age_num + 1)  # 29

# Number to string
temp = 28
print("Temperature: " + str(temp) + "°C")

# Input always returns string
temp = float(input("Enter temperature: "))
# Now temp is a number, not text

Common Mistakes

Forgetting quotes for strings

# Wrong
name = Hugo  # NameError

# Right
name = "Hugo"

Using = instead of ==

# Wrong (assignment)
if name = "Hugo":

# Right (comparison)
if name == "Hugo":

List index out of range

fruits = ["apple", "banana"]
print(fruits[2])  # IndexError! Only 0 and 1 exist
