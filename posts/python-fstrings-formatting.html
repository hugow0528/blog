Python f-strings and String Formatting: Write Cleaner Code

Python June 29, 2026

String formatting is one of the most common things you'll do in Python — building output messages, generating reports, creating SQL queries, and more. Python offers four ways to format strings, from the old-school % operator to the modern, powerful f-strings. This guide walks you through all of them, with practical examples you can run today.

Method 1: The % Operator (Old School)

The % operator was inherited from C's printf. You'll see it in older code:

name = "Hugo"
age = 28

# %s for strings, %d for integers, %f for floats
print("Hello, %s! You are %d years old." % (name, age))
# Output: Hello, Hugo! You are 28 years old.

# Format floats: %.2f means 2 decimal places
price = 19.995
print("Price: $%.2f" % price)
# Output: Price: $20.00

When to use it: Legacy codebases. Use f-strings for anything new.

Method 2: str.format() (Mid Era)

The .format() method, introduced in Python 2.6, replaced % as the recommended approach:

name = "Hugo"
age = 28

# Positional arguments
print("Hello, {}! You are {} years old.".format(name, age))

# Numbered arguments (reorder easily)
print("{1} is {0} years old.".format(age, name))
# Output: Hugo is 28 years old.

# Named arguments (more readable)
print("Hello, {name}! You are {age} years old.".format(
    name="Hugo",
    age=28
))

# Format specifiers inside {}
print("Price: ${:.2f}".format(19.995))  # $20.00
print("Binary: {:b}".format(42))          # 101010
print("Hex: {:x}".format(255))           # ff
print("Percent: {:.1%}".format(0.855))   # 85.5%

Format width and alignment:

# Left-align in 20 characters
print("{:<20} | {}".format("Name", "Hugo"))
# Output: Name               | Hugo

# Right-align in 20 characters  
print("{:>20} | {}".format("Name", "Hugo"))
# Output:               Name | Hugo

# Center in 20 characters
print("{:^20} | {}".format("Name", "Hugo"))
# Output:      Name        | Hugo

# Pad with zeros (useful for IDs)
print("ID: {:05d}".format(42))
# Output: ID: 00042

Method 3: f-strings (The Modern Way)

Introduced in Python 3.6, f-strings are the recommended approach. They're faster, cleaner, and support inline expressions:

name = "Hugo"
age = 28

# Basic f-string
print(f"Hello, {name}! You are {age} years old.")
# Output: Hello, Hugo! You are 28 years old.

# Inline expressions
print(f"Next year, {name} will be {age + 1}.")
# Output: Next year, Hugo will be 29.

# Function calls inside f-strings
name = "hugo"
print(f"Hello, {name.title()}!")
# Output: Hello, Hugo!

Fancy Formatting with f-strings

# Numbers with thousands separators
population = 8000000000
print(f"Earth population: {population:,}")
# Output: Earth population: 8,000,000,000

# Percentage formatting
score = 0.9235
print(f"Accuracy: {score:.1%}")
# Output: Accuracy: 92.3%

# Fixed decimal places
pi = 3.14159265
print(f"Pi = {pi:.4f}")
# Output: Pi = 3.1416

# Pad strings
word = "Hi"
print(f"|{word:>10}|")
# Output: |        Hi|

# Binary, hex, octal
n = 42
print(f"Decimal: {n}, Binary: {n:b}, Hex: {n:x}, Octal: {n:o}")
# Output: Decimal: 42, Binary: 101010, Hex: 2a, Octal: 52

# Positive/negative sign always shown
temp = -5
print(f"Temperature: {temp:+.1f}°C")
# Output: Temperature: -5.0°C

# Scientific notation
avogadro = 6.022e23
print(f"Avogadro's number: {avogadro:.3e}")
# Output: Avogadro's number: 6.022e+23

f-strings with Dictionaries and Objects

# Accessing dictionary keys
user = {"name": "Hugo", "role": "admin", "active": True}
print(f"User: {user['name']}, Role: {user['role']}")
# Output: User: Hugo, Role: admin

# Safe dictionary access (avoid KeyError)
settings = {"theme": "dark"}
print(f"Theme: {settings.get('theme', 'light')}")
print(f"Mode: {settings.get('mode', 'auto')}")
# Output: Theme: dark
# Output: Mode: auto

Multi-line f-strings

items = [{"name": "Laptop", "price": 999.99},
         {"name": "Mouse", "price": 29.99},
         {"name": "Keyboard", "price": 79.95}]

report = f"""
═══════════════════════════════════
           ORDER RECEIPT
═══════════════════════════════════
"""

for item in items:
    report += f"  {item['name']:<15} ${item['price']:>8.2f}\n"

total = sum(item['price'] for item in items)
report += f"  ────────────────────────────\n"
report += f"  {'TOTAL':<15} ${total:>8.2f}\n"
report += "═══════════════════════════════════"

print(report)

Output:

  Laptop          $  999.99
  Mouse            $   29.99
  Keyboard         $   79.95
  ────────────────────────────
  TOTAL            $ 1109.93

Debug f-strings (Python 3.8+)

Python 3.8 added the = specifier for automatic debugging — it prints both the expression and its result:

x = 10
y = 20
print(f"{x = }, {y = }")
# Output: x = 10, y = 20

print(f"{x + y = }")
# Output: x + y = 30

# Combine with formatting
pi = 3.14159
print(f"{pi = :.2f}")
# Output: pi = 3.14

# Great for logging
items = [1, 2, 3, 4, 5]
print(f"{items = }")
print(f"{len(items) = }")
# Output: items = [1, 2, 3, 4, 5]
# Output: len(items) = 5

Method 4: string.Template (Safe for User Input)

When formatting strings with untrusted user input, use string.Template to avoid injection attacks:

from string import Template

# Safe template - no code execution possible
template = Template("Hello, $name! Your score is $score.")
result = template.safe_substitute(name="Hugo", score=95)
print(result)
# Output: Hello, Hugo! Your score is 95.

# Missing values stay as placeholders (no error!)
result = template.safe_substitute(name="Hugo")
print(result)
# Output: Hello, Hugo! Your score is $score.

Real-World Examples

Example 1: Log Formatter

from datetime import datetime

def log(message, level="INFO"):
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    print(f"[{timestamp}] [{level:<5}] {message}")

log("Server started on port 8080")
log("Connection timeout", level="ERROR")
log("Cache hit ratio: 87.3%", level="WARN")

# Output:
# [2026-06-29 10:15:23] [INFO ] Server started on port 8080
# [2026-06-29 10:15:24] [ERROR] Connection timeout
# [2026-06-29 10:15:25] [WARN ] Cache hit ratio: 87.3%

Example 2: CSV Generator

def generate_csv(headers, rows):
    """Generate a CSV string from headers and rows"""
    output = ",".join(headers) + "\n"
    for row in rows:
        output += ",".join(str(cell) for cell in row) + "\n"
    return output

headers = ["Name", "Age", "City"]
rows = [
    ["Hugo", 28, "Singapore"],
    ["Alice", 32, "London"],
    ["Bob", 25, "Tokyo"],
]

print(generate_csv(headers, rows))
# Output:
# Name,Age,City
# Hugo,28,Singapore
# Alice,32,London
# Bob,25,Tokyo

Example 3: Progress Bar

def progress_bar(current, total, width=30):
    """Create a text progress bar"""
    percent = current / total
    filled = int(width * percent)
    bar = "█" * filled + "░" * (width - filled)
    print(f"\rProgress: [{bar}] {percent:.1%}", end="")

# Simulate progress
import time
for i in range(101):
    progress_bar(i, 100)
    time.sleep(0.05)

Example 4: Formatted Table

data = [
    {"name": "Hugo", "score": 92.5, "grade": "A"},
    {"name": "Alice", "score": 87.3, "grade": "B+"},
    {"name": "Bob", "score": 74.8, "grade": "C"},
    {"name": "Charlie", "score": 95.1, "grade": "A+"},
]

# Build table
header = f"{'Name':<12} {'Score':>8} {'Grade':>6}"
separator = "-" * len(header)

print(header)
print(separator)
for row in data:
    print(f"{row['name']:<12} {row['score']:>8.1f} {row['grade']:>6}")

# Output:
# Name          Score  Grade
# ---------------------------
# Hugo           92.5      A
# Alice          87.3     B+
# Bob            74.8      C
# Charlie        95.1     A+

f-strings Performance Bonus

f-strings aren't just prettier — they're significantly faster because they're evaluated at compile time:

import timeit

name = "Hugo"
count = 1000000

# f-string (fastest)
print(timeit.timeit(f"f'Hello, {name}!'", globals=globals(), number=count))
# ~0.05 seconds

# .format() (slower)
print(timeit.timeit("'Hello, {}!'.format(name)", globals=globals(), number=count))
# ~0.12 seconds

# % operator (slowest for strings)
print(timeit.timeit("'Hello, %s!' % name", globals=globals(), number=count))
# ~0.15 seconds

f-strings are ~2x faster than .format() and ~3x faster than %. For tight loops or high-frequency logging, this matters.

Common Pitfalls

  1. Don't use {} inside f-strings for literal braces: Use {{ and }} to escape them. 
    # Wrong - raises SyntaxError
# print(f"The price is ${{100}}")

# Right - use double braces
print(f"The price is ${{100}}")
# Output: The price is $100
  2. Don't use backslashes inside f-string expressions: 
    # Wrong - SyntaxError
# print(f"New line: {\"hello\nworld\"}")

# Right - assign to a variable first
text = "hello\nworld"
print(f"New line: {text}")
  3. Lazy evaluation: f-strings evaluate expressions at creation time, not at use. 
    from time import time
t = time()
msg = f"Timestamp: {t}"
time.sleep(2)
print(msg)  # Still shows the original timestamp!
# Output: Timestamp: 1234567890.123456

Quick Reference Cheat Sheet

# Number formatting
f"{value:d}"       # Decimal integer
f"{value:f}"       # Fixed-point float
f"{value:.2f}"     # 2 decimal places
f"{value:e}"       # Scientific notation
f"{value:%}"       # Percentage
f"{value:,}"       # Thousands separator
f"{value:x}"       # Hexadecimal
f"{value:b}"       # Binary

# Alignment & padding
f"{'text':>10}"    # Right-align, width 10
f"{'text':<10}"    # Left-align, width 10
f"{'text':^10}"    # Center, width 10
f"{value:010}"     # Zero-pad to 10 digits

# Sign formatting
f"{value:+d}"      # Always show sign (+ or -)
f"{value: d}"      # Space for positive numbers

# Debug (Python 3.8+)
f"{variable = }"   # Prints variable = value
