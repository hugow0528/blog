Python Classes and OOP: Object-Oriented Programming for Beginners

June 23, 2026 · 11 min read

You've learned Python variables, loops, functions, and file operations. Now it's time to level up with Object-Oriented Programming (OOP) — the paradigm that powers most real-world Python applications. From web frameworks like Django to data science libraries like pandas, OOP is everywhere.

In this tutorial, we'll build from the ground up: creating your first class, understanding objects, inheritance, and real-world patterns — all with working code you can run immediately.

What Is Object-Oriented Programming?

OOP is a programming style that organizes code around objects — data structures that bundle related data (attributes) and behavior (methods) together. Think of an object as a blueprint for a real-world thing.

Analogy: A class is like a cookie cutter (the blueprint). Each cookie you make from it is an object (an instance). All cookies share the same shape but can have different toppings, textures, and flavors.

Your First Class

Let's create a simple Dog class. Every class in Python uses the class keyword and a special method called __init__ (the constructor) to set up new objects.

class Dog:
    """A simple Dog class."""
    
    def __init__(self, name, breed):
        """Initialize a Dog with a name and breed."""
        self.name = name      # instance attribute
        self.breed = breed    # instance attribute
        self.tricks = []      # starts with empty list
    
    def add_trick(self, trick):
        """Teach the dog a new trick."""
        self.tricks.append(trick)
        print(f"{self.name} learned '{trick}'!")
    
    def sit(self):
        """Make the dog sit."""
        print(f"{self.name} sits politely.")
    
    def speak(self):
        """Make the dog speak."""
        print(f"{self.name} says: Woof!")
    
    def __str__(self):
        """String representation of the Dog."""
        return f"{self.name} the {self.breed}"

# Create objects (instances)
buddy = Dog("Buddy", "Golden Retriever")
max = Dog("Max", "German Shepherd")

# Use methods
buddy.sit()          # Buddy sits politely.
buddy.speak()        # Buddy says: Woof!
buddy.add_trick("roll over")  # Buddy learned 'roll over'!

# Use __str__
print(buddy)         # Buddy the Golden Retriever
print(max)           # Max the German Shepherd

Key concepts here:

  • self refers to the current object instance — it's always the first parameter in methods
  • __init__ runs automatically when you create a new object
  • self.name stores data unique to each instance (Buddy vs Max)
  • __str__ defines what prints when you use print(object)

Class Attributes vs Instance Attributes

Attributes defined inside __init__ belong to each individual instance. Attributes defined outside methods are shared by all instances — these are class attributes.

class BankAccount:
    """A class to manage a bank account."""
    
    # Class attribute — shared by ALL BankAccount objects
    interest_rate = 0.05  # 5% interest
    
    def __init__(self, owner, balance=0):
        # Instance attributes — unique to each object
        self.owner = owner
        self.balance = balance
        self.transactions = []
    
    def deposit(self, amount):
        """Add money to the account."""
        if amount <= 0:
            raise ValueError("Deposit amount must be positive")
        self.balance += amount
        self.transactions.append(f"Deposited: ${amount:.2f}")
        print(f"Deposited ${amount:.2f}. New balance: ${self.balance:.2f}")
    
    def withdraw(self, amount):
        """Remove money from the account."""
        if amount <= 0:
            raise ValueError("Withdrawal amount must be positive")
        if amount > self.balance:
            print(f"Insufficient funds! Balance: ${self.balance:.2f}")
            return False
        self.balance -= amount
        self.transactions.append(f"Withdrew: ${amount:.2f}")
        print(f"Withdrew ${amount:.2f}. New balance: ${self.balance:.2f}")
        return True
    
    def apply_interest(self):
        """Apply annual interest to the balance."""
        interest = self.balance * self.interest_rate
        self.balance += interest
        self.transactions.append(f"Interest: +${interest:.2f}")
        print(f"Applied interest: +${interest:.2f}. New balance: ${self.balance:.2f}")
    
    def statement(self):
        """Print all transactions."""
        print(f"\nStatement for {self.owner}:")
        for i, txn in enumerate(self.transactions, 1):
            print(f"  {i}. {txn}")
        print(f"  Balance: ${self.balance:.2f}\n")

# Change the class attribute (affects ALL accounts)
BankAccount.interest_rate = 0.03  # Change to 3%

# Create accounts
savings = BankAccount("Alice", 1000)
checking = BankAccount("Bob", 500)

# Use the account
savings.deposit(200)       # Deposited $200.00. New balance: $1200.00
savings.withdraw(50)       # Withdrew $50.00. New balance: $1150.00
savings.apply_interest()   # Applied interest: +$34.50. New balance: $1184.50
savings.statement()

# Check balance
print(savings.balance)     # 1184.5

Inheritance: Building on Existing Classes

Inheritance lets you create a new class that inherits all the attributes and methods of an existing class, then add or override features. This is how you avoid repeating code.

class SavingsAccount(BankAccount):
    """A savings account with bonus features."""
    
    def __init__(self, owner, balance=0, minimum_balance=100):
        super().__init__(owner, balance)  # call parent __init__
        self.minimum_balance = minimum_balance
        self.withdrawal_limit = 3  # max withdrawals per month
    
    def withdraw(self, amount):
        """Override parent withdraw with minimum balance check."""
        if self.balance - amount < self.minimum_balance:
            print(f"Cannot withdraw! Must keep ${self.minimum_balance:.2f} minimum.")
            return False
        if self.withdrawal_limit <= 0:
            print("Withdrawal limit reached for this month!")
            return False
        self.withdrawal_limit -= 1
        return super().withdraw(amount)  # call parent withdraw
    
    def apply_interest(self):
        """Override: savings gets double interest."""
        interest = self.balance * self.interest_rate * 2
        self.balance += interest
        self.transactions.append(f"Bonus interest: +${interest:.2f}")
        print(f"Applied double interest: +${interest:.2f}")

# Create a savings account
mysavings = SavingsAccount("Alice", 2000, minimum_balance=500)
mysavings.deposit(300)        # Deposited $300.00. New balance: $2300.00
mysavings.withdraw(100)       # Withdrew $100.00. New balance: $2200.00
mysavings.withdraw(1800)      # Cannot withdraw! Must keep $500.00 minimum.
mysavings.apply_interest()    # Applied double interest: +$66.00

What happened:

  • SavingsAccount inherits everything from BankAccount
  • super().__init__() calls the parent's constructor so we don't rewrite it
  • We overrode withdraw() and apply_interest() with new logic
  • New attributes (minimum_balance, withdrawal_limit) are specific to savings accounts

Encapsulation: Protecting Your Data

Encapsulation means hiding internal details and controlling access. In Python, we use a single underscore prefix (_) to signal "private" and properties for safe access.

class Player:
    """A game player with protected attributes."""
    
    def __init__(self, name, health=100):
        self.name = name
        self._health = health    # "private" — don't modify directly
        self._score = 0          # "private"
    
    @property
    def health(self):
        """Read-only access to health."""
        return self._health
    
    @property
    def score(self):
        """Read-only access to score."""
        return self._score
    
    def take_damage(self, amount):
        """Reduce health safely."""
        if amount < 0:
            raise ValueError("Damage cannot be negative")
        self._health = max(0, self._health - amount)
        if self._health == 0:
            print(f"{self.name} has been defeated!")
    
    def earn_points(self, points):
        """Increase score safely."""
        self._score += points
        print(f"{self.name} earned {points} points! Total: {self._score}")

# Use the Player class
hero = Player("Hero", 100)
print(hero.health)      # 100 (read-only, works via @property)

hero.take_damage(30)    # (no output, health goes to 70)
print(hero.health)      # 70

hero.earn_points(50)    # Hero earned 50 points! Total: 50

# Trying to set health directly is "discouraged" but not blocked:
# hero._health = 999    # Don't do this! Use take_damage() instead.

Polymorphism: Same Interface, Different Behavior

Polymorphism means objects of different classes can be treated uniformly if they share a method name. This is powerful for writing flexible code.

class Shape:
    """Base shape class."""
    
    def area(self):
        raise NotImplementedError("Subclasses must implement area()")
    
    def describe(self):
        return f"I am a {self.__class__.__name__}."

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        import math
        return math.pi * self.radius ** 2

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height

class Triangle(Shape):
    def __init__(self, base, height):
        self.base = base
        self.height = height
    
    def area(self):
        return 0.5 * self.base * self.height

# Polymorphism in action — works with ANY Shape
shapes = [
    Circle(5),
    Rectangle(4, 6),
    Triangle(3, 8)
]

for shape in shapes:
    print(f"{shape.describe()} Area = {shape.area():.2f}")

# Output:
# I am a Circle. Area = 78.54
# I am a Rectangle. Area = 24.00
# I am a Triangle. Area = 12.00

Putting It All Together: A Contact Manager Project

Let's build something practical — a simple contact manager that uses everything we've covered.

import json
import os

class Contact:
    """Represents a single contact."""
    
    def __init__(self, name, phone, email=""):
        self.name = name
        self.phone = phone
        self.email = email
        self.tags = []
    
    def add_tag(self, tag):
        if tag not in self.tags:
            self.tags.append(tag)
    
    def __str__(self):
        tags_str = ", ".join(self.tags) if self.tags else "none"
        return f"{self.name} | {self.phone}" + (f" | {self.email}" if self.email else "") + f"\n  Tags: {tags_str}"

class ContactManager:
    """Manages a collection of contacts."""
    
    def __init__(self, filename="contacts.json"):
        self.filename = filename
        self.contacts = []
        self._load()
    
    def add(self, contact):
        """Add a new contact."""
        self.contacts.append(contact)
        self._save()
        print(f"Added: {contact.name}")
    
    def find(self, name):
        """Find contacts by name (partial match)."""
        return [c for c in self.contacts if name.lower() in c.name.lower()]
    
    def delete(self, name):
        """Delete a contact by name."""
        before = len(self.contacts)
        self.contacts = [c for c in self.contacts if c.name.lower() != name.lower()]
        if len(self.contacts) < before:
            self._save()
            print(f"Deleted: {name}")
            return True
        print(f"Not found: {name}")
        return False
    
    def list_all(self):
        """List all contacts."""
        if not self.contacts:
            print("No contacts yet.")
            return
        for i, contact in enumerate(self.contacts, 1):
            print(f"{i}. {contact}")
    
    def _save(self):
        """Save contacts to JSON file."""
        data = [{
            "name": c.name,
            "phone": c.phone,
            "email": c.email,
            "tags": c.tags
        } for c in self.contacts]
        with open(self.filename, "w") as f:
            json.dump(data, f, indent=2)
    
    def _load(self):
        """Load contacts from JSON file."""
        if not os.path.exists(self.filename):
            return
        try:
            with open(self.filename, "r") as f:
                data = json.load(f)
            for item in data:
                c = Contact(item["name"], item["phone"], item["email"])
                c.tags = item.get("tags", [])
                self.contacts.append(c)
        except (json.JSONDecodeError, KeyError):
            print("Warning: Could not load contacts file.")

# --- Use the Contact Manager ---
manager = ContactManager()

manager.add(Contact("Alice Smith", "555-0101", "alice@email.com"))
manager.add(Contact("Bob Jones", "555-0102"))

# Tag contacts
manager.contacts[0].add_tag("work")
manager.contacts[0].add_tag("friend")
manager.contacts[1].add_tag("family")

manager.list_all()

# Search
results = manager.find("alice")
print(f"\nFound {len(results)} match(es)")

# Delete
manager.delete("Bob Jones")

OOP Design Principles Cheat Sheet

  • Encapsulation — bundle data and behavior in classes; protect internal state
  • Inheritance — create new classes from existing ones to avoid duplication
  • Polymorphism — use the same interface (methods) across different classes
  • Composition over inheritance — prefer "has a" over "is a" when possible (e.g., a Car has an Engine rather than inheriting from it)
