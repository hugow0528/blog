Python f-Strings: String Formatting Made Beautiful and Fast

July 4, 2026 9 min read

If you've been writing Python for any length of time, you've probably formatted strings one of three ways:

# Old-style % formatting
name = "Hugo"
message = "Hello, %s!" % name

# .format() method
message = "Hello, {}!".format(name)

# f-strings (Python 3.6+)
message = f"Hello, {name}!"

f-strings (short for formatted string literals) are the modern, recommended way to format strings in Python. They're faster than the alternatives, more readable, and support almost anything you'd want to do with string formatting.

Why f-Strings Beat Everything Else

f-strings were introduced in Python 3.6 and have become the standard for string formatting. Here's why:

  • Speed: f-strings are evaluated at runtime but are significantly faster than % formatting and .format() because they avoid the overhead of method calls and parsing format strings
  • Readability: Variables appear directly in the string, making it obvious what's being substituted
  • Expressiveness: You can put any valid Python expression inside the curly braces
  • Debugging: Python 3.8+ adds a debug feature that shows both the variable name and its value

Let's benchmark the difference:

import timeit

name = "Hugo"

# f-string: ~0.06 seconds for 100K iterations
timeit.timeit(lambda: f"Hello, {name}!", number=100000)

# .format(): ~0.13 seconds for 100K iterations
timeit.timeit(lambda: "Hello, {}!".format(name), number=100000)

# % formatting: ~0.10 seconds for 100K iterations
timeit.timeit(lambda: "Hello, %s!" % name, number=100000)

f-strings are roughly 2x faster than .format() and noticeably faster than % formatting. For most code the difference is negligible, but in tight loops or high-throughput applications, it matters.

Basic f-String Syntax

Put an f before your string literal, then use {} to insert variables:

name = "Hugo"
age = 30
city = "San Francisco"

print(f"Hi, I'm {name}")
print(f"I'm {age} years old and live in {city}")

# Output:
# Hi, I'm Hugo
# I'm 30 years old and live in San Francisco

Works with single quotes, double quotes, and triple-quoted strings:

name = "Hugo"
print(f'Hello, {name}!')  # single quotes
print(f"""Multi-line
Hello, {name}!""")  # triple quotes

Expressions Inside f-Strings

Any valid Python expression goes inside {}. This is where f-strings get powerful:

price = 19.99
quantity = 3

# Arithmetic
total = f"Total: ${price * quantity:.2f}"
print(total)  # Total: $59.97

# Function calls
name = "  hugo  "
print(f"Name: {name.strip().title()}")  # Name: Hugo

# Boolean expressions
age = 25
print(f"Eligible: {age >= 18}")  # Eligible: True

# Ternary expressions
score = 75
grade = f"Result: {'Pass' if score >= 60 else 'Fail'}"
print(grade)  # Result: Pass

# Accessing list/dict elements
user = {"name": "Hugo", "role": "admin"}
print(f"User: {user['name']} ({user['role']})")  # User: Hugo (admin)

Format Specifiers: Control Exactly How Values Appear

After a variable in an f-string, add a colon : followed by a format specifier. Think of it as mini-language for controlling output:

# ===== NUMBERS =====
pi = 3.14159265

# Decimal places
print(f"Pi: {pi:.2f}")       # Pi: 3.14
print(f"Pi: {pi:.4f}")       # Pi: 3.1416

# Width and padding
print(f"Pi: {pi:10.2f}")     # Pi:       3.14 (10 chars wide)
print(f"Pi: {pi:010.2f}")    # Pi: 000003.14 (zero-padded)

# Thousands separator
population = 8045311000
print(f"World: {population:,}")  # World: 8,045,311,000

# Percentage
rate = 0.075
print(f"Rate: {rate:.1%}")     # Rate: 7.5%

# Scientific notation
avogadro = 6.022e23
print(f"Avogadro: {avogadro:.2e}")  # Avogadro: 6.02e+23

# ===== INTEGERS =====
number = 42

print(f"Decimal: {number}")     # Decimal: 42
print(f"Binary: {number:b}")    # Binary: 101010
print(f"Hex: {number:x}")       # Hex: 2a
print(f"Octal: {number:o}")     # Octal: 52
print(f"Padded: {number:05d}")  # Padded: 00042

# ===== STRINGS =====
name = "hugo"

print(f"Uppercase: {name:>10}")    # Right-align, width 10
print(f"Uppercase: {name:<10}")    # Left-align, width 10
print(f"Centered:  {name:^10}")    # Center, width 10
print(f"Trimmed:   {name:.3}")     # Trimmed:   hug (max 3 chars)

The Debug Feature (Python 3.8+)

Put a = after a variable name to see both the expression and its result. This is incredibly useful during debugging:

name = "Hugo"
age = 30

# Instead of:
print(f"Name: {name}, Age: {age}")
# Name: Hugo, Age: 30

# Use debug mode:
print(f"{name=}, {age=}")
# name='Hugo', age=30

# With expressions:
width, height = 800, 600
print(f"{width * height=}")
# width * height=480000

# Combine with format specifiers:
price = 19.995
print(f"{price=:.2f}")
# price=20.00

Real-World Patterns

1. Building JSON-like Output

user = {
    "name": "Hugo",
    "email": "hugo@example.com",
    "is_admin": True
}

# Quick debugging output (not actual JSON!)
log = f"""User Record:
  name:     {user['name']}
  email:    {user['email']}
  admin:    {user['is_admin']}
  created:  {user.get('created', 'N/A')}"""

print(log)

2. Generating SQL Queries

username = "hugo"
age = 30
active = True

# WARNING: Never use f-strings for SQL values directly (SQL injection risk!)
# This example is for understanding the syntax only.
# Use parameterized queries in production.

query = f"""SELECT * FROM users
WHERE username = '{username}'
  AND age = {age}
  AND is_active = {active!s}
ORDER BY created_at DESC"""

print(query)
# SELECT * FROM users WHERE username = 'hugo'
# AND age = 30 AND is_active = True
# ORDER BY created_at DESC

Important: Use {var!s} to force string conversion. The !s calls str() on the value, !r calls repr().

3. Formatted Logging Messages

import logging
from datetime import datetime

logger = logging.getLogger(__name__)

def process_order(order_id, items, total):
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    
    logger.info(f"[{timestamp}] Order #{order_id}: "
                f"{len(items)} items, "
                f"total: ${total:.2f}")
    
    # Debug with expressions
    logger.debug(f"{order_id=}, {len(items)=}, {total=:.2f}")

process_order(1001, ["laptop", "mouse", "keyboard"], 1299.97)
# [2026-07-04 12:00:00] Order #1001: 3 items, total: $1299.97
# order_id=1001, len(items)=3, total=1299.97

4. Building URLs and API Endpoints

base_url = "https://api.github.com"
username = "hugow0528"
page = 2
per_page = 10

url = f"{base_url}/users/{username}/repos"
url = f"{url}?page={page}&per_page={per_page}"

print(url)
# https://api.github.com/users/hugow0528/repos?page=2&per_page=10

# Or build it all in one f-string:
url = f"{base_url}/users/{username}/repos?page={page}&per_page={per_page}"

5. Tabular Data Output

products = [
    ("Laptop", 999.99, 15),
    ("Mouse", 29.99, 150),
    ("Keyboard", 79.99, 45),
    ("Monitor", 449.99, 30),
]

# Header
print(f"{'Product':<12} {'Price':>8} {'Stock':>6} {'Value':>12}")
print("-" * 40)

# Data rows
for name, price, stock in products:
    print(f"{name:<12} ${price:>7.2f} {stock:>6} ${price * stock:>11.2f}")

# Output:
# Product      Price  Stock        Value
# ----------------------------------------
# Laptop      $999.99     15    $14999.85
# Mouse        $29.99    150     $4498.50
# Keyboard     $79.99     45     $3599.55
# Monitor     $449.99     30    $13499.70

Common Gotchas and Best Practices

Backslashes Inside f-Strings

You cannot use backslash escapes directly inside the curly braces of an f-string. This is a common mistake:

# ❌ This will cause a SyntaxError
# f"The path is {path.replace('\\', '/')}"

Instead, do the escaping outside the braces or store it in a variable first:

path = "C:\\new\\test"
separator = "/"
print(f"The path is {path.replace('\\\\', separator)}")  # Works!

Quoting Inside f-Strings

If your f-string uses double quotes, you can use single quotes inside (and vice versa):

name = "Hugo"
# Use single quotes inside double-quoted f-string
print(f'{name} said "Hello!"')

# Or use triple quotes for maximum flexibility
msg = f"""{name}'s config:
{{"name": "{name}", "role": "admin"}}"""

Escaping Literal Curly Braces

Double the braces to include literal { or } in your string:

price = 99.99
print(f"The cost is {{${price}}} USD")  # The cost is {$99.99} USD

# Useful for JSON-like output:
name = "Hugo"
print(f'{{"name": "{name}", "active": true}}')
# {"name": "Hugo", "active": true}

When NOT to Use f-Strings

f-strings are evaluated at runtime, so they're not ideal for a few cases:

  • Internationalization (i18n): Use %s or .format() so translation tools can extract the template string at build time
  • Dictionary keys: "{key}".format_map(mapping) or % (mapping,) can be cleaner when all values come from the same dict
  • Repeated formatting: If you format the same template with different values, use a string.Template or compile a format string once: fmt = "Hello, {}!".format

Summary

f-strings are Python's best string formatting tool. They combine speed, readability, and expressiveness in a single feature. The key takeaways:

  1. Always use f"..." for string interpolation in Python 3.6+
  2. Use {:.2f} for decimals, {:,} for commas, {:.1%} for percentages
  3. Use {var=} in Python 3.8+ for quick debugging
  4. Double braces {{}} to include literal curly braces
  5. Use !s and !r to control string representation
  6. Avoid backslashes inside the curly braces

Start using f-strings everywhere, and you'll write cleaner, faster Python from day one.
