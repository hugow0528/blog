What Are JSON and CSV?

Data files are everywhere. APIs return JSON. Spreadsheets export as CSV. Configuration files use JSON. Logs are often CSV. As a Python developer, you'll need to read and write these formats daily.

JSON (JavaScript Object Notation) stores data as key-value pairs, lists, and nested structures. It's human-readable and the standard format for web APIs.

CSV (Comma-Separated Values) stores tabular data — rows and columns — with commas between values. It's the universal format for spreadsheets and databases.

Python makes both incredibly easy to work with using built-in modules — no external libraries required. Let's start with JSON.

JSON Basics

JSON maps to Python data types as follows:

JSON          → Python
object        → dict
array         → list
string        → str
number        → int or float
true/false    → True/False
null          → None

Python's built-in json module handles all conversions automatically. You just need to know two pairs of functions:

  • json.load() / json.dump() — work with files
  • json.loads() / json.dumps() — work with strings

Reading JSON Files

Let's create a sample data file and read it. Suppose we have a file called users.json:

{
    "users": [
        {"id": 1, "name": "Alice", "email": "alice@example.com"},
        {"id": 2, "name": "Bob", "email": "bob@example.com"},
        {"id": 3, "name": "Charlie", "email": "charlie@example.com"}
    ]
}

Here's how to read and process this file:

import json

# Read the entire JSON file into a Python dictionary
with open("users.json", "r") as f:
    data = json.load(f)

# Access the data
users = data["users"]
print(f"Total users: {len(users)}")

# Iterate through users
for user in users:
    print(f"User {user['id']}: {user['name']} <{user['email']}>")

# Find a specific user
alice = next((u for u in users if u["name"] == "Alice"), None)
if alice:
    print(f"Found Alice! Email: {alice['email']}")

Output:

Total users: 3
User 1: Alice <alice@example.com>
User 2: Bob <bob@example.com>
User 3: Charlie <charlie@example.com>
Found Alice! Email: alice@example.com

Notice we use json.load(f) with the file object, not json.loads(). The "s" in loads means "string" — use it when parsing JSON from a string instead of a file.

Here's the string version, useful for API responses:

import json

# Parse JSON from a string (e.g., API response)
json_string = '{"status": "ok", "count": 42}'
data = json.loads(json_string)

print(data["status"])   # ok
print(data["count"])    # 42

Writing JSON Files

Writing JSON is equally simple. Use json.dump() to write to a file or json.dumps() to create a string:

import json

# Create data to save
config = {
    "app_name": "MyApp",
    "version": "1.0.0",
    "debug": False,
    "database": {
        "host": "localhost",
        "port": 5432,
        "name": "mydb"
    },
    "features": ["auth", "logging", "cache"]
}

# Write to file with pretty formatting
with open("config.json", "w") as f:
    json.dump(config, f, indent=4)

# Or create a string
json_string = json.dumps(config, indent=4, sort_keys=True)
print(json_string)

Output (pretty-printed JSON):

{
    "app_name": "MyApp",
    "database": {
        "host": "localhost",
        "name": "mydb",
        "port": 5432
    },
    "debug": false,
    "features": [
        "auth",
        "logging",
        "cache"
    ],
    "version": "1.0.0"
}

The indent=4 parameter makes the output human-readable. Use sort_keys=True to alphabetize keys. For compact output (e.g., API responses), omit the indent parameter entirely.

Appending to JSON arrays: JSON files can't be appended like text. You need to read, modify, and rewrite:

import json

# Read existing data
with open("users.json", "r") as f:
    data = json.load(f)

# Add a new user
data["users"].append({
    "id": 4,
    "name": "Diana",
    "email": "diana@example.com"
})

# Write back
with open("users.json", "w") as f:
    json.dump(data, f, indent=4)

JSON Error Handling

JSON files can be malformed. Always handle errors gracefully:

import json

def read_json(filepath):
    """Safely read a JSON file with error handling."""
    try:
        with open(filepath, "r") as f:
            return json.load(f)
    except FileNotFoundError:
        print(f"Error: File '{filepath}' not found.")
        return None
    except json.JSONDecodeError as e:
        print(f"Error: Invalid JSON in '{filepath}': {e}")
        return None
    except PermissionError:
        print(f"Error: Cannot read '{filepath}' — permission denied.")
        return None

# Test with a bad file
data = read_json("bad.json")
if data:
    print("Loaded successfully!")

The three main errors to catch are FileNotFoundError (file doesn't exist), json.JSONDecodeError (invalid JSON format), and PermissionError (can't read the file).

CSV Basics

CSV files look like this:

id,name,email,role
1,Alice,alice@example.com,admin
2,Bob,bob@example.com,user
3,Charlie,charlie@example.com,user

Each line is a row. Each comma separates a column. The first row is typically the header. Python's built-in csv module handles all the parsing.

Reading CSV Files

Use csv.reader for simple row-by-row access:

import csv

# Read CSV with csv.reader
with open("users.csv", "r") as f:
    reader = csv.reader(f)
    
    # Get header row
    headers = next(reader)
    print(f"Columns: {headers}")
    
    # Read all rows
    for row in reader:
        print(f"ID={row[0]}, Name={row[1]}, Role={row[3]}")

Output:

Columns: ['id', 'name', 'email', 'role']
ID=1, Name=Alice, Role=admin
ID=2, Name=Bob, Role=user
ID=3, Name=Charlie, Role=user

Calling next(reader) gets the first row (the header). After that, iterating over reader gives you each subsequent row as a list. Access columns by index.

Writing CSV Files

Use csv.writer to create CSV files:

import csv

# Data to write
headers = ["id", "name", "email", "role"]
rows = [
    [1, "Alice", "alice@example.com", "admin"],
    [2, "Bob", "bob@example.com", "user"],
    [3, "Charlie", "charlie@example.com", "moderator"],
]

# Write to CSV
with open("output.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(headers)   # Write header row
    writer.writerows(rows)     # Write all data rows

print("CSV file created!")

Output (output.csv):

id,name,email,role
1,Alice,alice@example.com,admin
2,Bob,bob@example.com,user
3,Charlie,charlie@example.com,moderator

Important: always use newline="" when opening files for CSV writing. Without it, you'll get blank lines between rows on Windows.

CSV with DictReader and DictWriter

Instead of accessing columns by index, use csv.DictReader and csv.DictWriter to work with dictionaries:

import csv

# --- Reading with DictReader ---
with open("users.csv", "r") as f:
    reader = csv.DictReader(f)
    for row in reader:
        # Each row is a dict: {'id': '1', 'name': 'Alice', ...}
        print(f"{row['name']} is a {row['role']}")

# --- Writing with DictWriter ---
data = [
    {"id": 1, "name": "Alice", "email": "alice@example.com", "role": "admin"},
    {"id": 2, "name": "Bob", "email": "bob@example.com", "role": "user"},
]

with open("output2.csv", "w", newline="") as f:
    fieldnames = ["id", "name", "email", "role"]
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()       # Write header from fieldnames
    writer.writerows(data)     # Write all rows as dicts

DictReader/DictWriter are much cleaner when you care about column names rather than positions. They're the preferred approach for most real-world code.

Handling Special Characters in CSV

CSV can get tricky with commas inside data, quotes, and line breaks. Python's csv module handles most cases automatically:

import csv

# Data with tricky characters
data = [
    ["id", "name", "bio"],
    [1, 'Alice "The Coder"', "Loves Python, JavaScript"],
    [2, "Bob Smith", "Works at Google, San Francisco"],
    [3, "Charlie\nBrown", "Line breaks in bio"],
]

with open("special.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(data)

# Read it back — everything is preserved correctly
with open("special.csv", "r") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(f"Name: {row['name']}, Bio: {row['bio']}")

The csv module automatically quotes fields containing commas, quotes, and newlines. Never try to parse CSV with str.split(",") — it breaks on these cases.

Real-World: Convert JSON to CSV

Let's build a practical tool — a JSON-to-CSV converter. This is a common task when you get structured API data and need to analyze it in a spreadsheet:

import json
import csv

def json_to_csv(json_path, csv_path):
    """Convert a JSON array of objects to a CSV file."""
    # Read JSON
    with open(json_path, "r") as f:
        data = json.load(f)
    
    # Handle both array format and wrapped format
    if isinstance(data, dict):
        # e.g., {"users": [...]}
        for key, value in data.items():
            if isinstance(value, list):
                data = value
                break
        else:
            raise ValueError("No array found in JSON object")
    
    if not data:
        print("Empty dataset!")
        return
    
    # Get headers from the first record
    fieldnames = list(data[0].keys())
    
    # Write CSV
    with open(csv_path, "w", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(data)
    
    print(f"Converted {len(data)} records to {csv_path}")

# Usage
json_to_csv("users.json", "users_converted.csv")

This function handles both [...] (raw array) and {"key": [...]} (wrapped) JSON formats. It reads all records, extracts headers from the first record's keys, and writes a clean CSV.

Bonus: Reverse Conversion (CSV to JSON)

import csv
import json

def csv_to_json(csv_path, json_path):
    """Convert a CSV file to a JSON array of objects."""
    records = []
    
    with open(csv_path, "r") as f:
        reader = csv.DictReader(f)
        for row in reader:
            # Try to convert numeric strings to numbers
            for key, value in row.items():
                try:
                    row[key] = int(value)
                except ValueError:
                    try:
                        row[key] = float(value)
                    except ValueError:
                        pass  # Keep as string
            records.append(row)
    
    with open(json_path, "w") as f:
        json.dump(records, f, indent=2)
    
    print(f"Converted {len(records)} records to {json_path}")

# Usage
csv_to_json("users_converted.csv", "users_back_to_json.json")

The csv_to_json function also attempts to convert string numbers back to integers and floats — so "42" becomes 42 in the JSON output.

Best Practices

  1. Always use context managers (with) — they automatically close files even if an error occurs.
  2. Use json.dumps() for API responses and json.dump() for files.
  3. Use csv.DictReader over csv.reader when you have column headers — it's much more readable.
  4. Always specify newline="" when opening files for CSV writing to avoid blank lines.
  5. Handle errors gracefully — JSON can be malformed, files can be missing, and permissions can fail.
  6. Use indent for readable JSON in config files, but omit it for API responses to save bandwidth.
  7. For large files, process line by line instead of loading everything into memory.

Summary

JSON and CSV are the two most common data formats you'll encounter as a Python developer. The built-in json and csv modules make working with them straightforward:

  • json.load() / json.dump() for file-based JSON
  • json.loads() / json.dumps() for string-based JSON
  • csv.reader / csv.writer for simple CSV access
  • csv.DictReader / csv.DictWriter for dictionary-based CSV access

Start with these tools, add error handling for production code, and you'll be ready for any data processing task.
