Cloudflare Stream: Video Upload, Transcoding & Streaming Made Easy

Cloudflare Python 2026-06-27 10 min read

Video hosting is hard. You need storage, transcoding pipelines, CDN delivery, adaptive bitrate streaming, and analytics. Cloudflare Stream handles all of that — upload a video file and get back a ready-to-play streaming URL with automatic quality optimization, thumbnails, and DRM support.

In this guide, you'll learn how to upload videos, embed players, manage uploads programmatically with Python, and set up a complete video streaming pipeline.

What Is Cloudflare Stream?

Cloudflare Stream is a fully managed video service that sits on top of Cloudflare's global network. When you upload a video, Stream:

  • Transcodes it into multiple resolutions (480p, 720p, 1080p)
  • Generates thumbnails and poster images automatically
  • Delivers via HTTP Live Streaming (HLS) from 300+ edge locations
  • Provides an embeddable HTML5 player with built-in controls
  • Tracks viewership analytics — when, where, and for how long

Think of it as the "Cloudflare Pages for video" — you upload, and Stream handles the rest.

Pricing Overview

Stream uses a pay-per-minute model:

  • $0.006 per stored minute (storage)
  • $0.02 per streaming minute (viewing)

For 1,000 viewers watching a 10-minute video, that's roughly $200 for viewing and $0.06 for storage. Compare that to self-hosting with S3 + transcoding infrastructure, and the math gets compelling fast.

Step 1: Upload Your First Video

You can upload via the Cloudflare dashboard or programmatically. Let's start with the dashboard:

  1. Go to dash.cloudflare.com → Stream → Video Uploads
  2. Click "Upload Video" and select your file
  3. Wait for transcoding (usually seconds for short videos)
  4. Copy the Video UUID — you'll need this for embedding

Step 2: Embed the Video Player

Cloudflare provides a drop-in player. Add this to any HTML page:

<!-- Basic embed -->
<video id="my-video" controls>
    <source src="https://stream.video.cloudflare.com/YOUR_UUID.m3u8" type="application/x-mpegURL">
    Your browser doesn't support video.
</video>

<!-- Using the official Stream player -->
<script src="https://embed.cloudflarestream.com/YOUR_UUID">
</script>

<!-- With custom dimensions -->
<div class="stream-player" style="max-width: 640px;">
    <script src="https://embed.cloudflarestream.com/YOUR_UUID">
    </script>
</div>

Step 3: Upload Videos with Python

The manual dashboard works for a few videos, but what about building a video platform? Cloudflare Stream has an API, and we can drive it entirely from Python.

Install the SDK:

pip install cloudflare

Upload a video programmatically:

import os
from cloudflare import Cloudflare

# Initialize with API token (has Stream permissions)
cf = Cloudflare.from_tokens(os.environ["CLOUDFLARE_API_TOKEN"])

# Upload from a file path
response = cf.stream.videos.post(
    file=open("my_video.mp4", "rb"),
    metadata={"title": "My First Stream", "tags": ["tutorial", "python"]}
)

video_id = response.result.uuid
print(f"✅ Video uploaded! UUID: {video_id}")
print(f"🎬 Embed URL: https://cloudflarestream.com/{video_id}/iframe")
print(f"📊 Thumbnail: https://cloudflarestream.com/{video_id}/thumbnail.jpg")
print(f"🔗 Direct HLS: https://cloudflarestream.com/{video_id}/manifest/video.m3u8")

# Check upload progress
status = cf.stream.videos.get(video_id)
print(f"Status: {status.result.status}")
print(f"Duration: {status.result.duration}s")

Step 4: Create a Custom Upload Page

Let's build a simple Flask app where users can upload videos through a web form:

# pip install flask cloudflare
from flask import Flask, request, jsonify, render_template_string
from cloudflare import Cloudflare
import os

app = Flask(__name__)
cf = Cloudflare.from_tokens(os.environ["CLOUDFLARE_API_TOKEN"])

UPLOAD_HTML = '''
<html>
<head><title>Upload Video</title>
    <style>
        body { font-family: system-ui; max-width: 600px; margin: 40px auto; padding: 0 20px; }
        input[type="file"] { margin: 10px 0; }
        button { background: #f38020; color: white; border: none; padding: 10px 20px;
                 border-radius: 4px; cursor: pointer; font-size: 16px; }
        .result { margin-top: 20px; padding: 15px; background: #f5f5f5; border-radius: 8px; }
    </style>
</head>
<body>
    <h1>🎥 Upload to Cloudflare Stream</h1>
    <form method="post" enctype="multipart/form-data">
        <input type="file" name="video" accept="video/*" required>
        <br>
        <input type="text" name="title" placeholder="Video title" required>
        <br><br>
        <button type="submit">Upload Video</button>
    </form>
    {% if video_id %}
    <div class="result">
        <p>✅ Uploaded! UUID: {{ video_id }}</p>
        <video controls width="100%">
            <source src="https://cloudflarestream.com/{{ video_id }}/manifest/video.m3u8"
                    type="application/x-mpegURL">
        </video>
        <p><a href="/play/{{ video_id }}">Open player page</a></p>
    </div>
    {% endif %}
</body>
</html>
'''

@app.route("/", methods=["GET", "POST"])
def upload():
    if request.method == "POST":
        video_file = request.files["video"]
        title = request.form["title"]

        response = cf.stream.videos.post(
            file=video_file.read(),
            metadata={"title": title}
        )

        return render_template_string(
            UPLOAD_HTML, video_id=response.result.uuid
        )

    return render_template_string(UPLOAD_HTML, video_id=None)

@app.route("/play/<video_id>")
def play(video_id):
    return f'''
    <html>
    <head><title>Watch</title></head>
    <body style="max-width:800px;margin:40px auto">
        <h1>Playing video</h1>
        <div style="position:relative;padding-bottom:56.25%">
            <iframe src="https://cloudflarestream.com/{video_id}/iframe"
                    style="position:absolute;width:100%;height:100%;border:0">
            </iframe>
        </div>
        <p><a href="/">← Upload another</a></p>
    </body>
    </html>
    '''

if __name__ == "__main__":
    app.run(debug=True)

Step 5: Manage Videos via API

Stream's API lets you list, update, and delete videos:

# List all videos
videos = cf.stream.videos.get()
for v in videos.result:
    print(f"  {v.uuid} - {v.metadata.get('title', 'Untitled')} - {v.duration}s")

# Update video metadata
cf.stream.videos.patch(
    video_id,
    metadata={"title": "Updated Title", "description": "A longer description"}
)

# Delete a video
cf.stream.videos.delete(video_id)
print(f"🗑️ Deleted {video_id}")

Step 6: Streaming Analytics

Cloudflare provides viewership data so you know what's being watched:

from datetime import datetime, timedelta

# Get viewership for the last 7 days
end_time = datetime.utcnow()
start_time = end_time - timedelta(days=7)

analytics = cf.stream.analytics.get(
    video_id=video_id,
    filter=f"first_timestamp_gte:{start_time.isoformat()}"
)

total_views = analytics.result.viewership
print(f"📊 Total viewers: {total_views}")
print(f"📈 Total minutes watched: {analytics.result.minutes}")

# Get per-minute viewership curve
for point in analytics.result.minutes:
    print(f"  {point['timestamp']}: {point['value']} viewers")

Direct Upload: Let Users Upload Without Your Server

For large-scale apps, you can let the client upload directly to Cloudflare, bypassing your server entirely. This saves bandwidth and reduces server costs:

# Step 1: Create a direct upload token on your server
token_response = cf.stream.direct_upload.post(
    filename="user_video.mp4",
    metadata={"title": "User Upload", "uploaded_by": "user123"}
)

upload_url = token_response.result.url
upload_id = token_response.result.upload_id
print(f"Direct upload URL: {upload_url}")

# Step 2: Client uploads directly via curl or fetch
# curl -X PUT "{upload_url}" --data-binary @user_video.mp4

Security & Access Control

By default, any user with the video URL can watch it. To protect content, use signed URLs:

# Generate a token that expires in 1 hour
import time
import hashlib
import hmac
import base64

def generate_signed_url(video_id, secret_key, expires_in=3600):
    """Generate a time-limited signed URL for a video."""
    expiry = int(time.time()) + expires_in
    path = f"/{video_id}/manifest/video.m3u8"

    signature = hmac.new(
        secret_key.encode(),
        f"{path}:{expiry}".encode(),
        hashlib.sha256
    ).hexdigest()

    return (
        f"https://cloudflarestream.com{path}"
        f"?expiry={expiry}&signature={signature}"
    )

# Usage
url = generate_signed_url(video_id, "your-secret-key")
print(f"Protected URL: {url}")

Cloudflare Stream removes the complexity from video hosting. Key takeaways:

  • Upload a video → get a streaming URL. No infrastructure to manage.
  • Automatic transcoding into multiple quality levels.
  • Delivered from 300+ edge locations worldwide.
  • Python SDK makes programmatic uploads straightforward.
  • Direct upload feature lets clients upload without your server.
  • Built-in analytics tell you exactly how your content performs.
  • Pay only for what you store and what gets watched.

Whether you're building a course platform, a social video app, or just need to share presentations, Cloudflare Stream handles the heavy lifting so you can focus on your product.
