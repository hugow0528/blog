Python Async/Await: Asynchronous Programming — Complete Beginner's Guide

July 11, 2026 11 min read

Asynchronous programming in Python lets you do multiple things at once without needing multiple threads or processes. When you're waiting for a network request, a file to load, or a database query to complete, async code lets your program keep working on other tasks instead of sitting idle. This guide takes you from the basic syntax to building a real async application.

Why Async Matters

Imagine you're ordering food from three different restaurants by phone. A synchronous approach means you call one restaurant, wait for the answer, hang up, then call the next. An async approach means you place all three orders and then check back on each as they're ready.

In Python, synchronous code blocks — it waits for each operation to finish before moving on. Async code uses an event loop that switches between tasks whenever one of them is waiting for I/O (input/output).

The Basics: async def and await

Every async program in Python starts with two keywords:

  • async def — declares an async function (called a coroutine)
  • await — pauses the function until an async operation completes
import asyncio

async def say_hello(name):
    print(f"Hello, {name}!")
    await asyncio.sleep(1)  # Simulate waiting 1 second
    print(f"Goodbye, {name}!")

# Run the async function
asyncio.run(say_hello("Alice"))

Output:

Hello, Alice!
Goodbye, Alice!

The key insight: await asyncio.sleep(1) pauses this function for 1 second, but during that pause the event loop can run other coroutines. That's the magic.

Running Tasks Concurrently

To actually benefit from async, you need to run multiple coroutines at the same time. Use asyncio.gather():

import asyncio

async def fetch_data(name, delay):
    print(f"Starting fetch: {name}")
    await asyncio.sleep(delay)  # Simulate network delay
    print(f"Finished fetch: {name}")
    return f"Data from {name}"

async def main():
    # Run all three concurrently
    results = await asyncio.gather(
        fetch_data("API-A", 2),
        fetch_data("API-B", 1),
        fetch_data("API-C", 3),
    )
    print("All results:", results)

asyncio.run(main())

Output:

Starting fetch: API-A
Starting fetch: API-B
Starting fetch: API-C
Finished fetch: API-B
Finished fetch: API-A
Finished fetch: API-C
All results: ['Data from API-A', 'Data from API-B', 'Data from API-C']

Notice that all three tasks started immediately and the total time is ~3 seconds (the longest task), not 6 seconds (the sum). This is the power of async.

Async HTTP Requests with aiohttp

The standard requests library is synchronous. For async, use aiohttp:

pip install aiohttp
import aiohttp
import asyncio

async def fetch_url(session, url):
    async with session.get(url) as response:
        data = await response.json()
        return data

async def main():
    urls = [
        "https://jsonplaceholder.typicode.com/posts/1",
        "https://jsonplaceholder.typicode.com/posts/2",
        "https://jsonplaceholder.typicode.com/posts/3",
    ]

    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        results = await asyncio.gather(*tasks)
        for post in results:
            print(post["title"][:50])

asyncio.run(main())

We create a single ClientSession and reuse it across all requests — this is more efficient and reuses connections. All three API calls run concurrently.

Async File I/O

For file operations, Python 3.10+ includes asyncio.to_thread() to run blocking code without freezing the event loop:

import asyncio

async def read_file_async(filepath):
    # Run the blocking open() in a separate thread
    loop = asyncio.get_event_loop()
    content = await loop.run_in_executor(None, lambda: open(filepath).read())
    return content

async def write_file_async(filepath, data):
    loop = asyncio.get_event_loop()
    await loop.run_in_executor(None, lambda: open(filepath, "w").write(data))

Or use the aiodns / aiofiles libraries for truly async file operations:

pip install aiofiles
import aiofiles

async def read_file(path):
    async with aiofiles.open(path, mode="r") as f:
        content = await f.read()
    return content

async def write_file(path, data):
    async with aiofiles.open(path, mode="w") as f:
        await f.write(data)

Building an Async Web Scraper

Let's combine everything into a practical project — an async scraper that fetches multiple pages simultaneously:

import asyncio
import aiohttp
from bs4 import BeautifulSoup

async def scrape_page(session, url):
    """Fetch and parse a single page"""
    try:
        async with session.get(url, timeout=aiohttp.ClientTimeout(10)) as resp:
            if resp.status == 200:
                html = await resp.text()
                soup = BeautifulSoup(html, "html.parser")
                title = soup.title.string if soup.title else "No title"
                links = [a["href"] for a in soup.find_all("a", href=True)]
                return {"url": url, "title": title, "links": len(links)}
    except Exception as e:
        return {"url": url, "error": str(e)}
    return None

async def main():
    urls = [
        "https://python.org",
        "https://docs.python.org",
        "https://pypi.org",
        "https://realpython.com",
        "https://dev.to",
    ]

    async with aiohttp.ClientSession() as session:
        tasks = [scrape_page(session, url) for url in urls]
        results = await asyncio.gather(*tasks)

    for result in results:
        if result and "error" not in result:
            print(f"✅ {result['title']} — {result['links']} links")
        elif result:
            print(f"❌ {result['url']}: {result['error']}")

asyncio.run(main())

This scraper processes 5 URLs concurrently in the time it takes to fetch the slowest one, instead of sequentially taking 5× as long.

Common Async Patterns

asyncio.create_task() — Fire and Forget

async def background_task():
    print("Running in background...")
    await asyncio.sleep(2)
    print("Background task done!")

async def main():
    task = asyncio.create_task(background_task())
    print("Main continues immediately")
    await asyncio.sleep(1)
    print("Main still going...")
    await task  # Wait for background task

asyncio.run(main())

asyncio.wait_for() — Timeout Protection

async def slow_task():
    await asyncio.sleep(10)
    return "done"

async def main():
    try:
        result = await asyncio.wait_for(slow_task(), timeout=2)
    except asyncio.TimeoutError:
        print("Task timed out!")

asyncio.run(main())
# Output: Task timed out!

asyncio.as_completed() — Process Results as They Finish

async def main():
    tasks = [fetch_data("API-A", 3), fetch_data("API-B", 1), fetch_data("API-C", 2)]
    for future in asyncio.as_completed(tasks):
        result = await future
        print(f"Got: {result}")  # Prints B first, then C, then A

asyncio.run(main())

When NOT to Use Async

Async is great for I/O-bound tasks (network, file, database), but not for CPU-bound work:

  • Heavy computation (math, image processing) — use multiprocessing instead
  • Simple scripts — don't add async complexity when sync works fine
  • Blocking libraries — if a library isn't async-compatible, it will freeze the event loop

Async with FastAPI

FastAPI is built on async. Here's how you write an async endpoint:

pip install fastapi uvicorn
from fastapi import FastAPI
import asyncio

app = FastAPI()

@app.get("/slow")
async def slow_endpoint():
    await asyncio.sleep(2)  # Non-blocking delay
    return {"message": "Ready!"}

@app.get("/quick")
async def quick_endpoint():
    return {"message": "Fast!"}

# Run with: uvicorn main:app --reload

The key advantage: when /slow is being requested, the server can still handle /quick requests — they run concurrently.

Summary

Python async/await gives you a powerful way to handle concurrent I/O operations:

  • async def + await define and call async functions
  • asyncio.run() starts the event loop
  • asyncio.gather() runs multiple coroutines concurrently
  • aiohttp provides async HTTP client functionality
  • Use async for I/O-bound tasks, not CPU-bound work
  • FastAPI and many modern frameworks are async-native

Start with simple asyncio.gather() calls for concurrent API requests, and gradually adopt async patterns as your projects grow in complexity.
