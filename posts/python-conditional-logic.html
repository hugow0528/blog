Python Conditional Logic: if/elif/else — Make Decisions in Code

2026-06-26 10 min read New

Every useful program needs to make decisions. Should a user be logged in? Is this number positive or negative? Does this file exist? In Python, conditional logic answers these questions using if, elif, and else. This guide takes you from basic comparisons to real-world decision-making patterns.

The if Statement

The simplest conditional — check one condition and act if it's True:

temperature = 35

if temperature > 30:
    print("It's hot outside! 🌡️")

# Output: It's hot outside! 🌡️

Key things to notice:

  • The condition temperature > 30 evaluates to True or False
  • The colon : after the condition is REQUIRED — Python uses it to mark a new block
  • The indented lines below are the "body" — they only run if the condition is true
  • Python uses 4 spaces of indentation (not braces or parentheses)

if/else: Two Choices

Add else for a fallback when the condition is False:

age = 16

if age >= 18:
    print("You can vote! 🗳️")
else:
    print("You need to wait a bit.")

# Output: You need to wait a bit.

Exactly one branch runs — never both, never neither. The else catches every case the if didn't.

if/elif/else: Multiple Choices

When you have more than two options, use elif (short for "else if"):

score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Score: {score} → Grade: {grade}")

# Output: Score: 85 → Grade: B

How it works: Python checks each condition in order, top to bottom. The FIRST one that's true wins, and the rest are skipped entirely. This means the order matters — score >= 90 must come before score >= 80, because a score of 95 satisfies both. If the 80-check came first, every A-score would incorrectly become a B.

Comparison Operators

Conditions use comparison operators to produce True or False:

Operator Meaning Example Result
== Equal to 5 == 5 True
!= Not equal to 5 != 3 True
> Greater than 10 > 5 True
< Less than 3 < 7 True
>= Greater or equal 5 >= 5 True
<= Less or equal 3 <= 2 False

Common mistake: Use == to compare values, not =. A single = assigns a value:

x = 5    # ✅ Assigns 5 to x
if x == 5:  # ✅ Compares x to 5
    print("x is five!")

if x = 5:   # ❌ SyntaxError! Single = is assignment

Boolean Operators: and, or, not

Combine conditions with and, or, and not:

age = 25
has_license = True

# Both must be true
if age >= 18 and has_license:
    print("You can drive! 🚗")

# Only one needs to be true
is_weekend = False
is_holiday = True
if is_weekend or is_holiday:
    print("Day off! 🎉")

# Reverses True/False
if not has_license:
    print("Get your license first.")
else:
    print("All good!")

# Output: You can drive! 🚗
#         Day off! 🎉
#         All good!

Truth tables:

a b a and b a or b not a
TrueTrueTrueTrueFalse
TrueFalseFalseTrueFalse
FalseTrueFalseTrueTrue
FalseFalseFalseFalseTrue

Truthy and Falsy Values

In Python, you don't always need == True. Many values are "truthy" or "falsy" by default:

# These are ALL FALSY (evaluate to False in conditions):
False
None
0
0.0
""          # empty string
[]          # empty list
{}          # empty dict
set()       # empty set

# Everything else is TRUTHY:
True
1
-1
"hello"
[1, 2]
{"name": "Hugo"}

This lets you write clean checks:

name = input("Enter your name: ")

# Instead of: if name != "":
if name:
    print(f"Hello, {name}!")
else:
    print("You didn't enter a name.")

# Checking if a list has items
items = []
if not items:
    print("The cart is empty.")  # Simpler than: if len(items) == 0

The "in" Operator

Check membership in a string, list, tuple, or dictionary:

# Strings
email = "user@example.com"
if "@" in email and "." in email:
    print("Looks like a valid email!")

# Lists
fruits = ["apple", "banana", "cherry"]
if "banana" in fruits:
    print("We have bananas! 🍌")

# Dictionaries (checks keys)
user = {"name": "Hugo", "role": "admin"}
if "role" in user:
    print(f"User role: {user['role']}")

# Negation
if "banana" not in fruits:
    print("No bananas today.")

Real-World Example: User Login Validator

Let's combine everything into a practical function:

def validate_login(username, password):
    """Check if login credentials are valid."""
    
    # Check for empty inputs
    if not username or not password:
        return "Error: Username and password are required."
    
    # Check minimum length
    if len(password) < 8:
        return "Error: Password must be at least 8 characters."
    
    # Check for strong password
    has_upper = any(c.isupper() for c in password)
    has_digit = any(c.isdigit() for c in password)
    has_special = any(not c.isalnum() for c in password)
    
    if not (has_upper and has_digit and has_special):
        return "Error: Password needs uppercase, digit, and special character."
    
    # Simulated database check
    valid_users = {
        "admin": "Admin@123!",
        "user": "User!2024x"
    }
    
    if username in valid_users and valid_users[username] == password:
        return f"Welcome back, {username}! ✅"
    else:
        return "Error: Invalid username or password."

# Test it
print(validate_login("admin", "Admin@123!"))
# Welcome back, admin! ✅

print(validate_login("admin", "weak"))
# Error: Password must be at least 8 characters.

print(validate_login("", "Admin@123!"))
# Error: Username and password are required.

The Ternary Operator (One-Line if/else)

For simple conditions, Python has a one-liner:

# Standard if/else:
if age >= 18:
    status = "adult"
else:
    status = "minor"

# Ternary equivalent:
status = "adult" if age >= 18 else "minor"

The pattern is: value_if_true if condition else value_if_false. Use it for simple assignments — don't cram complex logic into one line:

price = 100
discount = 0.2 if price > 50 else 0  # ✅ Clean
final_price = price * (1 - discount)

# ❌ Don't do this:
result = "too long and confusing" if condition1 and condition2 else "still confusing" if condition3 else "unreadable"

match/case: Python's Switch Statement

Python 3.10+ introduced structural pattern matching — Python's version of a switch statement:

role = "admin"

match role:
    case "admin":
        print("Full system access granted 🔑")
    case "editor":
        print("Can edit and publish content ✏️")
    case "viewer":
        print("Read-only access 👀")
    case _:
        print("Unknown role — please contact support")

The case _: is the "catch-all" — equivalent to else in if/elif chains. Use match/case when checking a single variable against many specific values. Use if/elif when you need complex conditions with and/or.

Real-World Example: Discount Calculator

def calculate_discount(price, is_member, has_coupon, season=""):
    """Calculate final price with layered discounts."""
    
    discount = 0
    
    # Member discount: 10%
    if is_member:
        discount += 0.10
    
    # Coupon discount: 15%
    if has_coupon:
        discount += 0.15
    
    # Seasonal bonus using match/case
    match season:
        case "black_friday":
            discount += 0.25
        case "christmas":
            discount += 0.15
        case "new_year":
            discount += 0.10
        case "":
            pass  # No seasonal discount
        case _:
            print(f"Warning: Unknown season '{season}'")
    
    # Cap discount at 50%
    discount = min(discount, 0.50)
    
    final_price = price * (1 - discount)
    
    print(f"Original: ${price:.2f}")
    print(f"Discount: {discount:.0%}")
    print(f"Final price: ${final_price:.2f}")
    
    return final_price

# Test scenarios
calculate_discount(200, True, True, "black_friday")
# Original: $200.00
# Discount: 50%
# Final price: $100.00

calculate_discount(50, False, False, "")
# Original: $50.00
# Discount: 0%
# Final price: $50.00

Common Pitfalls to Avoid

1. Using = instead of ==

if x = 5:    # ❌ SyntaxError: assignment in condition
if x == 5:   # ✅ Correct comparison

2. Wrong indentation

if x > 0:
print("positive")   # ❌ IndentationError
if x > 0:
    print("positive")  # ✅ Properly indented

3. Comparing floating-point equality

0.1 + 0.2 == 0.3    # ❌ False! Floating-point imprecision

# Use math.isclose() instead:
import math
math.isclose(0.1 + 0.2, 0.3)   # ✅ True

4. Forgetting that order matters in elif chains

# This always returns "passing" for any score >= 60:
if score >= 60:
    grade = "passing"   # Checks first — catches everything >= 60
elif score >= 90:
    grade = "A"         # Never reached for scores >= 60

# Fix: check more specific conditions first
if score >= 90:
    grade = "A"
elif score >= 60:
    grade = "passing"

Summary

Conditional logic is the decision-making engine of every Python program. The core pattern:

if condition_1:
    # runs when condition_1 is True
elif condition_2:
    # runs when condition_1 is False AND condition_2 is True
else:
    # runs when neither condition is True

Key takeaways:

  1. Use == for comparison, = for assignment
  2. Combine conditions with and, or, not
  3. Leverage truthy/falsy for cleaner empty checks
  4. Use in for membership testing
  5. Ternary operator for simple one-line assignments
  6. match/case for multi-value checks (Python 3.10+)
  7. Always put the most specific conditions FIRST in elif chains

Practice by writing small functions — a grading system, a discount calculator, an input validator. Each one reinforces how conditions chain together to handle real-world logic.
