Cloudflare Workers AI: Run Machine Learning Models at the Edge

July 5, 2026 11 min read

Cloudflare Workers AI lets you run machine learning inference on Cloudflare's global edge network. No GPUs to provision, no model servers to maintain — just call an API from a Worker and get results in milliseconds from a data center near your user. The free tier includes 10,000 requests per day, which is enough to prototype and even run small production workloads.

How Workers AI Works

Instead of deploying a model to your own server, Cloudflare hosts the models on their edge infrastructure. You send input data, get predictions back. The models run on specialized hardware distributed across 300+ cities worldwide.

Supported tasks include:

  • Text generation — LLMs like Llama, Mistral, and Aya
  • Text embeddings — Convert text to vectors for search
  • Image classification — Label images with pretrained models
  • Object detection — Find and locate objects in images
  • Text-to-image — Generate images from text prompts
  • Speech-to-text — Transcribe audio

Text Generation with Llama

Here's how to use Workers AI for text generation. The most popular models are Meta's Llama and Mistral AI's models:

// src/index.ts
export default {
  async fetch(request: Request, env: Env): Promise {
    const url = new URL(request.url);

    if (url.pathname === "/generate" && request.method === "POST") {
      const { prompt, model, maxTokens } = await request.json();

      const result = await env.AI.run(
        model || "@cf/meta/llama-3-8b-instruct",
        {
          messages: [
            { role: "system", content: "You are a helpful assistant." },
            { role: "user", content: prompt }
          ],
          max_tokens: maxTokens || 256,
          temperature: 0.7
        }
      );

      return Response.json({ result });
    }

    return new Response("POST /generate with { prompt, model, maxTokens }");
  }
};

// Type definition:
interface Env {
  AI: Ai;
}

Text Embeddings for Semantic Search

Embeddings convert text into numerical vectors. Similar text produces similar vectors, which enables semantic search — finding content by meaning, not just keywords.

// Generate embeddings
const embeddings = await env.AI.run(
  "@cf/baai/bge-small-en-v1.5",
  {
    texts: [
      "What is the weather like today?",
      "How do I fix a memory leak?",
      "Cloudflare Workers documentation"
    ]
  }
);

console.log(embeddings.embeddings[0]);
// [0.023, -0.045, 0.012, ...] (384 dimensions)

Here's a complete semantic search API:

// src/index.ts — Semantic Search Worker
interface Env {
  AI: Ai;
  KB: KVNamespace;  // Store embeddings in Workers KV
}

export default {
  async fetch(request: Request, env: Env): Promise {
    const url = new URL(request.url);

    // Add a document to the knowledge base
    if (url.pathname === "/add" && request.method === "POST") {
      const { text } = await request.json();
      const embedding = await env.AI.run("@cf/baai/bge-small-en-v1.5", {
        texts: [text]
      });

      const id = crypto.randomUUID();
      await env.KB.put(id, JSON.stringify({
        text,
        vector: embedding.embeddings[0]
      }));

      return Response.json({ id });
    }

    // Search the knowledge base
    if (url.pathname === "/search" && request.method === "POST") {
      const { query, limit = 5 } = await request.json();
      
      // Get query embedding
      const queryEmb = await env.AI.run("@cf/baai/bge-small-en-v1.5", {
        texts: [query]
      });
      const queryVector = queryEmb.embeddings[0];

      // Fetch all documents and compute similarity
      const list = await env.KB.list();
      const results = [];

      for (const doc of list.keys) {
        const data = JSON.parse(await env.KB.get(doc.name));
        const similarity = cosineSimilarity(queryVector, data.vector);
        results.push({ id: doc.name, text: data.text, score: similarity });
      }

      results.sort((a, b) => b.score - a.score);
      return Response.json({ results: results.slice(0, limit) });
    }

    return new Response("POST /add with { text } | POST /search with { query, limit }");
  }
};

// Cosine similarity helper
function cosineSimilarity(a: number[], b: number[]): number {
  const dot = a.reduce((sum, x, i) => sum + x * b[i], 0);
  const magA = Math.sqrt(a.reduce((sum, x) => sum + x * x, 0));
  const magB = Math.sqrt(b.reduce((sum, x) => sum + x * x, 0));
  return dot / (magA * magB);
}

Image Classification

Workers AI can classify images in real-time. Use cases include content moderation, auto-tagging, and input validation:

// Classify an uploaded image
export default {
  async fetch(request: Request, env: Env): Promise {
    if (request.method === "POST") {
      const body = await request.arrayBuffer();
      
      const result = await env.AI.run(
        "@cf/facebook/resnet-50",
        { image: [...new Uint8Array(body)] }
      );

      // result: [{ label: "tabby cat", probability: 0.94 }, ...]
      return Response.json({
        prediction: result[0].label,
        confidence: result[0].probability,
        all: result
      });
    }

    return new Response("POST image data to classify");
  }
};

Real-World Project: Smart Content Moderator

Let's build a content moderation pipeline that checks both text and images:

// src/moderator.ts
interface Env {
  AI: Ai;
  MODERATION_LOG: KVNamespace;
}

export default {
  async fetch(request: Request, env: Env): Promise {
    if (request.method !== "POST") {
      return new Response("POST /moderate with { text?, image? }", {
        headers: { "Content-Type": "application/json" }
      });
    }

    const { text, image } = await request.json();
    const violations = [];

    // Text moderation: check sentiment + toxicity
    if (text) {
      const analysis = await env.AI.run(
        "@cf/meta/llama-3-8b-instruct",
        {
          messages: [{
            role: "user",
            content: `Analyze this text for toxicity, hate speech, 
              harassment, or spam. Respond with JSON:
              {"toxic": boolean, "reason": string, "confidence": number}
              
              Text: ${text}`
          }],
          max_tokens: 128
        }
      );

      const result = JSON.parse(analysis.response);
      if (result.toxic) {
        violations.push({
          type: "text",
          reason: result.reason,
          confidence: result.confidence
        });
      }
    }

    // Image moderation: classify the image
    if (image) {
      const decoded = Uint8Array.from(
        atob(image.replace("data:image/png;base64,", "")),
        c => c.charCodeAt(0)
      );

      const classification = await env.AI.run(
        "@cf/facebook/efficientnet-lite0",
        { image: [...decoded] }
      );

      // Flag unexpected image types based on your use case
      const unexpected = classification.filter(
        c => c.label.includes("adult") || c.label.includes("weapon")
      );
      
      if (unexpected.length > 0) {
        violations.push({
          type: "image",
          labels: unexpected,
          confidence: unexpected[0].probability
        });
      }
    }

    // Log the moderation decision
    await env.MODERATION_LOG.put(
      crypto.randomUUID(),
      JSON.stringify({ text, violations, timestamp: new Date().toISOString() })
    );

    return Response.json({
      approved: violations.length === 0,
      violations
    });
  }
};

Combining Workers AI with Other Cloudflare Products

Workers AI + Workers KV = Persistent Memory

// Chatbot with conversation history in KV
export default {
  async fetch(request: Request, env: Env): Promise {
    const { userId, message } = await request.json();

    // Load previous conversation
    const history = await env.KV.get(`${userId}:history`) || "[]";
    const chat = JSON.parse(history);
    
    chat.push({ role: "user", content: message });

    // Generate response
    const result = await env.AI.run("@cf/meta/llama-3-8b-instruct", {
      messages: [
        { role: "system", content: "You are a helpful assistant." },
        ...chat.slice(-10)  // Last 10 messages for context
      ],
      max_tokens: 256
    });

    // Save updated history
    chat.push({ role: "assistant", content: result.response });
    await env.KV.put(`${userId}:history`, JSON.stringify(chat));

    return Response.json({ reply: result.response });
  }
};

Workers AI + D1 = Structured Knowledge Base

// Store embeddings with metadata in D1
export default {
  async fetch(request: Request, env: Env): Promise {
    const { text, category } = await request.json();

    // Generate embedding
    const embedding = await env.AI.run("@cf/baai/bge-small-en-v1.5", {
      texts: [text]
    });

    // Store in D1 database
    const vectorString = JSON.stringify(embedding.embeddings[0]);
    await env.DB.prepare(
      "INSERT INTO documents (text, category, embedding) VALUES (?, ?, ?)"
    ).bind(text, category, vectorString).run();

    return Response.json({ status: "indexed" });
  }
};

Best Practices

  • Cache embeddings — Don't regenerate embeddings for static content. Store in Workers KV and reuse.
  • Set temperature carefully — Low (0.1-0.3) for factual tasks, high (0.7-0.9) for creative tasks.
  • Limit max_tokens — Prevent runaway costs and latency by setting reasonable token limits.
  • Handle model unavailability — Workers AI models can be temporarily busy. Add retry logic with exponential backoff.
  • Sanitize inputs — Never pass raw user input directly to LLM prompts without sanitization (prompt injection risk).
  • Use edge caching — For repetitive queries (e.g., same FAQ), cache the AI response at the edge.
