Python Dictionaries and Sets: The Hash-Based Data Structures You'll Use Daily — Complete Beginner's Guide

July 18, 2026 11 min read

If you know lists and tuples, you already understand Python sequences. But when you need to look up data by name instead of position, or track unique items efficiently, dictionaries and sets become your best friends. They are the two most-used data structures in Python after lists, and mastering them will make your code shorter, faster, and clearer.

What Are Dictionaries?

A dictionary (dict) stores key-value pairs. Think of it like a real dictionary: you look up a word (the key) to find its definition (the value). In Python, keys must be immutable (strings, numbers, tuples), while values can be anything.

# Creating dictionaries
user = {"name": "Hugo", "age": 30, "city": "Tokyo"}

# Empty dict, then fill it
config = {}
config["host"] = "localhost"
config["port"] = 8080

# Using the dict() constructor
settings = dict(debug=True, version="2.0", retries=3)

print(user["name"])   # Hugo
print(settings["debug"])  # True

Accessing values is O(1) — constant time — because Python uses a hash table under the hood. That means looking up user["name"] takes the same time whether the dictionary has 10 entries or 10 million.

Safe Access with .get()

Direct access with ["key"] raises a KeyError if the key doesn't exist. Use .get() for safe access:

data = {"name": "Alice", "role": "admin"}

# Direct access — crashes if key missing
# print(data["email"])  # KeyError!

# Safe access with .get()
email = data.get("email")
print(email)  # None

# Safe access with a default value
role = data.get("role", "guest")
print(role)  # "admin" (key exists)

country = data.get("country", "Unknown")
print(country)  # "Unknown" (key missing)

Updating and Merging Dictionaries

Several ways to modify or combine dictionaries:

# Update individual keys
user = {"name": "Hugo", "age": 30}
user["city"] = "Tokyo"       # Add new key
user["age"] = 31             # Overwrite existing

# .update() — merge another dict
defaults = {"theme": "dark", "lang": "en", "notif": True}
prefs = {"theme": "light", "lang": "ja"}

defaults.update(prefs)
print(defaults)  # {"theme": "light", "lang": "ja", "notif": True}

# Merge with | operator (Python 3.9+)
base = {"a": 1, "b": 2}
extra = {"b": 3, "c": 4}
merged = base | extra
print(merged)  # {"a": 1, "b": 3, "c": 4}

Iterating Over Dictionaries

Three ways to loop through a dictionary:

scores = {"math": 95, "science": 88, "english": 92}

# Keys only (default)
for subject in scores:
    print(subject)
# math, science, english

# Key-value pairs
for subject, score in scores.items():
    print(f"{subject}: {score}")

# Values only
for score in scores.values():
    print(score)

# Keys only (explicit)
for subject in scores.keys():
    print(subject)

Dictionary Comprehensions

Build dictionaries in one line with dict comprehensions — the same syntax as list comprehensions, but with curly braces and key: value pairs:

# Square numbers: {n: n^2}
squares = {n: n**2 for n in range(1, 6)}
print(squares)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Invert a dictionary
original = {"a": 1, "b": 2, "c": 3}
inverted = {v: k for k, v in original.items()}
print(inverted)  # {1: "a", 2: "b", 3: "c"}

# Filter and transform
prices = {"apple": 1.2, "banana": 0.5, "cherry": 3.0}
cheap = {k: v for k, v in prices.items() if v < 2.0}
print(cheap)  # {"apple": 1.2, "banana": 0.5}

What Are Sets?

A set stores unique, unordered items. Use sets when you need to track membership, remove duplicates, or perform mathematical operations like union and intersection.

# Creating sets
fruits = {"apple", "banana", "cherry"}
empty = set()  # Not {} — that's an empty dict!

# From a list — removes duplicates
numbers = [1, 2, 2, 3, 3, 3, 4]
unique = set(numbers)
print(unique)  # {1, 2, 3, 4}

# Membership testing — O(1), very fast!
print("apple" in fruits)    # True
print("mango" in fruits)    # False

# Adding and removing
fruits.add("mango")
fruits.discard("banana")  # Safe — won't error if missing
fruits.remove("cherry")   # Raises KeyError if missing

Set Operations

Sets shine when you need mathematical operations on collections:

python_users = {"Alice", "Bob", "Charlie", "Diana"}
js_users = {"Bob", "Diana", "Eve", "Frank"}

# Union — everyone
everyone = python_users | js_users
print(everyone)  # {"Alice", "Bob", "Charlie", "Diana", "Eve", "Frank"}

# Intersection — both
both = python_users & js_users
print(both)  # {"Bob", "Diana"}

# Difference — Python only
python_only = python_users - js_users
print(python_only)  # {"Alice", "Charlie"}

# Symmetric difference — one but not both
either = python_users ^ js_users
print(either)  # {"Alice", "Charlie", "Eve", "Frank"}

Real-World Example: Counting with a Dictionary

One of the most common patterns is counting occurrences. A dictionary maps items to their count:

from collections import Counter

# Manual counting
words = ["the", "cat", "sat", "on", "the", "mat", "the", "cat"]
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
print(counts)  # {"the": 3, "cat": 2, "sat": 1, "on": 1, "mat": 1}

# Or use Counter (built-in, faster, more features)
counter = Counter(words)
print(counter.most_common(3))  # [("the", 3), ("cat", 2), ("sat", 1)]

Real-World Example: Grouping with Dictionaries

Group items by a common property using a dictionary with lists as values:

students = [
    {"name": "Alice", "grade": "A"},
    {"name": "Bob", "grade": "B"},
    {"name": "Charlie", "grade": "A"},
    {"name": "Diana", "grade": "C"},
    {"name": "Eve", "grade": "B"},
]

# Group by grade
groups = {}
for student in students:
    grade = student["grade"]
    groups.setdefault(grade, []).append(student["name"])

print(groups)
# {"A": ["Alice", "Charlie"], "B": ["Bob", "Eve"], "C": ["Diana"]}

When to Use What

Quick reference for choosing the right data structure:

  • List — ordered, allows duplicates, index-based access
  • Dict — key-value lookup, unique keys, fast by-name access
  • Set — unique items, fast membership testing, math operations
  • Tuple — fixed, immutable sequence, configuration data

Common Pitfalls

Mutability matters. Dictionary keys must be immutable:

# These keys work — immutable types
d = {
    "name": "Alice",    # str
    42: "answer",        # int
    (1, 2): "pair",      # tuple
}

# These keys don't work — mutable types
# d[[1, 2]] = "list"    # TypeError!
# d[{"a": 1}] = "dict"  # TypeError!

Remember: {} creates an empty dictionary, not an empty set. Use set() for an empty set.

Summary

Dictionaries and sets are the backbone of everyday Python. Use dictionaries when you need to associate data by name, and sets when you need uniqueness or fast lookups. Combine them with comprehensions for concise, Pythonic code. Practice with real data — parse config files, count words in text, deduplicate API responses — and these structures will become second nature.
