Python CSV and JSON Files: Read, Write, and Transform Data

July 7, 2026 10 min read New

If you're working with data in Python, you'll inevitably encounter CSV and JSON files. Whether you're exporting reports, importing datasets, or interacting with APIs, these two formats are everywhere. Python makes handling them effortless with built-in modules — no pip install required.

In this guide, we'll cover everything from basic file reading to advanced data transformations, with practical examples you can use in real projects today.

What Are CSV and JSON?

CSV (Comma-Separated Values) is a tabular format where each line represents a row and values are separated by commas. It's the go-to format for spreadsheets, databases, and data exports.

JSON (JavaScript Object Notation) is a hierarchical format for structured data. APIs return JSON, configuration files use JSON, and many NoSQL databases store data as JSON. It maps naturally to Python dictionaries and lists.

Reading CSV Files with the csv Module

Python's built-in csv module handles all the quirks of CSV parsing — quoted fields, commas inside values, different delimiters — so you don't have to.

Basic CSV Reading

Here's a sample CSV file called employees.csv:

name,department,salary,start_year
Alice,Engineering,95000,2021
Bob,Marketing,72000,2020
Charlie,Engineering,105000,2019
Diana,Sales,68000,2022
Eve,Engineering,88000,2023

Read it row by row using csv.reader:

import csv

with open('employees.csv', 'r') as f:
    reader = csv.reader(f)
    header = next(reader)  # Skip header row
    print(header)
    # Output: ['name', 'department', 'salary', 'start_year']

    for row in reader:
        print(row)
    # Output:
    # ['Alice', 'Engineering', '95000', '2021']
    # ['Bob', 'Marketing', '72000', '2020']
    # ...

Each row is returned as a list of strings. The next(reader) call skips the header row.

Using csv.DictReader for Cleaner Access

When your CSV has headers, csv.DictReader is much more convenient. Each row becomes a dictionary keyed by column name:

import csv

with open('employees.csv', 'r') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(f"{row['name']}: ${row['salary']} in {row['department']}")

# Output:
# Alice: $95000 in Engineering
# Bob: $72000 in Marketing
# Charlie: $105000 in Engineering
# Diana: $68000 in Sales
# Eve: $88000 in Engineering

Filtering and Transforming CSV Data

Let's find all engineers and calculate their average salary:

import csv

engineers = []

with open('employees.csv', 'r') as f:
    reader = csv.DictReader(f)
    for row in reader:
        if row['department'] == 'Engineering':
            engineers.append(row)

# Calculate average salary
avg_salary = sum(int(e['salary']) for e in engineers) / len(engineers)
print(f"Engineering team: {len(engineers)} people")
print(f"Average salary: ${avg_salary:,.0f}")

# Output:
# Engineering team: 3 people
# Average salary: $96,000

Writing CSV Files

Use csv.writer to create CSV output:

import csv

# Filter: only engineers, write to new file
with open('employees.csv', 'r') as infile:
    reader = csv.DictReader(infile)
    engineers = [row for row in reader if row['department'] == 'Engineering']

# Write filtered results
with open('engineers.csv', 'w', newline='') as outfile:
    writer = csv.DictWriter(outfile, fieldnames=['name', 'salary', 'start_year'])
    writer.writeheader()
    writer.writerows(engineers)

print("Created engineers.csv with", len(engineers), "rows")

Note the newline='' parameter — it's essential on Windows to avoid blank lines between rows. Always include it when writing CSV files.

Working with Different Delimiters

CSV doesn't always mean commas. Many files use tabs, semicolons, or pipes:

import csv

# Tab-separated file
with open('data.tsv', 'r') as f:
    reader = csv.reader(f, delimiter='\t')
    for row in reader:
        print(row)

# Semicolon-separated (common in European exports)
with open('european_data.csv', 'r') as f:
    reader = csv.DictReader(f, delimiter=';')
    for row in reader:
        print(row)

Reading JSON Files with the json Module

JSON maps directly to Python data types: objects become dictionaries, arrays become lists, strings stay strings, numbers become int or float, and boolean/null become True/False/None.

Basic JSON Reading

Here's a config.json file:

{
    "app_name": "MyApp",
    "version": "2.1.0",
    "database": {
        "host": "localhost",
        "port": 5432,
        "name": "myapp_db"
    },
    "features": ["auth", "logging", "cache"],
    "debug": false
}

Load it into a Python dictionary:

import json

with open('config.json', 'r') as f:
    config = json.load(f)

print(config['app_name'])       # MyApp
print(config['database']['host'])  # localhost
print(config['features'])        # ['auth', 'logging', 'cache']
print(type(config))              # <class 'dict'>

Working with JSON Arrays

Many API responses return a JSON array at the top level:

{
    "users": [
        {"id": 1, "name": "Alice", "role": "admin"},
        {"id": 2, "name": "Bob", "role": "user"},
        {"id": 3, "name": "Charlie", "role": "user"}
    ]
}

import json

with open('users.json', 'r') as f:
    data = json.load(f)

# Iterate over the users array
for user in data['users']:
    print(f"User {user['id']}: {user['name']} ({user['role']})")

# Filter admins
admins = [u for u in data['users'] if u['role'] == 'admin']
print(f"Found {len(admins)} admin(s)")

Writing JSON Files

Convert Python objects back to JSON with json.dump():

import json

# Transform data and save
summary = {
    "total_users": len(data['users']),
    "admin_count": len(admins),
    "user_count": len(data['users']) - len(admins),
    "roles": {}
}

# Count by role
for user in data['users']:
    role = user['role']
    summary['roles'][role] = summary['roles'].get(role, 0) + 1

with open('summary.json', 'w') as f:
    json.dump(summary, f, indent=2)

print("Created summary.json")
# Output:
# {
#   "total_users": 3,
#   "admin_count": 1,
#   "user_count": 2,
#   "roles": {
#     "admin": 1,
#     "user": 2
#   }
# }

The indent=2 parameter formats the output with readable indentation. Without it, json.dump() produces compact one-line JSON.

Pretty-Printing JSON Strings

Use json.dumps() (with an 's' for "string") when you want a formatted string instead of writing to a file:

import json

data = {"name": "Alice", "scores": [95, 87, 92], "active": True}

# Compact
print(json.dumps(data))
# Output: {"name": "Alice", "scores": [95, 87, 92], "active": true}

# Pretty-printed
print(json.dumps(data, indent=2))
# Output:
# {
#   "name": "Alice",
#   "scores": [95, 87, 92],
#   "active": true
# }

Handling JSON Parsing Errors

Always handle malformed JSON — especially when reading from external sources:

import json

def safe_load_json(filepath):
    """Load JSON with error handling."""
    try:
        with open(filepath, 'r') as f:
            return json.load(f)
    except FileNotFoundError:
        print(f"Error: {filepath} not found")
        return None
    except json.JSONDecodeError as e:
        print(f"Error: Invalid JSON in {filepath}")
        print(f"  Line {e.lineno}, Column {e.colno}: {e.msg}")
        return None
    except PermissionError:
        print(f"Error: Cannot read {filepath}")
        return None

data = safe_load_json('data.json')
if data is not None:
    print(f"Loaded {len(data)} items")

Converting Between CSV and JSON

A common task is converting CSV to JSON (or vice versa). Here's a complete conversion utility:

import csv
import json

def csv_to_json(csv_file, json_file):
    """Convert a CSV file to JSON array of objects."""
    with open(csv_file, 'r') as f:
        reader = csv.DictReader(f)
        data = list(reader)

    with open(json_file, 'w') as f:
        json.dump(data, f, indent=2)

    print(f"Converted {len(data)} rows to JSON")

def json_to_csv(json_file, csv_file):
    """Convert a JSON array of objects to CSV."""
    with open(json_file, 'r') as f:
        data = json.load(f)

    if not data:
        print("No data to convert")
        return

    # Get all unique keys (column names)
    fieldnames = list(data[0].keys())

    with open(csv_file, 'w', newline='') as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(data)

    print(f"Converted {len(data)} records to CSV")

# Usage
csv_to_json('employees.csv', 'employees.json')
json_to_csv('employees.json', 'employees_backup.csv')

Real-World Example: Processing API Data

Let's combine CSV and JSON skills to process data fetched from an API, transform it, and save it in both formats:

import json
import csv

# Simulated API response
api_data = {
    "status": "success",
    "count": 4,
    "results": [
        {"id": 1, "project": "Web App", "budget": 50000, "status": "active", "team_size": 5},
        {"id": 2, "project": "Mobile App", "budget": 75000, "status": "planning", "team_size": 3},
        {"id": 3, "project": "API Service", "budget": 30000, "status": "active", "team_size": 2},
        {"id": 4, "project": "Data Pipeline", "budget": 45000, "status": "completed", "team_size": 4}
    ]
}

# Save raw API response as JSON
with open('api_response.json', 'w') as f:
    json.dump(api_data, f, indent=2)

# Extract and transform data
projects = api_data['results']

# Filter active projects
active_projects = [p for p in projects if p['status'] == 'active']

# Calculate total budget for active projects
total_active_budget = sum(p['budget'] for p in active_projects)

# Write summary to CSV
with open('active_projects.csv', 'w', newline='') as f:
    writer = csv.DictWriter(f, fieldnames=['id', 'project', 'budget', 'team_size'])
    writer.writeheader()
    writer.writerows(active_projects)

# Write report as JSON
report = {
    "total_projects": len(projects),
    "active_projects": len(active_projects),
    "total_active_budget": total_active_budget,
    "average_team_size": round(
        sum(p['team_size'] for p in active_projects) / len(active_projects), 1
    ),
    "projects": active_projects
}

with open('report.json', 'w') as f:
    json.dump(report, f, indent=2)

print(f"Active projects: {len(active_projects)}")
print(f"Total active budget: ${total_active_budget:,}")
print(f"Average team size: {report['average_team_size']}")

# Output:
# Active projects: 2
# Total active budget: $80,000
# Average team size: 3.5

Handling Large Files

For files that won't fit in memory, process them line by line or in chunks:

import csv

# Process large CSV one row at a time (constant memory usage)
def count_by_department(filename):
    departments = {}
    with open(filename, 'r') as f:
        reader = csv.DictReader(f)
        for row in reader:  # Reads one row at a time
            dept = row['department']
            departments[dept] = departments.get(dept, 0) + 1
    return departments

counts = count_by_department('huge_employees.csv')
print(counts)
# Output: {'Engineering': 1523, 'Marketing': 487, 'Sales': 932, ...}

For large JSON arrays, consider using ijson (a streaming JSON parser) instead of json.load(), which loads the entire file into memory.

Summary

CSV and JSON are the two most common data formats you'll encounter in Python. The built-in csv and json modules handle everything you need:

  • csv.DictReader and csv.DictWriter for tabular data
  • json.load() and json.dump() for structured data
  • Both support reading/writing from files and strings
  • Always handle errors — especially for external data sources
  • Use newline='' when writing CSV on all platforms
  • Use indent=2 for human-readable JSON output

Practice these patterns with your own data files. Once you're comfortable reading and writing CSV and JSON, you're ready to tackle APIs, data pipelines, and automation scripts.
