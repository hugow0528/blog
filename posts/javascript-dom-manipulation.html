JavaScript DOM Manipulation: Build Interactive Web Pages — Complete Beginner's Guide

July 11, 2026 12 min read

HTML gives your page structure. CSS makes it beautiful. But JavaScript is what brings it to life. The Document Object Model (DOM) is JavaScript's bridge to the HTML — it lets you read, change, add, and remove page elements in real time. By the end of this guide, you'll build an interactive task list, a dynamic calculator, and understand every DOM concept you need for modern web development.

What Is the DOM?

When your browser loads an HTML page, it builds a tree of objects representing every element, attribute, and piece of text. This tree is the DOM. JavaScript can access and modify every node in this tree, and the browser updates the visual page accordingly.

Think of it like this: HTML is a blueprint, the DOM is the building, and JavaScript is the contractor who can demolish walls, paint rooms, and add new floors at any time.

Step 1: Selecting Elements

Before you can change anything, you need to find it. Modern JavaScript gives you several powerful selection methods:

The Modern Way: querySelector and querySelectorAll

// Get the first matching element (like CSS selectors)
const heading = document.querySelector('h1');
const submitBtn = document.querySelector('.btn-submit');
const firstParagraph = document.querySelector('#content p:first-child');

// Get ALL matching elements (returns a NodeList)
const allLinks = document.querySelectorAll('a');
const allItems = document.querySelectorAll('.task-list li');
const highlighted = document.querySelectorAll('.highlight, .important');

These methods use the same syntax as CSS selectors, so if you know CSS, you already know 90% of DOM selection. querySelector returns a single element (or null if nothing matches). querySelectorAll returns a NodeList — a collection that you can loop through.

Legacy Methods (Still Common)

const byId = document.getElementById('main');        // Single element
const byClass = document.getElementsByClassName('card');  // HTMLCollection
const byTag = document.getElementsByTagName('div');    // HTMLCollection

These work but are less flexible than querySelector. Stick to the modern methods unless you have a specific reason.

Step 2: Reading and Changing Content

Once you have a reference to an element, you can read and modify its content:

<h1 id="title">Hello World</h1>
<p class="desc"><strong>Bold</strong> and <em>italic</em> text</p>
<input type="text" id="name" value="Hugo">

<script>
// Read text content
const title = document.querySelector('#title');
console.log(title.textContent);  // "Hello World"
console.log(title.innerHTML);    // "Hello World"

// Read paragraph with HTML
const desc = document.querySelector('.desc');
console.log(desc.textContent);  // "Bold and italic text"
console.log(desc.innerHTML);    // "<strong>Bold</strong> and <em>italic</em> text"

// Read form input
const input = document.querySelector('#name');
console.log(input.value);       // "Hugo"
</script>

textContent vs innerHTML: Use textContent when you only need plain text (it's faster and safer). Use innerHTML when you need to preserve HTML tags. Never set innerHTML with user input — it opens XSS vulnerabilities.

Changing content is just as straightforward:

// Change text
title.textContent = 'Updated Title';

// Change HTML content (be careful!)
desc.innerHTML = '<em>Just italic now</em>';

// Change input value
input.value = 'New Name';

// Change placeholder
input.placeholder = 'Enter your name...';

// Change attribute
title.setAttribute('class', 'highlight');
input.setAttribute('disabled', '');

// Quick attribute access (common ones)
const link = document.querySelector('a');
link.href = 'https://example.com';
link.target = '_blank';
link.title = 'Visit example';

Step 3: Modifying Styles and Classes

Don't inline styles with JavaScript when you can help it. Toggle CSS classes instead:

<div class="card" id="myCard">Hello</div>

<style>
.card { padding: 1rem; border: 1px solid #ccc; }
.card.active { background: #e8f5e9; border-color: #4caf50; }
.card.hidden { display: none; }
</style>

<script>
const card = document.querySelector('#myCard');

// Add a class
card.classList.add('active');

// Remove a class
card.classList.remove('active');

// Toggle a class (add if absent, remove if present)
card.classList.toggle('active');

// Check if a class exists
if (card.classList.contains('active')) {
    console.log('Card is active!');
}

// Replace classes
card.classList.replace('hidden', 'active');

// Multiple classes at once
card.classList.add('active', 'large', 'shadow');
</script>

If you absolutely need inline styles (for dynamic values), use the style property. Note that CSS property names with hyphens become camelCase in JavaScript:

// Inline styles (use sparingly!)
card.style.backgroundColor = '#e8f5e9';
card.style.fontSize = '18px';
card.style.padding = '20px';
card.style.display = 'block';
card.style.transform = 'scale(1.1)';

Step 4: Creating and Removing Elements

Dynamically add and remove elements on the page:

// Create a new element
const newParagraph = document.createElement('p');
newParagraph.textContent = 'I was added by JavaScript!';
newParagraph.classList.add('new-item');

// Add to the page
document.body.appendChild(newParagraph);

// Insert before a specific element
const heading = document.querySelector('h1');
const subheading = document.createElement('p');
subheading.textContent = 'A subtitle';
heading.after(subheading);       // After the heading
heading.before(subheading);      // Before the heading

// Insert as first/last child
const container = document.querySelector('#container');
container.prepend(subheading);   // First child
container.append(newParagraph);  // Last child

// Remove an element
newParagraph.remove();

// Replace an element
const oldElement = document.querySelector('#old');
const newElement = document.createElement('div');
newElement.textContent = 'Replaced!';
oldElement.replaceWith(newElement);

Step 5: Traversing the DOM

Navigate between elements without needing selectors:

<ul id="list">
  <li class="item" data-index="0">First</li>
  <li class="item" data-index="1">Second</li>
  <li class="item" data-index="2">Third</li>
</ul>

<script>
const item = document.querySelector('.item');

// Parent
console.log(item.parentElement);  // <ul>

// Children
console.log(item.parentElement.children);  // All child elements
console.log(item.parentElement.firstChild);  // First child (could be text node)

// Siblings
console.log(item.nextElementSibling);  // Next sibling element
console.log(item.previousElementSibling);  // Previous sibling element

// First and last child
const list = document.querySelector('#list');
console.log(list.firstElementChild);  // First <li>
console.log(list.lastElementChild);   // Last <li>
console.log(list.children.length);    // Number of children: 3
</script>

Step 6: Working with Data Attributes

Store custom data on elements using data-* attributes:

<div class="user-card"
     data-user-id="42"
     data-role="admin"
     data-score="98.5">
  Admin User
</div>

<script>
const card = document.querySelector('.user-card');

// Read data attributes
console.log(card.dataset.userId);   // "42"
console.log(card.dataset.role);     // "admin"
console.log(card.dataset.score);    // "98.5"

// Write data attributes
card.dataset.status = 'online';
// <div data-status="online"...>

// Delete data attributes
delete card.dataset.role;
</script>

Note: Data attribute values are always strings. Convert with parseInt() or parseFloat() when needed.

Step 7: Event Listeners — Making Things Interactive

Events are the heartbeat of interactive web pages. Connect JavaScript functions to user actions:

const btn = document.querySelector('#myButton');

// Click event
btn.addEventListener('click', function(event) {
    console.log('Button clicked!', event.target);
    btn.textContent = 'Clicked!';
});

// Multiple event types
const input = document.querySelector('#searchInput');

// Fires on every keystroke
input.addEventListener('input', (e) => {
    console.log('Current value:', e.target.value);
});

// Fires when pressing specific keys
input.addEventListener('keydown', (e) => {
    if (e.key === 'Enter') {
        console.log('Search:', input.value);
    }
    if (e.key === 'Escape') {
        input.value = '';  // Clear on Escape
    }
});

// Mouse events
btn.addEventListener('mouseenter', () => {
    btn.classList.add('hovering');
});
btn.addEventListener('mouseleave', () => {
    btn.classList.remove('hovering');
});

// Form events
const form = document.querySelector('#myForm');
form.addEventListener('submit', (e) => {
    e.preventDefault();  // Stop page reload
    const formData = new FormData(form);
    console.log(Object.fromEntries(formData));
});

// Remove an event listener (you need a named function)
function handleClick() {
    console.log('clicked');
}
btn.addEventListener('click', handleClick);
// Later...
btn.removeEventListener('click', handleClick);

Step 8: Event Delegation — The Pro Pattern

Instead of attaching a listener to every element, attach one listener to a parent and use event bubbling to handle child events:

<ul id="taskList">
  <li data-id="1">Task 1 <button class="delete">✕</button></li>
  <li data-id="2">Task 2 <button class="delete">✕</button></li>
  <li data-id="3">Task 3 <button class="delete">✕</button></li>
</ul>

<script>
// ONE listener on the parent instead of 9 on each child
const taskList = document.querySelector('#taskList');

taskList.addEventListener('click', (e) => {
    // Check if a delete button was clicked
    if (e.target.classList.contains('delete')) {
        const task = e.target.parentElement;
        const id = task.dataset.id;
        task.remove();
        console.log(`Deleted task ${id}`);
    }

    // Check if a task item was clicked (for toggling)
    if (e.target.tagName === 'LI') {
        e.target.classList.toggle('completed');
    }
});
</script>

Why use delegation? It works for dynamically added elements too. If you add a new <li> after the listener is set up, it still works because the listener is on the parent.

Step 9: Full Project — Interactive Task Manager

Let's combine everything into a practical project:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Task Manager</title>
    <style>
        body { font-family: system-ui; max-width: 500px; margin: 2rem auto; padding: 0 1rem; }
        input { padding: 8px; width: 70%; border: 1px solid #ccc; border-radius: 4px; }
        button { padding: 8px 16px; border: none; border-radius: 4px; cursor: pointer; }
        #addBtn { background: #4caf50; color: white; }
        ul { list-style: none; padding: 0; }
        li { display: flex; align-items: center; gap: 8px; padding: 8px; border-bottom: 1px solid #eee; }
        li.completed span { text-decoration: line-through; color: #999; }
        .delete { margin-left: auto; background: #f44336; color: white; padding: 4px 8px; font-size: 12px; }
        .stats { margin-top: 1rem; color: #666; font-size: 14px; }
    </style>
</head>
<body>
    <h1>📝 Task Manager</h1>
    <div>
        <input type="text" id="taskInput" placeholder="Add a new task...">
        <button id="addBtn">Add</button>
    </div>
    <ul id="taskList"></ul>
    <div class="stats" id="stats">0 tasks</div>

    <script>
        const input = document.querySelector('#taskInput');
        const addBtn = document.querySelector('#addBtn');
        const taskList = document.querySelector('#taskList');
        const stats = document.querySelector('#stats');

        // Add a new task
        function addTask() {
            const text = input.value.trim();
            if (!text) return;

            const li = document.createElement('li');
            li.innerHTML = `<span>${escapeHtml(text)}</span><button class="delete">✕</button>`;
            taskList.appendChild(li);
            input.value = '';
            updateStats();
        }

        // Handle clicks via delegation
        taskList.addEventListener('click', (e) => {
            if (e.target.classList.contains('delete')) {
                e.target.parentElement.remove();
                updateStats();
            } else if (e.target.tagName === 'SPAN') {
                const li = e.target.parentElement;
                li.classList.toggle('completed');
                updateStats();
            }
        });

        // Enter key adds task
        input.addEventListener('keydown', (e) => {
            if (e.key === 'Enter') addTask();
        });

        addBtn.addEventListener('click', addTask);

        // Update task count
        function updateStats() {
            const total = taskList.children.length;
            const completed = taskList.querySelectorAll('.completed').length;
            stats.textContent = `${completed}/${total} tasks completed`;
        }

        // Prevent XSS when inserting user input
        function escapeHtml(text) {
            const div = document.createElement('div');
            div.textContent = text;
            return div.innerHTML;
        }
    </script>
</body>
</html>

Common Patterns and Tips

Waiting for the DOM to Load

If your JavaScript runs before the HTML exists, your selectors return null. Three solutions:

// 1. Put <script> at the end of <body> (before </body>)
// 2. Use the defer attribute
<script src="app.js" defer></script>
// 3. Wrap in DOMContentLoaded
document.addEventListener('DOMContentLoaded', () => {
    // DOM is ready
});

Looping Over NodeLists

// querySelectorAll returns a NodeList — use .forEach()
document.querySelectorAll('.item').forEach(item => {
    item.addEventListener('click', () => {
        item.classList.toggle('active');
    });
});

// Spread into an array for full Array methods
const items = [...document.querySelectorAll('.item')];
const filtered = items.filter(el => el.dataset.active === 'true');

Template Literals for HTML Generation

const users = [
    { name: 'Alice', role: 'Admin' },
    { name: 'Bob', role: 'User' }
];

const html = users.map(user => `
    <li class="user-item" data-role="${user.role}">
        <strong>${user.name}</strong>
        <span>${user.role}</span>
    </li>
`).join('');

document.querySelector('#userList').innerHTML = html;

Warning: If user data contains HTML, escape it first to prevent XSS. For complex apps, consider using document.createElement() or a template library instead of innerHTML.

Summary

The DOM API is the foundation of every interactive website. Master these concepts and you can build anything:

  1. Select elements with querySelector
  2. Read/change content with textContent, innerHTML, value
  3. Style with classList (prefer over inline styles)
  4. Create/remove elements with createElement(), appendChild(), remove()
  5. Navigate with parent/child/sibling properties
  6. React to user actions with addEventListener()
  7. Delegate events to handle dynamic content efficiently

Practice by building small interactive widgets — a counter, a color picker, a tab panel, a modal dialog. Each one reinforces a different DOM pattern. Once you're comfortable, you'll be ready to learn frameworks like React or Vue that abstract these same concepts into a more structured API.
