CSS Animations and Transitions: Smooth Motion on the Web — Complete Beginner's Guide

July 16, 2026 12 min read

Motion makes interfaces feel alive. CSS animations and transitions let you create smooth, hardware-accelerated effects without a single line of JavaScript — from subtle hover states to full-screen entrance animations. This guide walks through every concept from basic transitions to complex multi-step animations.

1. CSS Transitions: Smooth Property Changes

Transitions animate the change of a CSS property over a specified duration. They trigger when a property value changes — typically on hover, focus, or active states.

The transition Shorthand

/* Basic transition on hover */
.button {
    background-color: #6366f1;
    color: white;
    padding: 12px 24px;
    border: none;
    border-radius: 8px;
    cursor: pointer;
    transition: background-color 0.3s ease;
}

.button:hover {
    background-color: #4f46e5;
}

The transition shorthand accepts four values in order:

transition: <property> <duration> <timing-function> <delay>;

/* All four values */
.card {
    transition: transform 0.4s cubic-bezier(0.25, 0.46, 0.45, 0.94) 0s;
}

/* Duration only — transitions all properties */
.card {
    transition: 0.3s ease;
}

/* Multiple transitions */
.box {
    transition: opacity 0.2s ease, transform 0.4s ease-in-out;
}

Timing Functions

Timing functions control the speed curve of the animation:

/* Easing keywords */
.ease       /* ease curve, starts slow, fast middle, slow end */
.linear     /* constant speed throughout */
.ease-in    /* starts slow, speeds up */
.ease-out   /* starts fast, slows down */
.ease-in-out /* starts slow, fast middle, slow end */

/* Custom cubic-bezier for fine control */
.smooth {
    transition: transform 0.5s cubic-bezier(0.34, 1.56, 0.64, 1);
    /* The value > 1 creates a slight "overshoot" bounce effect */
}

2. The transform Property

The transform property enables 2D and 3D manipulation of elements. Unlike layout properties, transforms don't trigger reflow — making them the most performant way to animate position and size changes.

2D Transforms

/* Translate — move without affecting layout */
.slide-in {
    transform: translateX(-100%);
    transition: transform 0.5s ease-out;
}
.slide-in.visible {
    transform: translateX(0);
}

/* Scale — resize from center */
.zoom {
    transition: transform 0.3s ease;
}
.zoom:hover {
    transform: scale(1.1);
}

/* Rotate */
.spin:hover {
    transform: rotate(360deg);
    transition: transform 0.6s ease;
}

/* Combine transforms */
.combined:hover {
    transform: translateY(-4px) scale(1.02);
    transition: transform 0.3s ease-out;
}

3D Transforms

/* 3D card flip */
.card-container {
    perspective: 1000px;
}

.card {
    transform-style: preserve-3d;
    transition: transform 0.6s ease;
}

.card-container:hover .card {
    transform: rotateY(180deg);
}

/* 3D rotate with perspective */
.flip-x:hover {
    transform: perspective(600px) rotateX(15deg);
}

3. CSS @keyframes Animations

Unlike transitions that react to state changes, @keyframes define a multi-step animation that runs on its own timeline. You control every frame.

Basic Keyframe Animation

/* Define the animation */
@keyframes fadeIn {
    from {
        opacity: 0;
        transform: translateY(20px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

/* Apply the animation */
.hero-title {
    animation: fadeIn 0.8s ease-out forwards;
}

/* Multi-step animation */
@keyframes slideUpFade {
    0% {
        opacity: 0;
        transform: translateY(40px);
    }
    60% {
        opacity: 1;
        transform: translateY(-4px);
    }
    100% {
        opacity: 1;
        transform: translateY(0);
    }
}

.card {
    animation: slideUpFade 0.6s ease-out forwards;
}

Animation Properties

/* Full animation shorthand */
animation: name duration timing-function delay iteration-count direction fill-mode play-state;

.spinner {
    animation: spin 1s linear infinite;
    /* name: spin, duration: 1s, timing: linear, repeat: infinite */
}

/* Each property individually */
.notification {
    animation-name: slideInRight;
    animation-duration: 0.4s;
    animation-timing-function: ease-out;
    animation-delay: 0.1s;
    animation-iteration-count: 1;
    animation-fill-mode: forwards;
    animation-play-state: running;
}

/* fill-mode values */
.forwards   /* stays at final keyframe after animation ends */
.backwards  /* applies initial keyframe during delay period */
.both       /* combines forwards and backwards */
.none       /* default — resets to original state */

Practical Animation Examples

/* Loading spinner */
@keyframes spin {
    to { transform: rotate(360deg); }
}
.spinner {
    width: 40px;
    height: 40px;
    border: 3px solid #e5e7eb;
    border-top-color: #6366f1;
    border-radius: 50%;
    animation: spin 0.8s linear infinite;
}

/* Pulsing dot */
@keyframes pulse {
    0%, 100% { transform: scale(1); opacity: 1; }
    50% { transform: scale(1.5); opacity: 0.5; }
}
.live-dot {
    width: 8px;
    height: 8px;
    background: #10b981;
    border-radius: 50%;
    animation: pulse 2s ease-in-out infinite;
}

/* Staggered entrance animation */
.list-item {
    opacity: 0;
    animation: fadeInUp 0.5s ease forwards;
}
.list-item:nth-child(1) { animation-delay: 0.0s; }
.list-item:nth-child(2) { animation-delay: 0.1s; }
.list-item:nth-child(3) { animation-delay: 0.2s; }
.list-item:nth-child(4) { animation-delay: 0.3s; }

@keyframes fadeInUp {
    from { opacity: 0; transform: translateY(20px); }
    to   { opacity: 1; transform: translateY(0); }
}

/* Skeleton loading placeholder */
@keyframes shimmer {
    0% { background-position: -200% 0; }
    100% { background-position: 200% 0; }
}
.skeleton {
    height: 20px;
    background: linear-gradient(90deg, #e5e7eb 25%, #f3f4f6 50%, #e5e7eb 75%);
    background-size: 200% 100%;
    animation: shimmer 1.5s ease-in-out infinite;
    border-radius: 4px;
}

4. Animating with JavaScript (When You Need It)

CSS animations handle most cases, but sometimes you need JavaScript for dynamic control:

// Trigger animation by adding a class
const button = document.querySelector('.magic-btn');
button.addEventListener('click', () => {
    button.classList.add('animate');
});

/* CSS */
@keyframes confetti {
    0% { transform: translateY(0) rotate(0deg); opacity: 1; }
    100% { transform: translateY(-200px) rotate(720deg); opacity: 0; }
}

.animate::after {
    content: '🎉';
    position: absolute;
    animation: confetti 0.8s ease-out forwards;
}

// Listen for animation events
element.addEventListener('animationend', (e) => {
    console.log('Animation completed:', e.animationName);
    element.classList.remove('animate');
});

// Dynamic animation with Web Animations API
element.animate([
    { transform: 'scale(1)', opacity: 1 },
    { transform: 'scale(1.2)', opacity: 0.8 },
    { transform: 'scale(1)', opacity: 1 }
], {
    duration: 400,
    easing: 'ease-in-out',
    iterations: 1
});

5. Performance: Animating Without Jank

Not all CSS properties are equal when it comes to animation performance. Understanding what triggers expensive browser operations is the difference between smooth 60fps and stuttering 15fps.

The Performance Hierarchy

/* 🟢 BEST — GPU composited (no layout, no paint) */
.fast {
    transition: transform 0.3s ease, opacity 0.3s ease;
}

/* 🟡 GOOD — Triggers paint but not layout */
.okay {
    transition: color 0.3s, background-color 0.3s, box-shadow 0.3s;
}

/* 🔴 AVOID — Triggers full layout recalculation */
.slow {
    transition: width 0.3s, height 0.3s, margin 0.3s, top 0.3s, left 0.3s;
}

Performance Best Practices

/* ❌ BAD: Animating width */
.bad-expand:hover {
    width: 300px;  /* triggers layout every frame */
    transition: width 0.3s;
}

/* ✅ GOOD: Animating transform:scale instead */
.good-expand {
    transform-origin: left center;
}
.good-expand:hover {
    transform: scaleX(1.5);  /* GPU composited */
    transition: transform 0.3s;
}

/* Use will-change for elements you know will animate */
.hero-image {
    will-change: transform;
    /* Apply early, remove after animation starts */
}

/* Prefer translate over top/left for movement */
/* ❌ BAD */
.moving-bad {
    top: 100px;
    left: 50px;
    transition: top 0.3s, left 0.3s;
}

/* ✅ GOOD */
.moving-good {
    transform: translate(50px, 100px);
    transition: transform 0.3s;
}

/* Limit concurrent animations */
.card-grid {
    /* Only animate cards that enter viewport */
    animation-timeline: view();
}

7. Accessibility Considerations

Animations can cause discomfort or even trigger seizures in some users. Always respect user preferences:

/* Respect the user's motion preference */
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
        scroll-behavior: auto !important;
    }
}

/* Alternative: disable specific animations */
@media (prefers-reduced-motion: reduce) {
    .parallax {
        transform: none;
    }
    .fade-in {
        opacity: 1;
    }
}

/* Never animate on pages that could be read for a long time
   — avoid parallax, scroll-triggered animations */
/* It's fine to animate on load, hover, or interaction */

Summary

TechniqueBest ForPerformance
transitionHover states, togglesHigh (with transform/opacity)
@keyframesMulti-step, timed animationsHigh (with transform/opacity)
transformMove, scale, rotateGPU composited — fastest
opacityFade in/out effectsGPU composited — fast
animation-timelineScroll-driven effectsHigh — native scroll sync

The golden rule: animate transform and opacity whenever possible, use transition for interaction feedback, reserve @keyframes for multi-step effects, and always respect prefers-reduced-motion. With these tools, you can create beautiful, smooth animations that enhance every interface.
