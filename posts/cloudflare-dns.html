Cloudflare DNS Explained: Proxied vs DNS Only

June 17, 2026 · 4 min read

When you add a DNS record in Cloudflare, you see an orange cloud toggle. What does it do? Should you turn it on or off? This guide explains in simple terms.

The Two Modes

🟠 Orange Cloud — Proxied

Traffic goes through Cloudflare first:

User → Cloudflare → Your Server

Benefits:

  • DDoS protection — Cloudflare absorbs attacks
  • Free SSL/TLS — automatic HTTPS
  • Caching — faster load times
  • Bot protection — blocks malicious bots
  • Your server IP stays hidden

⚪ Grey Cloud — DNS Only

Cloudflare just points the domain. Traffic goes direct:

User → Your Server

When to use:

  • Services that need direct IP access (SSH, FTP, game servers)
  • When Cloudflare proxying breaks something
  • Internal services

Real World Example

Here's my DNS setup:

Subdomain Type Proxy Why
weather.hugow.dev CNAME 🟠 Proxied Web app — needs SSL + protection
deploy.hugow.dev CNAME 🟠 Proxied Web app — needs SSL + protection
remote.hugow.dev CNAME 🟠 Proxied Remote desktop — proxied works fine
sftp.hugow.dev CNAME 🟠 Proxied SSH via Cloudflare Tunnel

Common DNS Record Types

A Record

Points to an IPv4 address (e.g., 192.168.1.1)

CNAME

Points to another domain name (e.g., cfargotunnel.com)

MX Record

Mail server — must be grey cloud (DNS only)

SRV Record

Service discovery — used by VoIP, gaming

Proxying Issues & Fixes

Problem: WebSocket connections fail

Fix: Enable "Connection Optimization" in Cloudflare dashboard or turn proxy off temporarily to test.

Problem: Real IP not showing

Fix: Use X-Forwarded-For header instead of remote_addr in your code.

Problem: Upload size limited

Fix: Free plan has 100MB limit. Go to Bandwidth → File Size Limit.

Cloudflare API for DNS

You can manage DNS via API too:

# List DNS records
curl -X GET "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT/dns_records" \
  -H "Authorization: Bearer $API_TOKEN"

# Create a CNAME record
curl -X POST "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT/dns_records" \
  -H "Authorization: Bearer $API_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{
    "type": "CNAME",
    "name": "blog.hugow.dev",
    "content": "cfargotunnel.com",
    "proxied": true
  }'

Key Takeaways

  • 🟠 Proxied = protection, SSL, caching, speed
  • ⚪ DNS Only = direct connection, no Cloudflare benefits
  • Web apps → Always proxied
  • Email → Always DNS only
  • When in doubt → Start proxied, test, adjust
