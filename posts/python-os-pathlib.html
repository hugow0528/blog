Python os and pathlib Modules: Navigate and Manage Filesystems

July 9, 2026 · 10 min read

Every Python developer needs to work with the filesystem — whether finding configuration files, listing project directories, cleaning up temporary data, or building tools that process files in bulk. Python gives you two powerful built-in modules for this: os (and os.path) and pathlib. In this guide, we'll explore both approaches so you can choose the right tool for every task.

The Two Schools: os.path vs pathlib

Python has had two ways to work with file paths. Understanding both is important because you'll encounter os.path in older codebases and pathlib in modern ones.

os.path (String-Based, Since Python 1.5)

The os.path module treats paths as strings. Every operation takes strings and returns strings:

import os.path

path = "home/user/documents/report.pdf"

# Get the directory name
directory = os.path.dirname(path)
print(directory)  # "home/user/documents"

# Get the file name
filename = os.path.basename(path)
print(filename)  # "report.pdf"

# Join path parts (handles slashes correctly)
full = os.path.join("home", "user", "documents", "report.pdf")
print(full)  # "home/user/documents/report.pdf" (Unix)

# Split into (path, extension)
name, ext = os.path.splitext(path)
print(name)  # "home/user/documents/report"
print(ext)   # ".pdf"

# Check if file/directory exists
print(os.path.exists(path))    # True or False
print(os.path.isfile(path))    # True if it's a file
print(os.path.isdir(path))     # True if it's a directory

# Get file size in bytes
size = os.path.getsize(path)
print(f"Size: {size} bytes")

pathlib (Object-Based, Since Python 3.4)

The pathlib module treats paths as objects with methods. This is the modern, recommended approach:

from pathlib import Path

path = Path("home/user/documents/report.pdf")

# Properties replace functions
print(path.parent)       # PosixPath('home/user/documents')
print(path.name)         # "report.pdf"
print(path.stem)         # "report"
print(path.suffix)       # ".pdf"
print(path.suffixes)     # [".pdf"] (for "file.tar.gz")

# Joining paths uses the / operator
full = Path("home") / "user" / "documents" / "report.pdf"
print(full)  # PosixPath('home/user/documents/report.pdf')

# Checking existence
print(path.exists())    # True or False
print(path.is_file())   # True if it's a file
print(path.is_dir())    # True if it's a directory

# File size
print(path.stat().st_size)  # Size in bytes

The pathlib approach reads more naturally and is less error-prone. You chain methods instead of nesting function calls.

Listing Directory Contents

Listing files in a directory is one of the most common filesystem operations. Both modules handle it well:

Using os.listdir()

import os

# List everything in the current directory
items = os.listdir(".")
print(items)
# ['script.py', 'data.csv', 'output/', 'README.md']

# List with full paths
for item in os.listdir("/tmp"):
    full_path = os.path.join("/tmp", item)
    print(full_path)

# Filter for specific extensions
python_files = [f for f in os.listdir(".") if f.endswith(".py")]
print(python_files)  # ['script.py', 'utils.py']

Using pathlib's iterdir() and glob()

from pathlib import Path

# List everything
items = Path(".").iterdir()
for item in items:
    print(item)

# Filter by name pattern (glob)
python_files = Path(".").glob("*.py")
for f in python_files:
    print(f.name)  # just the filename

# Recursive glob (all .py files in subdirectories too)
all_python = Path(".").rglob("*.py")
for f in all_python:
    print(f)  # prints full relative path

# Multiple patterns
configs = list(Path(".").glob("*.json")) + list(Path(".").glob("*.yaml"))
print(f"Found {len(configs)} config files")

Walking Directory Trees Recursively

When you need to process every file in a directory and all its subdirectories, use os.walk() or Path.rglob():

Using os.walk()

import os

# Walk yields (dirpath, subdirectories, files) for each directory
for dirpath, dirnames, filenames in os.walk("my_project"):
    print(f"Directory: {dirpath}")
    for filename in filenames:
        filepath = os.path.join(dirpath, filename)
        print(f"  File: {filepath}")

# Walk only .txt files and print their sizes
for dirpath, _, filenames in os.walk("documents"):
    for filename in filenames:
        if filename.endswith(".txt"):
            filepath = os.path.join(dirpath, filename)
            size = os.path.getsize(filepath)
            print(f"{filepath}: {size} bytes")

# Skip certain directories (modify dirnames in-place)
for dirpath, dirnames, filenames in os.walk("my_project"):
    # Skip hidden directories and __pycache__
    dirnames[:] = [d for d in dirnames if not d.startswith(".") and d != "__pycache__"]
    for filename in filenames:
        print(os.path.join(dirpath, filename))

Using pathlib.rglob()

from pathlib import Path

# Simple recursive search — all files
all_files = list(Path("my_project").rglob("*"))
for f in all_files:
    if f.is_file():
        print(f"{f}: {f.stat().st_size} bytes")

# Find all test files
test_files = list(Path("my_project").rglob("test_*.py"))
for f in test_files:
    print(f)

# Find Markdown files and count words
for md_file in Path(".").rglob("*.md"):
    text = md_file.read_text()
    word_count = len(text.split())
    print(f"{md_file.name}: {word_count} words")

Creating, Copying, and Removing Files

Filesystem manipulation goes beyond reading — you'll often need to create directories, copy files, or clean up temporary data.

Creating Directories

from pathlib import Path
import os

# pathlib: create directory (and parents if needed)
config_dir = Path("config/database")
config_dir.mkdir(parents=True, exist_ok=True)
# parents=True creates intermediate dirs (like mkdir -p)
# exist_ok=True prevents error if directory already exists

# os equivalent: creates intermediate dirs
os.makedirs("config/database", exist_ok=True)

# Create a file (touch)
(Path("config/database") / "settings.json").touch()

# Write content directly
(Path("config/database") / "settings.json").write_text(
    '{"host": "localhost", "port": 5432}'
)

Reading and Writing Files with pathlib

from pathlib import Path

# Read entire file as text
text = Path("notes.txt").read_text()

# Read as bytes (for images, binaries)
data = Path("logo.png").read_bytes()

# Write text
Path("output.txt").write_text("Hello, World!\n")

# Append text
Path("output.txt").write_text(Path("output.txt").read_text() + "New line\n")

# Read lines into a list
lines = Path("notes.txt").read_text().splitlines()
print(f"Found {len(lines)} lines")

Copying and Moving Files

from pathlib import Path
import shutil

src = Path("data/report.csv")
dst = Path("backup/report.csv")

# Copy file
shutil.copy(src, dst)

# Copy entire directory tree
shutil.copytree("my_project", "my_project_backup")

# Move (rename) a file
src.rename(Path("archive") / src.name)

# Remove a single file
Path("temp.txt").unlink()

# Remove empty directory
Path("empty_folder").rmdir()

# Remove directory tree (BE CAREFUL!)
shutil.rmtree("unwanted_folder")

Working with Environment Variables and Paths

The os module also handles environment variables and system information — things that pathlib doesn't cover:

import os

# Get environment variables
home = os.environ.get("HOME")  # or os.getenv("HOME")
print(f"Home directory: {home}")

# Safe access with default value
db_host = os.getenv("DB_HOST", "localhost")
db_port = int(os.getenv("DB_PORT", "5432"))

# Get the current working directory
cwd = os.getcwd()
print(f"Working in: {cwd}")

# Change directory
os.chdir("/tmp")

# Get special path info
print(os.name)           # 'posix' (Linux/Mac) or 'nt' (Windows)
print(os.cpu_count())    # Number of CPU cores
print(os.getpid())       # Current process ID

# Expand user home (~)
expanded = os.path.expanduser("~/documents")
print(expanded)  # "/home/user/documents"

Practical Example: Project File Analyzer

Let's combine everything into a practical script that analyzes a Python project — counting files, calculating total size, and generating a summary report:

from pathlib import Path
from collections import Counter

def analyze_project(project_dir="."):
    """Analyze a project directory and print statistics."""
    project = Path(project_dir)
    
    # Track file types and total size
    extensions = Counter()
    total_size = 0
    file_count = 0
    dir_count = 0
    
    for filepath in project.rglob("*"):
        if filepath.is_file():
            extensions[filepath.suffix or "(no extension)"] += 1
            total_size += filepath.stat().st_size
            file_count += 1
        elif filepath.is_dir():
            dir_count += 1
    
    # Print report
    print(f"\n{'='*50}")
    print(f"Project Analysis: {project.name}")
    print(f"{'='*50}")
    print(f"Directories: {dir_count}")
    print(f"Files:       {file_count}")
    print(f"Total size:  {total_size / 1024:.1f} KB")
    print(f"\nFile types:")
    for ext, count in extensions.most_common():
        print(f"  {ext:15} {count}")
    print()

# Run it
analyze_project(".")
analyze_project("my_project")

Which Should You Use: os.path or pathlib?

Here's a simple decision guide:

  • Use pathlib for everyday path manipulation, file I/O, and glob patterns. It's cleaner, more Pythonic, and the modern standard.
  • Use os.path when working with legacy code or when you specifically need string paths (some older libraries expect strings).
  • Use os for environment variables (os.environ), process info (os.getpid()), and system calls (os.chdir(), os.system()).
  • Use shutil for copying/moving files and directories — neither os nor pathlib handles this well.

Pro tip: If you need a string from a pathlib Path, just use str(path). If you need a Path from a string, use Path(string). Converting between them is trivial.

Common Pitfalls to Avoid

Here are mistakes beginners make when working with paths:

# ❌ Don't concatenate paths with string formatting
bad_path = "./data/" + filename  # breaks on Windows, fails with trailing slashes

# ✅ Use pathlib's / operator
good_path = Path("./data") / filename

# ❌ Don't hardcode directory separators
bad_path = "home/user/data"  # works on Linux, breaks on Windows

# ✅ Let Python handle the separator
good_path = Path("home") / "user" / "data"

# ❌ Don't forget to handle missing files
try:
    data = Path("missing.txt").read_text()
except FileNotFoundError:
    print("File not found, creating default...")
    Path("missing.txt").write_text("default content")
