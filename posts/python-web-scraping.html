Python Web Scraping: Extract Data from Any Website — Complete Beginner's Guide

July 11, 2026 12 min read

Web scraping is one of the most practical skills a Python developer can learn. Whether you need to track prices, gather research data, build a dataset for machine learning, or automate repetitive tasks, scraping web pages with Python gives you direct access to structured data hidden behind HTML. This guide takes you from your first HTTP request to a production-ready scraper.

What is Web Scraping?

Web scraping is the automated extraction of data from websites. A scraper:

  • Fetches the HTML content of a webpage using HTTP requests
  • Parses the HTML to find and extract specific data elements
  • Structures the extracted data into a usable format (CSV, JSON, database)

Think of it as programmatically browsing the web — but instead of reading with your eyes, your code reads and collects.

Tools You'll Need

We'll use two core libraries that are the industry standard for Python web scraping:

  • requests — sends HTTP requests to fetch web pages
  • BeautifulSoup (from the bs4 package) — parses HTML and extracts data
pip install requests beautifulsoup4

Your First Scraper: Fetch a Page

Let's start with the simplest possible scraper — fetching a webpage and checking the response:

import requests

url = "https://quotes.toscrape.com/"
response = requests.get(url)

# Always check the status code
print(f"Status: {response.status_code}")  # 200 means success
print(f"Length: {len(response.text)} bytes")

# response.text contains the raw HTML
print(response.text[:200])

The status_code tells you whether the request succeeded:

  • 200 — Success, the page loaded
  • 404 — Not found, the URL doesn't exist
  • 403 — Forbidden, the server rejected your request
  • 429 — Too many requests, you're being rate-limited

Parse HTML with BeautifulSoup

Raw HTML is a wall of text. BeautifulSoup turns it into a navigable tree you can query:

import requests
from bs4 import BeautifulSoup

response = requests.get("https://quotes.toscrape.com/")
soup = BeautifulSoup(response.text, "html.parser")

# Find all quote elements
quotes = soup.find_all("span", class_="text")
for quote in quotes:
    print(quote.get_text())

Output:

"The world as we have created it is a process of our thinking..."
"The person, be it gentleman or lady, who has not pleasure..."
"Imperfection is beauty..."
...

Key BeautifulSoup methods:

  • find() — returns the first matching element
  • find_all() — returns all matching elements as a list
  • get_text() — extracts visible text from an element
  • get("href") — gets an attribute value (like a link URL)

Select Elements by CSS Selector

BeautifulSoup supports CSS selectors via select(), which is often cleaner than chaining find methods:

# Using find_all (old style)
authors = soup.find_all("small", class_="author")

# Using CSS selectors (new style — preferred)
authors = soup.select("small.author")

# More complex selectors
quote_texts = soup.select("div.quote span.text")
author_links = soup.select("a[href*='author']")

for author in authors[:5]:
    print(author.get_text())

CSS selector tips:

  • div.quote — div elements with class "quote"
  • a[href] — all anchor tags with an href attribute
  • span.text — span elements with class "text"
  • .author — any element with class "author"
  • #main — element with id "main"

Extract Structured Data: A Real Example

Let's build a scraper that extracts quotes, authors, and tags from the quotes website:

import requests
from bs4 import BeautifulSoup

def scrape_quotes(url):
    """Extract quotes, authors, and tags from a page."""
    response = requests.get(url)
    response.raise_for_status()  # Raise exception for 4xx/5xx
    soup = BeautifulSoup(response.text, "html.parser")

    results = []
    for quote_div in soup.select("div.quote"):
        quote = {
            "text": quote_div.select_one("span.text").get_text(),
            "author": quote_div.select_one("small.author").get_text(),
            "tags": [tag.get_text() for tag in quote_div.select("a.tag")]
        }
        results.append(quote)

    return results

quotes = scrape_quotes("https://quotes.toscrape.com/")
print(f"Found {len(quotes)} quotes on page 1")
for q in quotes[:3]:
    print(f"  — {q['author']}: {q['text'][:60]}...")
    print(f"    Tags: {', '.join(q['tags'])}")

Handle Pagination

Most websites split data across multiple pages. A good scraper navigates all pages automatically:

import requests
from bs4 import BeautifulSoup
import time

def scrape_all_quotes(base_url="https://quotes.toscrape.com/page/"):
    """Scrape quotes from all pages."""
    all_quotes = []
    page = 1

    while True:
        url = f"{base_url}{page}/"
        print(f"Scraping page {page}...")

        response = requests.get(url)
        if response.status_code != 200:
            print(f"Page {page} not found. Done!")
            break

        soup = BeautifulSoup(response.text, "html.parser")
        quotes = []

        for quote_div in soup.select("div.quote"):
            quotes.append({
                "text": quote_div.select_one("span.text").get_text(),
                "author": quote_div.select_one("small.author").get_text(),
                "tags": [tag.get_text() for tag in quote_div.select("a.tag")]
            })

        all_quotes.extend(quotes)
        print(f"  Collected {len(quotes)} quotes from page {page}")

        # Check if there's a next page
        next_btn = soup.select_one("li.next a")
        if not next_btn:
            print("No more pages.")
            break

        # Be polite — wait between requests
        time.sleep(1)
        page += 1

    return all_quotes

quotes = scrape_all_quotes()
print(f"\nTotal: {len(quotes)} quotes scraped")

The key pattern: scrape → check for next page → sleep → repeat.

Save Data to CSV

Raw scraped data is useless if you can't store it. Python's built-in csv module makes this trivial:

import csv

def save_to_csv(quotes, filename="quotes.csv"):
    """Save quotes list to a CSV file."""
    if not quotes:
        print("No data to save!")
        return

    # Write CSV with all fields
    with open(filename, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=["text", "author", "tags"])
        writer.writeheader()
        for quote in quotes:
            quote["tags"] = "; ".join(quote["tags"])  # Join tags for CSV
            writer.writerow(quote)

    print(f"Saved {len(quotes)} quotes to {filename}")

save_to_csv(quotes)

The resulting CSV opens perfectly in Excel, Google Sheets, or any data tool.

Be a Responsible Scraper

Web scraping has rules. Follow them or get blocked (or worse):

1. Check robots.txt

Every website has a robots.txt file that tells scrapers what's allowed:

import requests

# Check robots.txt before scraping
def check_robots(url):
    url = url.rstrip("/")
    robot_url = f"{url}/robots.txt"
    response = requests.get(robot_url)
    if response.status_code == 200:
        print("robots.txt rules:")
        print(response.text[:500])
        return True
    print("No robots.txt found — proceed carefully")
    return False

check_robots("https://quotes.toscrape.com/")

2. Add Delays Between Requests

Never hammer a server with rapid requests. Add time.sleep() between each request:

import time
import random

# Sleep 1-3 seconds between requests
time.sleep(random.uniform(1, 3))

3. Set a User-Agent Header

Many servers block requests without a proper User-Agent. Identify yourself honestly:

headers = {
    "User-Agent": "MyScraperBot/1.0 (mailto:you@example.com)"
}
response = requests.get(url, headers=headers)

4. Handle Errors Gracefully

Websites go down, change, or block you. Always handle failures:

import requests
from requests.exceptions import RequestException, Timeout

def safe_fetch(url, retries=3):
    """Fetch a URL with retries and error handling."""
    headers = {"User-Agent": "MyScraperBot/1.0"}

    for attempt in range(retries):
        try:
            response = requests.get(url, headers=headers, timeout=10)
            response.raise_for_status()
            return response
        except Timeout:
            print(f"Timeout on attempt {attempt + 1}")
        except RequestException as e:
            print(f"Request error: {e}")
        except Exception as e:
            print(f"Unexpected error: {e}")

        if attempt < retries - 1:
            time.sleep(2 ** attempt)  # Exponential backoff

    print("All retries failed!")
    return None

Complete Scraper Project

Here's a production-ready scraper combining everything:

#!/usr/bin/env python3
"""Quote Scraper — Scrape quotes.toscrape.com and save to CSV."""

import requests
from bs4 import BeautifulSoup
import csv
import time
import random
from urllib.parse import urljoin

HEADERS = {
    "User-Agent": "EducationalScraper/1.0 (mailto:student@example.com)"
}

def scrape_page(page_num):
    """Scrape a single page and return quotes."""
    url = f"https://quotes.toscrape.com/page/{page_num}/"
    response = requests.get(url, headers=HEADERS, timeout=10)

    if response.status_code != 200:
        return None

    soup = BeautifulSoup(response.text, "html.parser")
    quotes = []

    for div in soup.select("div.quote"):
        quotes.append({
            "text": div.select_one("span.text").get_text(strip=True),
            "author": div.select_one("small.author").get_text(strip=True),
            "tags": [t.get_text() for t in div.select("a.tag")],
            "author_url": urljoin(url, div.select_one("a")["href"])
        })

    return quotes

def scrape_all():
    """Scrape all pages, saving results to CSV."""
    all_quotes = []
    page = 1

    while True:
        print(f"Scraping page {page}...")
        quotes = scrape_page(page)

        if quotes is None:
            print(f"Page {page} not found — scraping complete!")
            break

        all_quotes.extend(quotes)
        print(f"  Got {len(quotes)} quotes (total: {len(all_quotes)})")

        # Polite delay
        time.sleep(random.uniform(1, 2))
        page += 1

    # Save to CSV
    if all_quotes:
        filename = "quotes.csv"
        with open(filename, "w", newline="", encoding="utf-8") as f:
            writer = csv.DictWriter(f, fieldnames=["text", "author", "tags", "author_url"])
            writer.writeheader()
            for q in all_quotes:
                q["tags"] = "; ".join(q["tags"])
                writer.writerow(q)
        print(f"\n✅ Saved {len(all_quotes)} quotes to {filename}")
    else:
        print("No quotes scraped.")

if __name__ == "__main__":
    scrape_all()

When to Use What Tool

Not every website is the same. Choose the right tool for the job:

Scenario Tool
Static HTML pages requests + BeautifulSoup
Pages loaded by JavaScript playwright or selenium
Websites with an API requests to the API endpoint
Large-scale, distributed scraping scrapy framework
JSON APIs (no HTML) requests + .json()

Key Takeaways

  • Use requests to fetch web pages and BeautifulSoup to parse HTML
  • CSS selectors (select()) are the most readable way to find elements
  • Always handle pagination, errors, and retries gracefully
  • Be responsible: respect robots.txt, add delays, and identify your bot
  • Save structured data to CSV for analysis and reuse

Web scraping opens a world of data at your fingertips. Start small with practice sites, build confidence, then tackle real-world projects. The patterns in this guide — fetch, parse, extract, save, repeat — form the foundation of every successful scraper.
