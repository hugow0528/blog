Python Web Scraping with BeautifulSoup: Beginner Guide

June 22, 2026 · 9 min read

Web scraping lets your Python programs extract data from websites automatically. Collect product prices, monitor news articles, aggregate job listings, or gather research data — all with a few lines of code. This guide teaches you everything from fetching a page to building a reusable scraping tool.

What Is Web Scraping?

Web scraping is the process of programmatically downloading web pages and extracting specific information. A human visits a website, reads the content, and writes down what they need. Web scraping does the same thing, but automatically.

The two tools we'll use:

  • requests — Downloads the HTML of a web page
  • BeautifulSoup — Parses the HTML and lets you find specific elements
Legal note: Always check a website's robots.txt file (e.g., example.com/robots.txt) and Terms of Service before scraping. Be polite — add delays between requests and don't overwhelm servers.

Scrape Your First Page

Let's extract headlines from Hacker News, which has a clean, well-structured layout perfect for learning:

import requests
from bs4 import BeautifulSoup

# 1. Download the page
url = "https://news.ycombinator.com"
response = requests.get(url)
response.raise_for_status()  # Raise an error for bad status codes

# 2. Parse the HTML
soup = BeautifulSoup(response.text, "html.parser")

# 3. Find all story links (Hacker News uses class "titleline")
stories = soup.find_all("span", class_="titleline")

print(f"Found {len(stories)} stories:\n")

for i, story in enumerate(stories[:5], 1):  # Show first 5
    link = story.find("a")
    title = link.text
    href = link["href"]
    print(f"{i}. {title}")
    print(f"   {href}")
    print()

Output:

Found 30 stories:

1. A new programming language for the browser
   https://example.com/newlang

2. How we scaled our app to 1M users
   https://example.com/scaling

3. The best VS Code extensions in 2026
   https://example.com/vscode-ext

Key concepts:

  • BeautifulSoup(response.text, "html.parser") — Parses the raw HTML into a navigable tree
  • soup.find_all(tag, class_=name) — Finds all elements matching the criteria
  • element.find(tag) — Finds the first matching child element
  • element.text — Gets the text content inside an element
  • element["href"] — Gets the value of an attribute

Understanding the HTML Tree

BeautifulSoup lets you navigate HTML like a family tree:

# Navigate the tree
soup.find("div")              # Find first <div>
soup.find("div", id="main")   # Find <div id="main">
soup.find("div", class_="content")  # Find <div class="content">

# Find all matching elements
soup.find_all("a")            # All <a> tags
soup.find_all("p", class_="text")  # All <p class="text">

# Navigate from an element
element.parent               # Go up to parent
element.children             # Go down to children
element.next_sibling         # Next element at same level
element.find_next("p")       # Find next <p> tag (anywhere below)

# CSS selectors (like JavaScript's querySelector)
soup.select("div.content p.text")    # <p class="text"> inside <div class="content">
soup.select("ul.list > li")         # Direct children <li> of <ul class="list">
soup.select_one("h1")              # First <h1> (returns single element)

Extracting Structured Data: A Price Tracker

Let's build a more realistic scraper that extracts structured data. We'll scrape book data from Books to Scrape — a practice website designed specifically for learning web scraping:

import requests
from bs4 import BeautifulSoup
import csv

# Fetch the main page
url = "https://books.toscrape.com/"
response = requests.get(url)
response.raise_for_status()

soup = BeautifulSoup(response.text, "html.parser")

# Find all book entries
books = soup.find_all("article", class_="product_pod")

# Extract structured data
book_data = []
for book in books:
    title = book.h3.find("a")["title"]
    
    # Extract price (e.g., "£51.77")
    price = book.find("p", class_="price_color").text
    
    # Extract star rating
    star = book.find("p", class_="star-rating")
    rating = star["class"][1] if star else "No rating"  # e.g., "Three"
    
    # Extract availability
    availability = book.find("p", class_="instock availability").text.strip()
    
    book_data.append({
        "title": title,
        "price": price,
        "rating": rating,
        "in_stock": "Yes" in availability
    })

# Print first 5 books
for book in book_data[:5]:
    print(f"📖 {book['title'][:40]}")
    print(f"   💰 {book['price']} | ⭐ {book['rating']} | {'✅' if book['in_stock'] else '❌'}")
    print()

# Save to CSV
with open("books.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["title", "price", "rating", "in_stock"])
    writer.writeheader()
    writer.writerows(book_data)

print(f"Saved {len(book_data)} books to books.csv")

Handling Multiple Pages

Real scraping projects need to handle pagination. Here's how to scrape all pages:

import requests
from bs4 import BeautifulSoup
import time

def scrape_all_books():
    base_url = "https://books.toscrape.com/"
    all_books = []
    current_url = base_url
    page = 1
    
    while current_url:
        print(f"Scraping page {page}...")
        
        response = requests.get(current_url)
        response.raise_for_status()
        
        soup = BeautifulSoup(response.text, "html.parser")
        
        # Extract books from current page
        for book in soup.find_all("article", class_="product_pod"):
            title = book.h3.find("a")["title"]
            price = book.find("p", class_="price_color").text
            all_books.append({"title": title, "price": price})
        
        # Find the "next page" link
        next_btn = soup.find("li", class_="next")
        if next_btn and next_btn.find("a"):
            next_link = next_btn.find("a")["href"]
            # Convert relative URL to absolute
            current_url = base_url + next_link
            page += 1
            time.sleep(1)  # Be polite: wait 1 second between pages
        else:
            current_url = None  # No more pages
    
    print(f"\nTotal: {len(all_books)} books scraped")
    return all_books

books = scrape_all_books()

Building a Reusable Scraper Class

Let's wrap everything into a reusable class with error handling:

# scraper.py
import requests
from bs4 import BeautifulSoup
import time
from dataclasses import dataclass, asdict
from typing import Optional

@dataclass
class Book:
    title: str
    price: float
    rating: str
    in_stock: bool
    url: str

class BookScraper:
    """A reusable web scraper for the books.toscrape.com site."""
    
    def __init__(self, delay=1.0, user_agent=None):
        self.base_url = "https://books.toscrape.com/"
        self.delay = delay
        self.session = requests.Session()
        
        if user_agent:
            self.session.headers.update({"User-Agent": user_agent})
        else:
            # Default to a browser-like user agent
            self.session.headers.update({
                "User-Agent": "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7)"
                "PythonScraper/1.0"
            })
    
    def fetch_page(self, url: str) -> BeautifulSoup:
        """Fetch and parse a single page."""
        try:
            response = self.session.get(url, timeout=10)
            response.raise_for_status()
            return BeautifulSoup(response.text, "html.parser")
        except requests.exceptions.Timeout:
            print(f"⏱️  Timeout fetching {url}")
        except requests.exceptions.RequestException as e:
            print(f"❌ Error fetching {url}: {e}")
        return None
    
    def parse_books(self, soup: BeautifulSoup) -> list[Book]:
        """Extract book data from a parsed page."""
        books = []
        page_url = self.session.url  # Track which page we're on
        
        for article in soup.find_all("article", class_="product_pod"):
            try:
                link_tag = article.h3.find("a")
                title = link_tag["title"]
                book_url = self.base_url + link_tag["href"]
                
                price_text = article.find("p", class_="price_color").text
                price = float(price_text.replace("£", ""))
                
                star = article.find("p", class_="star-rating")
                rating = star["class"][1] if star else "No rating"
                
                stock_text = article.find("p", class_="instock availability").text
                in_stock = "In stock" in stock_text
                
                books.append(Book(
                    title=title,
                    price=price,
                    rating=rating,
                    in_stock=in_stock,
                    url=book_url
                ))
            except (KeyError, AttributeError, ValueError) as e:
                print(f"⚠️  Skipping malformed book entry: {e}")
                continue
        
        return books
    
    def scrape_all(self, max_pages: Optional[int] = None) -> list[Book]:
        """Scrape all books, optionally limiting the number of pages."""
        all_books = []
        current_url = self.base_url
        page = 0
        
        while current_url and (max_pages is None or page < max_pages):
            page += 1
            print(f"📄 Page {page}: {current_url}")
            
            soup = self.fetch_page(current_url)
            if not soup:
                break
            
            books = self.parse_books(soup)
            all_books.extend(books)
            print(f"   → Found {len(books)} books (total: {len(all_books)})")
            
            # Navigate to next page
            next_li = soup.find("li", class_="next")
            if next_li and next_li.find("a"):
                current_url = self.base_url + next_li.find("a")["href"]
                time.sleep(self.delay)
            else:
                current_url = None
        
        print(f"\n✅ Done! Scraped {len(all_books)} books in {page} pages.")
        return all_books

# Usage
if __name__ == "__main__":
    scraper = BookScraper(delay=1.0)
    books = scraper.scrape_all(max_pages=3)  # Just first 3 pages for demo
    
    # Show most expensive books
    sorted_books = sorted(books, key=lambda b: b.price, reverse=True)
    print("\n🏆 Top 5 Most Expensive Books:")
    for book in sorted_books[:5]:
        print(f"  {book.price:>7} | {book.title[:45]}")

Respectful Scraping: Best Practices

  • Add delays — time.sleep(1) between requests to avoid overwhelming the server
  • Check robots.txt — Every website should have one. Respect its rules.
  • Use a proper User-Agent — Don't hide who you are. Include your project name.
  • Handle errors gracefully — Networks fail, pages change, servers go down. Always use try/except.
  • Set timeouts — Never let a request hang forever. Use timeout=10.
  • Cache results — Don't re-scrape data you already have. Save to CSV, JSON, or a database.
  • Use APIs when available — If a site offers an API, prefer it over scraping. It's more reliable and usually faster.

Going Beyond: Selenium for JavaScript Pages

BeautifulSoup can only parse static HTML. For sites that load content with JavaScript (React, Vue, etc.), you need a real browser. Enter Selenium:

# pip install selenium webdriver-manager
from selenium import webdriver
from selenium.webdriver.common.by import By
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.service import Service

# Set up headless Chrome
options = webdriver.ChromeOptions()
options.add_argument("--headless")  # No GUI — runs in background
options.add_argument("--no-sandbox")
options.add_argument("--disable-dev-shm-usage")

driver = webdriver.Chrome(
    service=Service(ChromeDriverManager().install()),
    options=options
)

try:
    driver.get("https://example.com/dynamic-page")
    
    # Wait for content to load (up to 10 seconds)
    from selenium.webdriver.support.ui import WebDriverWait
    from selenium.webdriver.support import expected_conditions as EC
    
    element = WebDriverWait(driver, 10).until(
        EC.presence_of_element_located((By.CLASS_NAME, "loaded-content"))
    )
    
    # Now you can get the rendered HTML
    html = driver.page_source
    
    # Use BeautifulSoup on the rendered HTML
    soup = BeautifulSoup(html, "html.parser")
    # ... extract data as normal ...
    
finally:
    driver.quit()

Quick Reference

  • requests.get(url) — Download a web page
  • BeautifulSoup(html, "html.parser") — Parse HTML
  • soup.find_all(tag, class_=name) — Find all matching elements
  • soup.select("css selector") — Find elements with CSS selectors
  • element.text — Get text content
  • element["attribute"] — Get an attribute value
  • element.parent — Navigate up the HTML tree
  • time.sleep(n) — Pause between requests (be polite!)
  • response.raise_for_status() — Raise error on HTTP failures
