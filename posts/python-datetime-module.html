Python datetime Module: Dates, Times, Timezones & Formatting — Complete Guide

July 12, 2026 · 11 min read

Working with dates and times is one of the most common tasks in programming — scheduling tasks, calculating durations, formatting timestamps, comparing deadlines, and handling user input. Python's built-in datetime module handles all of this, but it has a learning curve. This guide covers everything from creating your first date object to handling timezones like a pro.

The datetime Module: Four Key Classes

The datetime module provides four main classes you'll use constantly:

ClassWhat It RepresentsExample
dateA calendar date (no time)2026-07-12
timeA time of day (no date)14:30:00
datetimeBoth date and time2026-07-12 14:30:00
timedeltaA duration / difference3 days, 5 hours

Creating Dates and Times

from datetime import date, time, datetime, timedelta

# Get current date, time, and datetime
today = date.today()
now = datetime.now()
print(today)   # 2026-07-12
print(now)     # 2026-07-12 14:30:45.123456

# Create specific dates
birthday = date(1995, 3, 15)
print(birthday)  # 1995-03-15

# Create specific datetime
meeting = datetime(2026, 7, 15, 10, 30, 0)
print(meeting)   # 2026-07-15 10:30:00

# Create just a time
alarm = time(7, 0, 0)
print(alarm)     # 07:00:00

Accessing Date Components

Every datetime object gives you easy access to individual components:

dt = datetime(2026, 7, 12, 14, 30, 45, 123456)

print(dt.year)        # 2026
print(dt.month)       # 7
print(dt.day)         # 12
print(dt.hour)        # 14
print(dt.minute)      # 30
print(dt.second)      # 45
print(dt.microsecond) # 123456

# Day of the week (Monday = 0, Sunday = 6)
print(dt.weekday())        # 6 (Sunday)
print(dt.isoweekday())     # 7 (Sunday)
print(dt.strftime("%A"))   # "Sunday"

# Check if it's a leap year
from calendar import isleap
print(isleap(2026))  # False
print(isleap(2024))  # True

Formatting Dates with strftime()

The strftime() method converts a datetime object to a formatted string. The format codes are the most important thing to memorize:

dt = datetime(2026, 7, 12, 14, 30, 45)

# Common format codes
print(dt.strftime("%Y-%m-%d"))       # 2026-07-12
print(dt.strftime("%d/%m/%Y"))       # 12/07/2026
print(dt.strftime("%B %d, %Y"))      # July 12, 2026
print(dt.strftime("%a, %d %b %Y"))   # Sun, 12 Jul 2026
print(dt.strftime("%I:%M %p"))       # 02:30 PM
print(dt.strftime("%H:%M:%S"))       # 14:30:45

# ISO 8601 format (recommended for APIs)
print(dt.isoformat())                # 2026-07-12T14:30:45

# Custom human-readable format
print(dt.strftime("%A, %B %d at %I:%M %p"))
# Sunday, July 12 at 02:30 PM

Parsing Dates with strptime()

The strptime() method does the reverse — parse a formatted string into a datetime object. Use the same format codes as strftime():

from datetime import datetime

# Parse different date formats
dt1 = datetime.strptime("2026-07-12", "%Y-%m-%d")
dt2 = datetime.strptime("12/07/2026", "%d/%m/%Y")
dt3 = datetime.strptime("July 12, 2026", "%B %d, %Y")
dt4 = datetime.strptime("2026-07-12T14:30:45", "%Y-%m-%dT%H:%M:%S")

print(dt1)  # 2026-07-12 00:00:00
print(dt2)  # 2026-07-12 00:00:00

# Parse with time
dt5 = datetime.strptime("12-Jul-2026 02:30 PM", "%d-%b-%Y %I:%M %p")
print(dt5)  # 2026-07-12 14:30:00

Date Arithmetic with timedelta

The timedelta class represents a duration. Add or subtract it from datetime objects:

from datetime import datetime, timedelta

now = datetime(2026, 7, 12, 10, 0, 0)

# Create timedeltas
one_day = timedelta(days=1)
one_hour = timedelta(hours=1)
three_days_2_hours = timedelta(days=3, hours=2)
one_week = timedelta(weeks=1)

# Add/subtract durations
tomorrow = now + one_day
yesterday = now - one_day
later = now + three_days_2_hours
next_week = now + one_week

print(tomorrow)   # 2026-07-13 10:00:00
print(yesterday)  # 2026-07-11 10:00:00
print(later)      # 2026-07-15 12:00:00

# timedelta supports all units: days, seconds, microseconds,
# milliseconds, minutes, hours, weeks

Calculating Differences Between Dates

Subtracting two datetime objects returns a timedelta — use it to find durations:

from datetime import datetime

start = datetime(2026, 1, 1, 9, 0)
end = datetime(2026, 7, 12, 17, 30)

diff = end - start
print(diff)              # 192 days, 8:30:00
print(diff.days)         # 192
print(diff.seconds)      # 30600 (8:30 in seconds)
print(diff.total_seconds())  # 16638600.0

# Human-readable difference
def readable_duration(td):
    days = td.days
    hours, remainder = divmod(td.seconds, 3600)
    minutes, seconds = divmod(remainder, 60)
    parts = []
    if days: parts.append(f"{days} day(s)")
    if hours: parts.append(f"{hours} hour(s)")
    if minutes: parts.append(f"{minutes} minute(s)")
    if seconds: parts.append(f"{seconds} second(s)")
    return " ".join(parts)

print(readable_duration(diff))
# 192 day(s) 8 hour(s) 30 minute(s)

Comparing Dates

Python datetime objects support direct comparison using <, >, <=, >=, ==:

from datetime import datetime

deadline = datetime(2026, 7, 15, 23, 59, 59)
now = datetime(2026, 7, 12, 14, 30)

if now < deadline:
    remaining = deadline - now
    print(f"⏰ {remaining.days} days until deadline")
    # ⏰ 3 days until deadline
elif now > deadline:
    late = now - deadline
    print(f"⚠️ {late.days} days past deadline")
else:
    print("🎯 Exactly at deadline!")

# Check if date is in the past
past_date = datetime(2025, 1, 1)
print(past_date < datetime.now())  # True

# Check if within a range
start = datetime(2026, 7, 1)
end = datetime(2026, 7, 31)
test = datetime(2026, 7, 15)
print(start <= test <= end)  # True

Working with Timezones

Python 3.9+ includes the zoneinfo module for timezone handling. Older versions can use pytz:

from datetime import datetime, timezone
from zoneinfo import ZoneInfo

# UTC time
utc_now = datetime.now(timezone.utc)
print(utc_now)  # 2026-07-12 14:30:45.123456+00:00

# Specific timezones
ny_time = datetime.now(ZoneInfo("America/New_York"))
tokyo_time = datetime.now(ZoneInfo("Asia/Tokyo"))
london_time = datetime.now(ZoneInfo("Europe/London"))

print(ny_time)    # 2026-07-12 10:30:45-04:00 (EDT)
print(tokyo_time) # 2026-07-13 02:30:45+09:00 (JST)
print(london_time)# 2026-07-12 19:30:45+01:00 (BST)

# Convert between timezones
naive = datetime(2026, 7, 12, 15, 0)  # No timezone
aware = naive.replace(tzinfo=ZoneInfo("America/New_York"))
tokyo = aware.astimezone(ZoneInfo("Asia/Tokyo"))

print(aware)  # 2026-07-12 15:00:00-04:00
print(tokyo)  # 2026-07-13 04:00:00+09:00

Golden rule: Always store and compare datetime objects in UTC. Only convert to local timezones for display to users.

Common Timezone Pitfalls

# ❌ BAD: Mixing naive and aware datetimes
naive = datetime(2026, 7, 12, 12, 0)
aware = datetime(2026, 7, 12, 12, 0, tzinfo=timezone.utc)
# naive < aware  → TypeError!

# ✅ GOOD: Always use aware datetimes
utc_dt = datetime(2026, 7, 12, 12, 0, tzinfo=timezone.utc)
local_dt = utc_dt.astimezone(ZoneInfo("Asia/Tokyo"))

# ✅ GOOD: Replace deprecated pytz.localize()
# Old (pytz):  tz.localize(naive)
# New (zoneinfo): naive.replace(tzinfo=ZoneInfo("Region/City"))

Complete Project: Deadline Tracker

Let's combine everything into a practical project:

from datetime import datetime, timedelta, timezone
from zoneinfo import ZoneInfo
import json

class DeadlineTracker:
    """Track deadlines with timezone support and notifications"""

    def __init__(self):
        self.deadlines = []

    def add_deadline(self, name, due_date, timezone_str="UTC"):
        """Add a deadline with timezone awareness"""
        dt = datetime.strptime(due_date, "%Y-%m-%d %H:%M")
        dt = dt.replace(tzinfo=ZoneInfo(timezone_str))

        self.deadlines.append({
            "name": name,
            "due": dt,
            "timezone": timezone_str,
            "created": datetime.now(timezone.utc)
        })
        print(f"  ✅ Added: '{name}' due {dt.strftime('%B %d, %Y at %I:%M %p')}")

    def get_status(self, deadline):
        """Return human-readable status for a deadline"""
        now = datetime.now(timezone.utc)
        due = deadline["due"].astimezone(timezone.utc)
        diff = due - now

        if diff.total_seconds() <= 0:
            late = abs(diff)
            days = late.days
            hours = late.seconds // 3600
            if days > 0:
                return f"🚨 OVERDUE by {days} day(s) and {hours} hour(s)"
            return f"🚨 OVERDUE by {hours} hour(s)"
        elif diff.days == 0:
            hours = diff.seconds // 3600
            return f"🔴 TODAY — {hours} hour(s) remaining"
        elif diff.days <= 7:
            return f"🟡 {diff.days} day(s) remaining"
        else:
            return f"🟢 {diff.days} day(s) remaining"

    def list_upcoming(self, limit=5):
        """List upcoming deadlines sorted by date"""
        now = datetime.now(timezone.utc)
        upcoming = [d for d in self.deadlines
                    if d["due"].astimezone(timezone.utc) >= now]
        upcoming.sort(key=lambda d: d["due"])

        for dl in upcoming[:limit]:
            status = self.get_status(dl)
            print(f"  {status}  → {dl['name']}")
            print(f"     Due: {dl['due'].strftime('%B %d, %Y at %I:%M %p (%Z)')}")

    def save(self, filename="deadlines.json"):
        """Serialize deadlines to JSON file"""
        data = []
        for dl in self.deadlines:
            data.append({
                "name": dl["name"],
                "due": dl["due"].isoformat(),
                "timezone": dl["timezone"],
                "created": dl["created"].isoformat()
            })
        with open(filename, "w") as f:
            json.dump(data, f, indent=2)
        print(f"  💾 Saved {len(data)} deadlines to {filename}")

    def load(self, filename="deadlines.json"):
        """Load deadlines from JSON file"""
        with open(filename, "r") as f:
            data = json.load(f)
        self.deadlines = []
        for item in data:
            dt = datetime.fromisoformat(item["due"])
            self.deadlines.append({
                "name": item["name"],
                "due": dt,
                "timezone": item["timezone"],
                "created": datetime.fromisoformat(item["created"])
            })
        print(f"  📂 Loaded {len(self.deadlines)} deadlines from {filename}")


# Usage
tracker = DeadlineTracker()
tracker.add_deadline("Deploy v2.0", "2026-07-15 18:00", "UTC")
tracker.add_deadline("Team meeting", "2026-07-13 09:00", "America/New_York")
tracker.add_deadline("Server maintenance", "2026-07-20 02:00", "Asia/Tokyo")

print("\n📋 Upcoming Deadlines:")
tracker.list_upcoming()

tracker.save()  # Persist to file

Best Practices Summary

  • Always use timezone-aware datetimes — avoid naive datetimes in production
  • Store everything in UTC — convert to local timezone only for display
  • Use ISO 8601 format (.isoformat()) for serialization and APIs
  • Use timedelta for date math — don't manually add days/hours
  • Use zoneinfo over pytz — it's built-in (Python 3.9+)
  • Always set tzinfo when creating datetimes, not after
  • Use .total_seconds() for duration calculations, not .seconds
  • Parse dates defensively — use try/except around strptime()
