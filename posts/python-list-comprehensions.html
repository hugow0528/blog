Python List Comprehensions & Generator Expressions: Write Cleaner, FASTER Code

2026-06-25 10 min read New

One of the first things that makes Python code look "Pythonic" is the use of list comprehensions. Instead of writing a four-line for loop to build a list, you can do it in a single readable expression. Combined with generator expressions and dictionary comprehensions, you'll write code that's shorter, faster, and easier to understand.

If you've ever written a loop just to collect results into a list, stop — there's a better way. Let's dive in.

1. The Basics: List Comprehensions

A list comprehension creates a new list by applying an expression to each item in an iterable. The syntax follows a clear pattern: [expression for item in iterable].

Here's the old way to square a list of numbers:

# Old way — for loop
squares = []
for n in [1, 2, 3, 4, 5]:
    squares.append(n ** 2)
print(squares)  # [1, 4, 9, 16, 25]

And here's the same thing with a list comprehension:

# New way — list comprehension
squares = [n ** 2 for n in [1, 2, 3, 4, 5]]
print(squares)  # [1, 4, 9, 16, 25]

Three lines compressed into one. And it actually runs faster because list comprehensions are optimized in CPython's internal loop.

2. Adding a Condition: Filtering with Comprehensions

You can add an if clause to filter items. This replaces a whole class of "loop with condition" patterns:

# Old way
evens = []
for n in range(1, 11):
    if n % 2 == 0:
        evens.append(n)
print(evens)  # [2, 4, 6, 8, 10]

# New way
evens = [n for n in range(1, 11) if n % 2 == 0]
print(evens)  # [2, 4, 6, 8, 10]

Real-world example — filter a list of filenames to only get Python files:

files = ["app.py", "readme.md", "main.py", "style.css", "test.py"]
python_files = [f for f in files if f.endswith(".py")]
print(python_files)  # ['app.py', 'main.py', 'test.py']

3. if/else Expressions in Comprehensions

You can also transform items conditionally. Note the different placement of the if/else:

# Transform: if/else goes BEFORE the for
labels = ["spam", "ham", "eggs"]
categories = ["meat" if x in ("spam", "ham") else "other" for x in labels]
print(categories)  # ['meat', 'meat', 'other']

# Filter: if goes AFTER the for (no else allowed)
meat_only = [x for x in labels if x in ("spam", "ham")]
print(meat_only)  # ['spam', 'ham']

# Both filter AND transform
scores = [85, 42, 91, 55, 78]
results = ["pass" if s >= 60 else "fail" for s in scores if s > 0]
print(results)  # ['pass', 'fail', 'pass', 'pass', 'pass']
Rule of thumb: If you have an else, it's a transformation (put if/else before for). If you don't have an else, it's a filter (put if after for).

4. Nested Loops in Comprehensions

You can nest loops. The order mirrors regular nested for-loops:

# Flatten a matrix (list of lists)
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Old way
flat = []
for row in matrix:
    for item in row:
        flat.append(item)
print(flat)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]

# Comprehension way
flat = [item for row in matrix for item in row]
print(flat)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]

With a filter condition:

# Get only even numbers from the matrix
flat_evens = [item for row in matrix for item in row if item % 2 == 0]
print(flat_evens)  # [2, 4, 6, 8]

5. Generator Expressions: Memory-Efficient Comprehensions

Change square brackets [] to parentheses () and you get a generator expression. Instead of building the entire list in memory, it yields items one at a time:

# List comprehension — builds entire list in memory
big_list = [x ** 2 for x in range(1000000)]

# Generator expression — generates on demand, uses minimal memory
big_gen = (x ** 2 for x in range(1000000))

# Both work the same in many contexts
print(sum(x for x in range(1000000)))  # Works great, no huge list in memory
print(list(x for x in range(10) if x % 2 == 0))  # Convert to list when needed

Generators are ideal when:

  • You're processing very large datasets
  • You only need to iterate once
  • You're chaining operations (sum, any, all, next)
# Practical example: find first matching log entry
logs = ["ERROR: disk full", "INFO: startup", "ERROR: timeout", "INFO: request"]

# Generator stops at first match — no need to process the rest
first_error = next(msg for msg in logs if "ERROR" in msg)
print(first_error)  # ERROR: disk full

# Count errors without building a list
error_count = sum(1 for msg in logs if "ERROR" in msg)
print(error_count)  # 2

6. Dictionary and Set Comprehensions

Python 3 supports the same comprehension syntax for dictionaries and sets:

# Dictionary comprehension
words = ["hello", "world", "python", "code"]
word_lengths = {w: len(w) for w in words}
print(word_lengths)
# {'hello': 5, 'world': 5, 'python': 6, 'code': 4}

# With a filter
short_words = {w: len(w) for w in words if len(w) <= 4}
print(short_words)  # {'code': 4}

# Set comprehension (unique values only)
fruits = ["apple", "banana", "apple", "cherry", "banana"]
unique = {f for f in fruits}
print(unique)  # {'apple', 'banana', 'cherry'}

7. Real-World Project: Data Cleaning Pipeline

Let's put everything together in a practical example. Imagine you have raw user data and need to clean and transform it:

raw_users = [
    {"name": "  Alice  ", "age": 28, "email": "alice@example.com"},
    {"name": "bob", "age": -5, "email": "bob"},           # invalid age & email
    {"name": "  Charlie  ", "age": 45, "email": "charlie@test.io"},
    {"name": "diana", "age": 17, "email": "diana@web.com"},  # underage
    {"name": "  Eve  ", "age": 33, "email": "eve@domain.org"},
]

# Step 1: Clean names (strip whitespace, capitalize)
cleaned = [
    {**u, "name": u["name"].strip().title()} for u in raw_users
]

# Step 2: Filter valid users (age 18+, has @ in email)
valid = [
    u for u in cleaned
    if u["age"] >= 18 and "@" in u["email"]
]

# Step 3: Create a lookup dict by email
user_lookup = {u["email"]: u["name"] for u in valid}

print(user_lookup)
# {'alice@example.com': 'Alice', 'charlie@test.io': 'Charlie', 'eve@domain.org': 'Eve'}

# Step 4: Quick stats using generators
avg_age = sum(u["age"] for u in valid) / len(valid)
print(f"Average age: {avg_age:.1f}")  # Average age: 35.3

8. When NOT to Use Comprehensions

List comprehensions are great, but don't force them everywhere. Avoid comprehensions when:

  • The logic is complex — if you need more than 2 nested loops or multiple conditions, a regular loop is clearer
  • You have side effects — comprehensions should create lists, not modify state
  • Readability suffers — if you need to explain the comprehension, write a loop instead
# BAD: Complex logic in comprehension — don't do this
result = [x * 2 if x > 0 and x % 3 == 0 else x + 1 for x in data if x is not None and isinstance(x, int)]

# GOOD: Clear, step-by-step loop
result = []
for x in data:
    if x is None or not isinstance(x, int):
        continue
    if x > 0 and x % 3 == 0:
        result.append(x * 2)
    else:
        result.append(x + 1)

Summary

List comprehensions and generator expressions are among Python's most beloved features. Here's the cheat sheet:

  • [expr for x in iterable] — basic list comprehension
  • [expr for x in iterable if cond] — with filter
  • [a if cond else b for x in iterable] — conditional transform
  • (expr for x in iterable) — memory-efficient generator
  • {k: v for k, v in iterable} — dictionary comprehension
  • {expr for x in iterable} — set comprehension

Start by replacing simple "build a list" loops with comprehensions. Once you're comfortable, add filters, conditionals, and nested loops. Your code will be shorter, faster, and unmistakably Pythonic.
