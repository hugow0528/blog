CSS Flexbox Layout: Align, Distribute & Responsive Design

July 19, 2026 11 min read

CSS Flexbox (Flexible Box Layout) is the most powerful layout tool in CSS for one-dimensional layouts — rows or columns of items. Whether you're centering a div (the classic CSS struggle), building a navigation bar, creating a responsive card grid, or aligning items in a form, Flexbox solves it in one line of code. Before Flexbox, developers used floats, tables, and JavaScript for layout. After Flexbox, all of that became a thing of the past.

This guide takes you from display: flex to production-ready layouts. Every concept is explained with visual reasoning and real HTML/CSS code you can copy and run immediately.

The Flexbox Mental Model

Flexbox has two parts: a container and items inside it.

  • Flex container: The parent element with display: flex
  • Flex items: Direct children of the container (only direct children are flex items)
  • Main axis: The primary direction items are laid out (horizontal by default)
  • Cross axis: The perpendicular direction

Here's the minimum code to make something flex:

<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>

<style>
.container {
  display: flex;        /* This makes it a flex container */
  gap: 16px;            /* Space between items */
}

.item {
  padding: 20px;
  background: #191a1b;
  border-radius: 8px;
  text-align: center;
}
</style>

That's it. Now the three items sit side by side with 16px gaps between them. No floats, no inline-block, no clearfix hacks.

flex-direction: Which Way Things Flow

By default, flex items lay out horizontally (left to right). Change the direction with flex-direction:

.container {
  display: flex;
}

/* Default: items go left → right (row) */
.row {
  flex-direction: row;
}

/* Items go right → left (row-reverse) */
.row-reverse {
  flex-direction: row-reverse;
}

/* Items go top → bottom (column) */
.column {
  flex-direction: column;
}

/* Items go bottom → top (column-reverse) */
.column-reverse {
  flex-direction: column-reverse;
}

Real-world use — vertical card stack:

<div class="card-stack">
  <div class="card">First</div>
  <div class="card">Second</div>
  <div class="card">Third</div>
</div>

<style>
.card-stack {
  display: flex;
  flex-direction: column;
  gap: 12px;
  max-width: 400px;
}
</style>

justify-content: Align on the Main Axis

justify-content controls how items are distributed along the main axis. This is the property you'll reach for most often:

/* Items start at the beginning (default) */
.start { justify-content: flex-start; }

/* Items pack to the end */
.end { justify-content: flex-end; }

/* Items center in the container — the #1 most used value */
.center { justify-content: center; }

/* Items spread out with equal space between them */
.between { justify-content: space-between; }

/* Equal space before first, between, and after last */
.around { justify-content: space-around; }

/* Equal space on all sides (visually cleanest) */
.evenly { justify-content: space-evenly; }

Real-world use — centered page layout:

<body>
  <div class="centered">
    <h1>Hello World</h1>
    <p>Perfectly centered</p>
  </div>
</body>

<style>
body {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
  margin: 0;
}

.centered {
  text-align: center;
}
</style>

This is the canonical "center a div" solution. Two properties: justify-content: center (horizontal) and align-items: center (vertical). Works on any viewport size.

align-items and align-content: Cross-Axis Alignment

While justify-content handles the main axis, align-items handles the cross axis:

/* Items stretch to fill container height (default) */
.stretch { align-items: stretch; }

/* Items align to the top/start */
.start { align-items: flex-start; }

/* Items align to the bottom/end */
.end { align-items: flex-end; }

/* Items center vertically */
.center { align-items: center; }

/* Items align to the baseline of text */
.baseline { align-items: baseline; }

Real-world use — navigation bar with logo and links:

<nav class="navbar">
  <div class="logo">MySite</div>
  <div class="links">
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
  </div>
</nav>

<style>
.navbar {
  display: flex;
  justify-content: space-between;  /* Logo left, links right */
  align-items: center;             /* Vertically center everything */
  padding: 16px 24px;
  background: #0f1011;
  border-bottom: 1px solid #23252a;
}

.links {
  display: flex;
  gap: 24px;
}

.links a {
  color: #d0d6e0;
  text-decoration: none;
}
</style>

flex-wrap: Handle Overflow

By default, flex items try to fit on one line and will shrink (or overflow). Enable wrapping so items flow to new lines:

/* All items on one line (default) — they shrink */
.nowrap { flex-wrap: nowrap; }

/* Items wrap to new lines when space runs out */
.wrap { flex-wrap: wrap; }

/* Items wrap but start from the last line */
.wrap-reverse { flex-wrap: wrap-reverse; }

Real-world use — responsive card grid:

<div class="card-grid">
  <div class="card">Card 1</div>
  <div class="card">Card 2</div>
  <div class="card">Card 3</div>
  <div class="card">Card 4</div>
  <div class="card">Card 5</div>
  <div class="card">Card 6</div>
</div>

<style>
.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  flex: 1 1 280px;     /* grow | shrink | basis */
  min-width: 250px;
  padding: 24px;
  background: #191a1b;
  border-radius: 8px;
  border: 1px solid #23252a;
}
</style>

The flex: 1 1 280px shorthand means: "grow to fill space, shrink if needed, but start at 280px wide." Combined with flex-wrap: wrap, this creates a responsive grid that shows 3 cards on desktop, 2 on tablet, and 1 on mobile — with zero media queries.

flex-grow, flex-shrink, and flex-basis

These three properties control how individual items behave. They can be set individually or with the flex shorthand:

/* flex: grow shrink basis */

/* Grow to fill space, don't shrink, base 300px */
.card { flex: 1 0 300px; }

/* Don't grow, don't shrink, fixed 200px */
.sidebar { flex: 0 0 200px; }

/* Grow equally, can shrink, no minimum */
.tab { flex: 1 1 0; }

/* Don't grow, can shrink if needed, auto width */
.logo { flex: 0 1 auto; }

/* Full shorthand: 1 1 280px is the same as */
.card {
  flex-grow: 1;      /* How much to grow relative to siblings */
  flex-shrink: 1;    /* How much to shrink when space is tight */
  flex-basis: 280px; /* Starting size before growing/shrinking */
}

Common patterns:

/* Two-column layout: sidebar + main content */
.layout {
  display: flex;
  gap: 24px;
}

.sidebar {
  flex: 0 0 250px;   /* Fixed width sidebar */
}

.main {
  flex: 1;           /* Takes all remaining space */
}

/* Footer: logo on left, links on right, copyright centered */
.footer {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 24px;
}

.footer .links {
  display: flex;
  gap: 16px;
}

align-self: Override per Item

Use align-self on individual items to override the container's align-items:

.container {
  display: flex;
  align-items: center;  /* Default: all items centered */
  height: 200px;
}

.item:nth-child(2) {
  align-self: flex-start;  /* This item goes to the top */
}

.item:nth-child(4) {
  align-self: flex-end;    /* This item goes to the bottom */
}

Real-world use — form with different input heights:

<div class="form-row">
  <label>Name</label>
  <input type="text" placeholder="Your name">
  <button type="submit">Send</button>
  <div class="help-text">Optional field</div>
</div>

<style>
.form-row {
  display: flex;
  align-items: center;
  gap: 12px;
}

.help-text {
  align-self: flex-start;  /* Align to top, not center */
  font-size: 12px;
  color: #8a8f98;
  margin-top: 24px;        /* Push it below the input */
}
</style>

order: Reorder Without Changing HTML

Flexbox lets you visually reorder items without touching the DOM. This is great for responsive layouts where mobile order differs from desktop:

<div class="content">
  <header>Header</header>
  <main>Main</main>
  <aside>Sidebar</aside>
  <footer>Footer</footer>
</div>

<style>
.content {
  display: flex;
  flex-direction: column;
}

/* Desktop: sidebar moves between header and main */
@media (min-width: 768px) {
  .content {
    flex-direction: row;
  }
  
  header { flex: 1; order: 1; }
  aside  { flex: 0 0 250px; order: 2; }
  main   { flex: 1; order: 3; }
  footer { order: 4; width: 100%; }
}

Real-World Layout Recipes

1. Holy Grail Layout:

<div class="holy-grail">
  <header>Header</header>
  <div class="body">
    <aside class="left">Nav</aside>
    <main>Content</main>
    <aside class="right">Widgets</aside>
  </div>
  <footer>Footer</footer>
</div>

<style>
.holy-grail {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}

.holy-grail header,
.holy-grail footer {
  padding: 16px;
  background: #0f1011;
}

.holy-grail .body {
  display: flex;
  flex: 1;                /* Fill remaining vertical space */
}

.left  { flex: 0 0 200px; }
.right { flex: 0 0 200px; }
main  { flex: 1; padding: 24px; }
</style>

2. Chat Message Bubbles:

<div class="chat">
  <div class="msg sent">
    <p>Hey, did you see the new release?</p>
    <span class="time">10:30 AM</span>
  </div>
  <div class="msg received">
    <p>Yes! The new CSS features are incredible.</p>
    <span class="time">10:31 AM</span>
  </div>
</div>

<style>
.chat {
  display: flex;
  flex-direction: column;
  gap: 8px;
  max-width: 500px;
}

.msg {
  display: flex;
  flex-direction: column;
  max-width: 80%;
  padding: 12px 16px;
  border-radius: 12px;
}

.sent {
  align-self: flex-end;
  background: #5e6ad2;
  border-bottom-right-radius: 4px;
}

.received {
  align-self: flex-start;
  background: #191a1b;
  border-bottom-left-radius: 4px;
}

.time {
  font-size: 10px;
  opacity: 0.6;
  margin-top: 4px;
}
</style>

3. Image Gallery with Caption Overlay:

<div class="gallery">
  <div class="gallery-item">
    <div class="image">🖼️</div>
    <div class="caption">
      <h3>Mountain View</h3>
      <p>Taken during sunrise</p>
    </div>
  </div>
  <!-- more items... -->
</div>

<style>
.gallery {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.gallery-item {
  flex: 1 1 300px;
  display: flex;
  flex-direction: column;
  background: #191a1b;
  border-radius: 8px;
  overflow: hidden;
}

.image {
  height: 200px;
  display: flex;
  justify-content: center;
  align-items: center;
  font-size: 64px;
}

.caption {
  padding: 16px;
  flex: 1;  /* Pushes content to fill available space */
  display: flex;
  flex-direction: column;
  justify-content: space-between;
}
</style>

Common Gotchas

  • Flex items only affect direct children. Nested elements don't inherit flex behavior — you need display: flex on each container level.
  • Margin auto is a flex superpower. Set margin-left: auto on an item to push everything else to the left. This is cleaner than justify-content: space-between when you need a specific gap pattern.
  • Min-width: 0 on flex items. By default, flex items won't shrink below their content size. Add min-width: 0 (or overflow: hidden) to allow shrinking past content.
  • Flexbox is one-dimensional. For two-dimensional layouts (rows AND columns simultaneously), use CSS Grid instead. Flexbox + Grid together cover every layout scenario.
  • gap works in all modern browsers. You no longer need negative margins or calc() for spacing between flex items.

Flexbox Quick Reference

Property Where Common Values
display Container flex, inline-flex
flex-direction Container row, column, row-reverse
justify-content Container center, space-between, space-evenly
align-items Container center, flex-start, stretch
flex-wrap Container wrap, nowrap
gap Container 8px, 16px, 1rem
flex Item 1, 0 0 200px, 1 1 280px
align-self Item flex-start, flex-end, center
order Item -1 (first), 1, 2
