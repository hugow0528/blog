Building RESTful APIs with Python Flask — Complete Beginner's Guide

July 8, 2026 · 12 min read

You know Python basics — variables, functions, loops. Now you want to build something the internet can talk to: a REST API. Maybe you're building a backend for a React app, exposing data to mobile devices, or creating a microservice.

Flask is the perfect framework to start. It's lightweight, has a gentle learning curve, and doesn't hide what's happening under the hood. In this tutorial, we'll build a complete task management API from scratch — with routes, request validation, error handling, and database storage.

What is a REST API?

REST (Representational State Transfer) is an architectural style for designing networked applications. In practice, it means your API uses HTTP methods to perform actions on resources:

GET    /tasks        → Get all tasks
POST   /tasks        → Create a new task
GET    /tasks/1      → Get task #1
PUT    /tasks/1      → Update task #1
DELETE /tasks/1      → Delete task #1

Each URL identifies a resource (a task), and the HTTP method defines the action. The API returns JSON responses with appropriate status codes.

Start with a clean virtual environment:

2. Your First Flask Route

Create app.py:

from flask import Flask

app = Flask(__name__)

@app.route("/")
def hello():
    return {"message": "Task API is running!"}

if __name__ == "__main__":
    app.run(debug=True)

Run it:

python app.py
# * Running on http://127.0.0.1:5000

# Test with curl or your browser:
curl http://127.0.0.1:5000
# {"message":"Task API is running!"}

That's it — you just built a web server in 10 lines. Flask's @app.route() decorator maps a URL path to a Python function. The function returns a response, which Flask converts to JSON automatically when you return a dictionary.

3. In-Memory Task Storage

Let's build the full CRUD API. We'll use a list to store tasks in memory (later we'll add SQLite):

from flask import Flask, request, jsonify

app = Flask(__name__)

# In-memory storage
tasks = []
next_id = 1

# GET /tasks — List all tasks
@app.route("/tasks", methods=["GET"])
def get_tasks():
    return jsonify({"tasks": tasks}), 200

# POST /tasks — Create a new task
@app.route("/tasks", methods=["POST"])
def create_task():
    global next_id
    data = request.get_json()

    # Validate required fields
    if not data or not data.get("title"):
        return jsonify({"error": "Title is required"}), 400

    task = {
        "id": next_id,
        "title": data["title"],
        "description": data.get("description", ""),
        "completed": False
    }
    tasks.append(task)
    next_id += 1

    return jsonify({"task": task}), 201

# GET /tasks/<id> — Get a single task
@app.route("/tasks/<int:task_id>", methods=["GET"])
def get_task(task_id):
    task = next((t for t in tasks if t["id"] == task_id), None)
    if not task:
        return jsonify({"error": "Task not found"}), 404
    return jsonify({"task": task}), 200

# PUT /tasks/<id> — Update a task
@app.route("/tasks/<int:task_id>", methods=["PUT"])
def update_task(task_id):
    task = next((t for t in tasks if t["id"] == task_id), None)
    if not task:
        return jsonify({"error": "Task not found"}), 404

    data = request.get_json()
    if data.get("title"):
        task["title"] = data["title"]
    if "description" in data:
        task["description"] = data["description"]
    if "completed" in data:
        task["completed"] = data["completed"]

    return jsonify({"task": task}), 200

# DELETE /tasks/<id> — Delete a task
@app.route("/tasks/<int:task_id>", methods=["DELETE"])
def delete_task(task_id):
    global tasks
    task = next((t for t in tasks if t["id"] == task_id), None)
    if not task:
        return jsonify({"error": "Task not found"}), 404

    tasks = [t for t in tasks if t["id"] != task_id]
    return jsonify({"message": "Task deleted"}), 200

if __name__ == "__main__":
    app.run(debug=True)

4. Add SQLite Database

In-memory storage disappears when the server restarts. Let's add SQLite — Python's built-in database:

import sqlite3
from flask import Flask, request, jsonify, g

app = Flask(__name__)
DATABASE = "tasks.db"

def get_db():
    """Get database connection for current request."""
    if "db" not in g:
        g.db = sqlite3.connect(DATABASE)
        g.db.row_factory = sqlite3.Row  # Access columns by name
    return g.db

@app.teardown_appcontext
def close_db(exception):
    """Close database connection at end of request."""
    db = g.pop("db", None)
    if db is not None:
        db.close()

def init_db():
    """Create the tasks table if it doesn't exist."""
    db = get_db()
    db.execute("""
        CREATE TABLE IF NOT EXISTS tasks (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            title TEXT NOT NULL,
            description TEXT DEFAULT '',
            completed INTEGER DEFAULT 0
        )
    """)
    db.commit()

# Initialize on startup
with app.app_context():
    init_db()

# Updated routes using the database
@app.route("/tasks", methods=["GET"])
def get_tasks():
    db = get_db()
    rows = db.execute("SELECT * FROM tasks ORDER BY id DESC").fetchall()
    tasks = [dict(row) for row in rows]
    # Convert completed: 0/1 → False/True
    for t in tasks:
        t["completed"] = bool(t["completed"])
    return jsonify({"tasks": tasks}), 200

@app.route("/tasks", methods=["POST"])
def create_task():
    data = request.get_json()
    if not data or not data.get("title"):
        return jsonify({"error": "Title is required"}), 400

    db = get_db()
    cursor = db.execute(
        "INSERT INTO tasks (title, description, completed) VALUES (?, ?, ?)",
        (data["title"], data.get("description", ""), 0)
    )
    db.commit()

    task = db.execute("SELECT * FROM tasks WHERE id = ?", (cursor.lastrowid,)).fetchone()
    task = dict(task)
    task["completed"] = bool(task["completed"])
    return jsonify({"task": task}), 201

@app.route("/tasks/<int:task_id>", methods=["GET"])
def get_task(task_id):
    db = get_db()
    task = db.execute("SELECT * FROM tasks WHERE id = ?", (task_id,)).fetchone()
    if not task:
        return jsonify({"error": "Task not found"}), 404
    task = dict(task)
    task["completed"] = bool(task["completed"])
    return jsonify({"task": task}), 200

@app.route("/tasks/<int:task_id>", methods=["PUT"])
def update_task(task_id):
    db = get_db()
    task = db.execute("SELECT * FROM tasks WHERE id = ?", (task_id,)).fetchone()
    if not task:
        return jsonify({"error": "Task not found"}), 404

    data = request.get_json()
    updates = []
    values = []

    if "title" in data:
        updates.append("title = ?")
        values.append(data["title"])
    if "description" in data:
        updates.append("description = ?")
        values.append(data["description"])
    if "completed" in data:
        updates.append("completed = ?")
        values.append(1 if data["completed"] else 0)

    if updates:
        values.append(task_id)
        db.execute(f"UPDATE tasks SET {', '.join(updates)} WHERE id = ?", values)
        db.commit()

    task = db.execute("SELECT * FROM tasks WHERE id = ?", (task_id,)).fetchone()
    task = dict(task)
    task["completed"] = bool(task["completed"])
    return jsonify({"task": task}), 200

@app.route("/tasks/<int:task_id>", methods=["DELETE"])
def delete_task(task_id):
    db = get_db()
    task = db.execute("SELECT * FROM tasks WHERE id = ?", (task_id,)).fetchone()
    if not task:
        return jsonify({"error": "Task not found"}), 404

    db.execute("DELETE FROM tasks WHERE id = ?", (task_id,))
    db.commit()
    return jsonify({"message": "Task deleted"}), 200

if __name__ == "__main__":
    app.run(debug=True)

Why parameterized queries? Notice WHERE id = ? instead of string formatting. This prevents SQL injection — a critical security vulnerability. Never use f-strings or concatenation to build SQL queries with user input.

5. Error Handling

Handle errors gracefully with Flask's error handlers:

@app.errorhandler(404)
def not_found(error):
    return jsonify({"error": "Resource not found"}), 404

@app.errorhandler(405)
def method_not_allowed(error):
    return jsonify({"error": "Method not allowed"}), 405

@app.errorhandler(500)
def internal_error(error):
    return jsonify({"error": "Internal server error"}), 500

You can also create a custom validation utility:

def validate_task_data(data, required_fields):
    """Validate incoming task data and return errors."""
    errors = []
    if not data:
        return ["No JSON body provided"]
    for field in required_fields:
        if field not in data or not data[field]:
            errors.append(f"Missing required field: {field}")
    if data.get("title") and len(data["title"]) > 200:
        errors.append("Title must be 200 characters or less")
    return errors

# Usage in a route
@app.route("/tasks", methods=["POST"])
def create_task():
    data = request.get_json()
    errors = validate_task_data(data, ["title"])
    if errors:
        return jsonify({"errors": errors}), 400
    # ... create task ...

6. Query Parameters: Filtering and Pagination

Make your API more useful by adding filters:

@app.route("/tasks", methods=["GET"])
def get_tasks():
    db = get_db()

    # Filtering
    status = request.args.get("status")
    completed = request.args.get("completed")

    query = "SELECT * FROM tasks WHERE 1=1"
    params = []

    if status:
        query += " AND title LIKE ?"
        params.append(f"%{status}%")
    if completed is not None:
        query += " AND completed = ?"
        params.append(1 if completed == "true" else 0)

    # Pagination
    page = int(request.args.get("page", 1))
    per_page = int(request.args.get("per_page", 20))
    offset = (page - 1) * per_page

    query += " ORDER BY id DESC LIMIT ? OFFSET ?"
    params.extend([per_page, offset])

    tasks = [dict(row) for row in db.execute(query, params).fetchall()]

    # Total count for pagination info
    count = db.execute("SELECT COUNT(*) FROM tasks").fetchone()[0]

    return jsonify({
        "tasks": tasks,
        "page": page,
        "per_page": per_page,
        "total": count,
        "pages": (count + per_page - 1) // per_page
    }), 200

Now you can call:

# Filter incomplete tasks, page 2, 10 per page
curl "http://127.0.0.1:5000/tasks?completed=false&page=2&per_page=10"

7. Project Structure for Larger APIs

As your API grows, organize it into files:

task-api/
├── app.py              # Application factory
├── config.py           # Configuration
├── database.py         # Database setup
├── models.py           # Data models
├── routes/
│   ├── __init__.py
│   └── tasks.py        # Task routes (Blueprint)
├── tests/
│   └── test_tasks.py
└── requirements.txt

Use Flask Blueprints to organize routes:

# routes/tasks.py
from flask import Blueprint

tasks_bp = Blueprint("tasks", __name__)

@tasks_bp.route("/tasks", methods=["GET"])
def get_tasks():
    return {"tasks": []}

# app.py
from routes.tasks import tasks_bp

app = Flask(__name__)
app.register_blueprint(tasks_bp)

8. Testing Your API

Flask includes a test client. No need to run the server:

import unittest
from app import app

class TaskAPITestCase(unittest.TestCase):
    def setUp(self):
        app.config["TESTING"] = True
        app.config["DATABASE"] = ":memory:"  # Use in-memory DB for tests
        self.client = app.test_client()

    def test_create_task(self):
        response = self.client.post("/tasks", json={
            "title": "Test task",
            "description": "Testing the API"
        })
        self.assertEqual(response.status_code, 201)
        data = response.get_json()
        self.assertEqual(data["task"]["title"], "Test task")

    def test_get_tasks(self):
        response = self.client.get("/tasks")
        self.assertEqual(response.status_code, 200)
        self.assertIn("tasks", response.get_json())

    def test_get_missing_task(self):
        response = self.client.get("/tasks/999")
        self.assertEqual(response.status_code, 404)

    def test_create_task_no_title(self):
        response = self.client.post("/tasks", json={"description": "No title"})
        self.assertEqual(response.status_code, 400)

if __name__ == "__main__":
    unittest.main()

# Run tests
python -m unittest
# ..
# OK (2 tests)

9. Run in Production

Flask's built-in server is for development only. Use Gunicorn for production:

# Install Gunicorn
pip install gunicorn

# Run with Gunicorn
gunicorn --bind 0.0.0.0:8000 --workers 4 app:app

# Or via Docker
# Dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY . .
RUN pip install --no-cache-dir -r requirements.txt
EXPOSE 8000
CMD ["gunicorn", "--bind", "0.0.0.0:8000", "--workers", "4", "app:app"]

# Build and run
docker build -t task-api .
docker run -p 8000:8000 task-api
