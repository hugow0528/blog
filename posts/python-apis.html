Python APIs: Fetch Data from the Web

June 21, 2026 · 8 min read

APIs (Application Programming Interfaces) let your Python programs talk to the internet. Fetch weather data, post to Twitter, query GitHub, interact with AI models — it all starts with API calls. This guide teaches you everything from a basic GET request to building a fully working weather app.

What Is an API?

An API is a set of rules that lets software programs communicate. A REST API uses standard HTTP methods (GET, POST, PUT, DELETE) and usually returns data in JSON format.

Think of it like ordering food at a restaurant. You (the client) send a request to the waiter (the API), who delivers it to the kitchen (the server). The kitchen prepares the food and sends it back through the waiter to you.

HTTP Methods in plain English: GET = read data, POST = create new data, PUT = update existing data, DELETE = remove data.

Install the requests Library

Python's built-in urllib can do API calls, but the requests library is far easier to use and is the de facto standard.

# Install via pip
pip install requests

# Verify it works
python -c "import requests; print(requests.__version__)"

Make Your First API Call: GET Request

Let's fetch data from a free, no-authentication-required API. We'll use JSONPlaceholder, a fake online API for testing:

import requests

# Make a GET request
response = requests.get("https://jsonplaceholder.typicode.com/posts/1")

# Check if the request was successful
if response.status_code == 200:
    # Parse the JSON response
    data = response.json()
    print(f"Title: {data['title']}")
    print(f"Body: {data['body']}")
    print(f"Author ID: {data['userId']}")
else:
    print(f"Error: {response.status_code}")

Output:

Title: sunt aut facere repellat provident occaecati excepturi optio reprehenderit
Body: quia et suscipit...
Author ID: 1

Key concepts:

  • response.status_code — 200 means success, 404 means not found, 500 means server error
  • response.json() — Converts the JSON string into a Python dictionary
  • response.text — Raw response text (useful for debugging)
  • response.headers — Response headers like Content-Type

Error Handling That Doesn't Crash

Real-world APIs fail. Networks drop. Servers go down. Always handle errors:

import requests

url = "https://jsonplaceholder.typicode.com/posts/1"

try:
    # Set a timeout so we don't hang forever
    response = requests.get(url, timeout=10)
    
    # Raise an exception for HTTP errors (4xx, 5xx)
    response.raise_for_status()
    
    data = response.json()
    print("Success! Got:", data["title"][:50])

except requests.exceptions.Timeout:
    print("Request timed out. Check your connection.")

except requests.exceptions.ConnectionError:
    print("Could not connect. Is your internet working?")

except requests.exceptions.HTTPError as e:
    print(f"HTTP error: {e}")

except requests.exceptions.RequestException as e:
    print(f"Something went wrong: {e}")

APIs with Query Parameters

Many APIs let you filter results using query parameters. Instead of manually building URLs, pass a dictionary to the params argument:

import requests

# Search GitHub repositories
url = "https://api.github.com/search/repositories"
params = {
    "q": "python tutorial",
    "sort": "stars",
    "order": "desc",
    "per_page": 5
}

response = requests.get(url, params=params)

if response.status_code == 200:
    results = response.json()["items"]
    
    print("Top Python Tutorial Repositories:\n")
    for repo in results:
        print(f"📦 {repo['full_name']}")
        print(f"   ⭐ {repo['stargazers_count']} stars")
        print(f"   📝 {repo['description'][:60]}")
        print(f"   🔗 {repo['html_url']}")
        print()

POST Requests: Sending Data

POST requests send data to a server. Use json= to send JSON data or data= for form data:

import requests

# Create a new post (simulated)
url = "https://jsonplaceholder.typicode.com/posts"

new_post = {
    "title": "My First API Post",
    "body": "Hello from Python!",
    "userId": 1
}

response = requests.post(url, json=new_post)

if response.status_code == 201:
    created = response.json()
    print(f"Created! ID: {created['id']}")
    print(f"Title: {created['title']}")
else:
    print(f"Failed: {response.status_code}")

Output:

Created! ID: 101
Title: My First API Post

Notice the server returned the data with a new id field. This is typical — APIs often echo back your data with added server-side fields.

APIs with Authentication (API Keys)

Many APIs require authentication. The most common method is passing an API key in headers:

import requests

# OpenWeatherMap example (get a free key at openweathermap.org)
api_key = "your_api_key_here"  # Replace with your key
city = "Tokyo"

url = "https://api.openweathermap.org/data/2.5/weather"
params = {
    "q": city,
    "appid": api_key,
    "units": "metric"  # Get temperature in Celsius
}

response = requests.get(url, params=params)

if response.status_code == 200:
    data = response.json()
    
    temp = data["main"]["temp"]
    feels_like = data["main"]["feels_like"]
    description = data["weather"][0]["description"]
    humidity = data["main"]["humidity"]
    wind_speed = data["wind"]["speed"]
    
    print(f"🌤️  Weather in {city}")
    print(f"   Temperature: {temp}°C (feels like {feels_like}°C)")
    print(f"   Condition: {description}")
    print(f"   Humidity: {humidity}%")
    print(f"   Wind: {wind_speed} m/s")
elif response.status_code == 401:
    print("Invalid API key. Check your key and try again.")
elif response.status_code == 404:
    print(f"City '{city}' not found.")
else:
    print(f"Error: {response.status_code}")

Other authentication methods:

  • Bearer tokens — headers = {"Authorization": "Bearer YOUR_TOKEN"}
  • Basic auth — requests.get(url, auth=("user", "password"))
  • OAuth 2.0 — Used by Google, Twitter, GitHub. More complex, uses the requests-oauthlib library

Building a Real Weather App

Let's put everything together into a reusable weather module:

# weather_app.py
import requests
from datetime import datetime

class WeatherClient:
    """A simple weather API client."""
    
    BASE_URL = "https://api.openweathermap.org/data/2.5"
    
    def __init__(self, api_key):
        self.api_key = api_key
        self.session = requests.Session()
        # Attach API key to every request automatically
        self.session.params = {"appid": self.api_key, "units": "metric"}
    
    def get_current(self, city):
        """Get current weather for a city."""
        response = self.session.get(
            f"{self.BASE_URL}/weather",
            params={"q": city}
        )
        response.raise_for_status()
        return self._parse_weather(response.json())
    
    def get_forecast(self, city, days=5):
        """Get a 5-day forecast."""
        response = self.session.get(
            f"{self.BASE_URL}/forecast",
            params={"q": city, "cnt": days * 8}  # 3-hour intervals
        )
        response.raise_for_status()
        return response.json()["list"]
    
    @staticmethod
    def _parse_weather(data):
        """Convert raw API response into a clean dictionary."""
        return {
            "city": data["name"],
            "country": data["sys"]["country"],
            "temp": data["main"]["temp"],
            "feels_like": data["main"]["feels_like"],
            "description": data["weather"][0]["description"],
            "humidity": data["main"]["humidity"],
            "wind_speed": data["wind"]["speed"],
            "icon": data["weather"][0]["icon"],
        }

# Usage example
if __name__ == "__main__":
    client = WeatherClient("your_api_key_here")
    
    cities = ["London", "Tokyo", "New York", "Sydney"]
    
    print("=" * 50)
    print(f"  🌍 World Weather Report — {datetime.now().strftime('%H:%M')}")
    print("=" * 50)
    
    for city in cities:
        try:
            weather = client.get_current(city)
            print(f"\n📍 {weather['city']}, {weather['country']}")
            print(f"   🌡️ {weather['temp']}°C ({weather['description']})")
            print(f"   💧 {weather['humidity']}% humidity | 💨 {weather['wind_speed']} m/s")
        except requests.exceptions.HTTPError:
            print(f"\n❌ Could not get weather for {city}")

Pagination for Large API Responses

APIs often limit results per page. Here's how to loop through all pages:

import requests

def fetch_all_repos(query, per_page=30):
    """Fetch ALL repositories matching a query, handling pagination."""
    all_repos = []
    page = 1
    
    while True:
        url = "https://api.github.com/search/repositories"
        params = {"q": query, "per_page": per_page, "page": page}
        
        response = requests.get(url, params=params)
        response.raise_for_status()
        
        data = response.json()
        repos = data["items"]
        
        if not repos:
            break  # No more results
            
        all_repos.extend(repos)
        print(f"Page {page}: fetched {len(repos)} repos (total: {len(all_repos)})")
        
        # Check if there are more pages
        if len(repos) < per_page:
            break
            
        page += 1
    
    return all_repos

# Fetch all Python repos sorted by stars
repos = fetch_all_repos("python", per_page=5)
print(f"\nTotal: {len(repos)} repositories found!")

Rate Limiting and Politeness

APIs often limit how many requests you can make. Don't hammer them:

import requests
import time

def polite_fetch(url, delay=1.0):
    """Fetch URLs with a delay between requests."""
    sessions = []
    
    for i in range(5):
        url_with_page = f"{url}/{i}"
        response = requests.get(url_with_page, timeout=10)
        response.raise_for_status()
        sessions.append(response.json())
        
        # Be nice to the API
        if i < 4:  # Don't sleep after the last request
            time.sleep(delay)
    
    return sessions

Pro tip: Many APIs include rate-limit headers:

response = requests.get(url)
print(response.headers.get("X-RateLimit-Remaining"))  # Requests left
print(response.headers.get("X-RateLimit-Reset"))        # When the limit resets

Quick Reference

  • requests.get(url) — Fetch data
  • requests.post(url, json=data) — Send data
  • requests.put(url, json=data) — Update data
  • requests.delete(url) — Delete data
  • response.json() — Parse JSON response
  • response.raise_for_status() — Raise error on 4xx/5xx
  • requests.get(url, params=d) — URL query parameters
  • requests.get(url, headers=d) — Custom headers (auth, etc.)
  • requests.get(url, timeout=10) — Timeout after 10 seconds
