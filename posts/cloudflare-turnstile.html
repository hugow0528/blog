Cloudflare Turnstile: Invisible CAPTCHA That Actually Works

July 8, 2026 9 min read

Google reCAPTCHA is everywhere, but it's also slow, privacy-invasive, and annoying. Cloudflare Turnstile is the modern alternative — it's invisible by default, privacy-respecting, free, and integrates in minutes. Here's how to set it up on any website.

What Is Cloudflare Turnstile?

Turnstile is a smart CAPTCHA alternative that uses risk analysis instead of puzzles. Instead of asking users to identify crosswalks or type distorted text, Turnstile analyzes:

  • Browser behavior patterns
  • IP reputation from Cloudflare's global network
  • Historical data from millions of requests

The result? 95% of real users pass instantly with zero interaction. The rest see a quick widget — no distorted text, no image grids. And unlike reCAPTCHA, Turnstile doesn't track users across websites for advertising.

Step 1: Create a Turnstile Site

  1. Go to dash.cloudflare.com → Security → Turnstile
  2. Click Add site
  3. Enter your site name and domain(s)
  4. Choose your widget mode (recommended: Non-interactive)

You'll get two keys:

# Widget key (client-side, goes in your HTML)
sitekey = "1x00000000000000000000AA"

# Secret key (server-side, for validation)
secret  = "1x0000000000000000000000000000000AA"

🔐 Secret Key is Secret

Never expose your secret key in client-side code. It belongs in your server's environment variables only.

Step 2: Add the Widget to Your HTML

Include the Turnstile script and a placeholder div in your form:

<!DOCTYPE html>
<html>
<head>
    <title>Protected Form</title>
    <script src="https://challenges.cloudflare.com/turnstile/v0/api.js"
            defer></script>
</head>
<body>
    <form id="contactForm" action="/submit" method="POST">
        <label for="name">Name:</label>
        <input type="text" id="name" name="name" required>

        <label for="email">Email:</label>
        <input type="email" id="email" name="email" required>

        <label for="message">Message:</label>
        <textarea id="message" name="message" required></textarea>

        
        <div class="cf-turnstile"
             data-sitekey="1x00000000000000000000AA">
        </div>

        <button type="submit">Send</button>
    </form>
</body>
</html>

That's literally it for the frontend. When the page loads, Turnstile renders a small widget that silently verifies the user is human.

Widget Modes

Turnstile supports different interaction modes via data-action and data-callback:


<div class="cf-turnstile" data-sitekey="YOUR_SITEKEY"></div>


<div class="cf-turnstile" data-sitekey="YOUR_SITEKEY"
     data-theme="dark"></div>


<div class="cf-turnstile"
     data-sitekey="YOUR_SITEKEY"
     data-callback="onTurnstileSuccess">
</div>

<script>
function onTurnstileSuccess(token) {
    // Token is ready — enable submit button or auto-submit
    document.getElementById("submitBtn").disabled = false;
}
</script>

Step 3: Validate on Your Server (Python/Flask)

The token from Turnstile must be validated server-side by posting to Cloudflare's verify endpoint:

from flask import Flask, request, jsonify
import requests

app = Flask(__name__)
TURNSTILE_SECRET = "1x0000000000000000000000000000000AA"  # From .env in production!

@app.route("/submit", methods=["POST"])
def submit():
    # Get the Turnstile token from form data
    token = request.form.get("cf-turnstile-response")

    if not token:
        return jsonify({"error": "Missing Turnstile token"}), 400

    # Validate with Cloudflare
    result = requests.post(
        "https://challenges.cloudflare.com/turnstile/v0/siteverify",
        data={
            "secret": TURNSTILE_SECRET,
            "response": token,
            "remoteip": request.remote_addr,  # Optional but recommended
        }
    ).json()

    print("Turnstile response:", result)
    # {"success": true, "challenge_ts": "...", "hostname": "..."}

    if not result.get("success"):
        errors = result.get("error-codes", [])
        return jsonify({"error": "Bot detected", "codes": errors}), 403

    # Turnstile passed — process the form
    name = request.form.get("name")
    email = request.form.get("email")
    message = request.form.get("message")

    return jsonify({
        "status": "success",
        "message": f"Thanks {name}! We'll contact you at {email}."
    })

if __name__ == "__main__":
    app.run(debug=True)

Validate with FastAPI

from fastapi import FastAPI, Form, HTTPException
from pydantic import BaseModel
import httpx

app = FastAPI()
TURNSTILE_SECRET = "YOUR_SECRET_KEY"

class FormSubmission(BaseModel):
    name: str
    email: str
    message: str

@app.post("/submit")
async def submit(
    name: str = Form(...),
    email: str = Form(...),
    message: str = Form(...),
    cf_turnstile_response: str = Form(...),
):
    async with httpx.AsyncClient() as client:
        result = await client.post(
            "https://challenges.cloudflare.com/turnstile/v0/siteverify",
            data={
                "secret": TURNSTILE_SECRET,
                "response": cf_turnstile_response,
            }
        )
        data = result.json()

    if not data.get("success"):
        raise HTTPException(status_code=403, detail="Bot detected")

    return {"status": "success", "name": name}

Validate with JavaScript/Node.js

// Using Node.js with express
const express = require('express');
const fetch = require('node-fetch');
const app = express();

app.use(express.urlencoded({ extended: true }));

const TURNSTILE_SECRET = process.env.TURNSTILE_SECRET;

app.post('/submit', async (req, res) => {
    const token = req.body['cf-turnstile-response'];

    if (!token) {
        return res.status(400).json({ error: 'Missing token' });
    }

    const result = await fetch(
        'https://challenges.cloudflare.com/turnstile/v0/siteverify',
        {
            method: 'POST',
            headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
            body: new URLSearchParams({
                secret: TURNSTILE_SECRET,
                response: token,
            })
        }
    ).then(r => r.json());

    if (!result.success) {
        return res.status(403).json({ error: 'Bot detected' });
    }

    // Valid! Process the form
    res.json({ status: 'success' });
});

app.listen(3000);

Common Error Codes

When validation fails, Cloudflare returns error codes:

Error Code Meaning Fix
missing-input-response No token submitted Check form has the widget and submits the hidden field
missing-input-secret No secret key sent Verify your server has the secret configured
invalid-input-secret Wrong secret key Double-check the secret from dashboard
invalid-input-response Token is malformed Ensure the form sends the right field name
timeout-or-duplicate Token expired or reused Tokens expire in 300s; don't reuse tokens
bad-request Misconfigured request Check URL encoding and parameters

Advanced: Multiple Widgets on One Page

If you need Turnstile on multiple forms, use explicit rendering:

<script src="https://challenges.cloudflare.com/turnstile/v0/api.js"
        defer></script>

<div id="widget1"></div>
<div id="widget2"></div>

<script>
// Render widgets explicitly
window.addEventListener('load', () => {
    turnstile.render('#widget1', {
        sitekey: 'YOUR_SITEKEY',
        callback: (token) => {
            console.log('Widget 1 token:', token);
        }
    });

    turnstile.render('#widget2', {
        sitekey: 'YOUR_SITEKEY',
        callback: (token) => {
            console.log('Widget 2 token:', token);
        }
    });
});

// Clear a widget after form submit
turnstile.reset('widget1');
</script>

Best Practices

  • Always validate server-side — never trust the client alone
  • Include remote IP in verification for better accuracy
  • Log failure reasons using error-codes from responses
  • Use environment variables for the secret key
  • Don't reuse tokens — each token is single-use
  • Handle timeouts gracefully — tokens expire after 300 seconds

Summary

  • Cloudflare Turnstile is a free, privacy-friendly CAPTCHA alternative
  • Setup takes 3 steps: create site, add widget, validate server-side
  • 95% of real users pass without any interaction
  • Validate tokens at challenges.cloudflare.com/turnstile/v0/siteverify
  • Always include the user's IP address for better accuracy
  • Error codes help debug common configuration issues

Turnstile makes bot protection feel invisible to real users while being effective against automated attacks. It's the kind of tool that makes you wonder why we ever settled for "click all the traffic lights."
